# Lay report

We checked whether the missing clock-depth rule was hiding in the way the clock and ruler directions
bend, turn, spread, or twist from place to place.

There is a real geometric vocabulary there—22 distinct “notes” if the transverse plane has an
orientation. Removing orientation choices reduces it to 13. Treating the ruler as an unoriented line
narrows it further, but still does not leave one answer.

The important test was whether some mixture of those notes automatically forms a consistent depth
that depends only on the endpoints. It does not. Valid clock/ruler fields already make every nonzero
mixture fail somewhere. A complete universe solution could force a special mixture to work, but local
geometry alone does not.

One attractive exception appears when the clock/ruler pair does nothing except Lorentz-like boosts in
its own two-dimensional plane. Then its ordinary boost connection is the derivative of rapidity. But
rapidity changes the observer frame while preserving the metric; UDT's founded `phi` changes the clock
and ruler reciprocally. They are different objects unless UDT later derives a relationship.

So we have not lost `phi`, and we have not invented a new field. We have learned that the missing rule
must come from how a complete global metric branch organizes these local building blocks—not from one
obvious first-derivative contraction that everybody had overlooked.
