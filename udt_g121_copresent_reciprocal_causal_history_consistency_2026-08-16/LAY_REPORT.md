# G121 lay report

We found the useful version of your idea, but also one important separation.

There are really two maps laid on top of each other:

- the **co-present observer map** says how A and B compare clocks and rulers. That comparison can be
  read in either direction;
- the **causal map** says how an actual ray or influence can travel through the metric's light
  cones. That trip has a future direction and can remember its route.

When we join already matching pieces, the arithmetic always works. Clock ratios multiply, reversing
a comparison inverts it, null rays stay null, and the angular machinery composes. Both a flat
universe and a genuinely changing curved test universe passed. So those rules alone do not choose
the universe; they are more like checking that every gear has correctly cut teeth.

The nontrivial condition is whether independently supplied pairwise clock/ruler comparisons can be
assembled into one worldwide calibration. Around any triangle A-B-C-A, the reciprocal changes must add back to zero.
Reciprocity by itself does not guarantee that. If every triangle closes, all observers are reading
one coherent global reciprocal network.

Crucially, this does **not** require the angular orchestra to return to zero around every loop. The
clock/ruler scalar can close while the angular channels retain real curvature and rotation memory.

So your proposed “physical history” can indeed constrain the combined object: one complete metric
plus one coherent network of observer relations. What we still lack is the native rule that says
which direct observer-pair edge the metric assigns. The next calculation is to compare that direct
co-present edge with the edge reconstructed through real causal rays from a common source—but only
after deriving the common mathematical carrier on which that comparison is legal. If they
join automatically, we have removed another piece of scaffolding. If they join only for some metric
histories, we have found an actual selection condition.
