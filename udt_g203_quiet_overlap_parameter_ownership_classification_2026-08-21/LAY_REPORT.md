# G203 lay report

The quiet middle now has three readable labels: how gently the score first leaves silence, where
that quiet spherical shell sits, and how rapidly the first note grows.

Those labels are not arbitrary coordinate tricks. The sphere's area fixes “where,” and the founded
depth scale fixes how the vertical response is measured. They belong to the metric profile itself.

But the reciprocal postulates do not print numerical values on those labels. Many perfectly lawful
profiles have different values. Observations can therefore calibrate a small, explicitly declared
family without being treated as a mechanism added after the kernel. What remains unjustified is
claiming that a few anchors uniquely derive the entire global score.
