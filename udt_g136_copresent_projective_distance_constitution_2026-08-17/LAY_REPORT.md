# G136 lay report

We asked whether the new bounded coordinate is merely one convenient way of marking distance.

The answer is sharper than G135: if the mark must carry the reciprocal kernel's own observer-pair
addition rule, every continuous possibility is `tanh(k phi)`. Neither `c_E` nor the already-chosen
`phi` convention fixes `k` for physical position. Choosing the local normalized-position unit to
have slope one fixes `k=1`; there is then no remaining shape freedom.

What mathematics cannot decide is what the word “distance” refers to. The old written record says
that time dilation occurs with distance, but explicitly admits that the kind of distance was not
specified. Current co-presence only says that events belong to one supplied solution.

So one clean foundational sentence is still needed:

> Physical normalized position is a continuous ordered coordinate of the completed reciprocal
> relation, obeys its native composition law, and has unit slope at coincidence.

If Charles adopts that meaning and unit convention, the formula is derived rather than named:

```text
x/X_max=tanh(phi_pair).
```

The value of `X_max`, proper path length, and which complete metric history Nature realizes remain
separate questions.
