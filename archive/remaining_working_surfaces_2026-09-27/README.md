## Historical references and restoration

Original bare names and root-relative links inside the preserved documents keep
their original context. Resolve an old name through the manifest or its baseline
Git tree; follow root INDEX for current status. Fixed census, hash and reorganization
tables retain their historical paths. For an epoch-specific replay, use the pinned
original tree rather than editing its source contract to match today's layout.

To inspect an original without altering the working tree, substitute its exact
manifest source in `git show 8aac11e13a2311347771e11f507f4f2042ea02a2:ORIGINAL_NAME.md`.
For physical restoration, first confirm the old path is absent, copy its archived
file to that path in a disposable worktree, and compare SHA-256 with the manifest.
Every selected file passed a scratch relocation/restoration byte check; current
archive bytes are independently compared with their original Git blobs.
Never overwrite an occupied path or infer permission to resume an old dispatch.
