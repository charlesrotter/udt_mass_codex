# Research tree

This directory organizes evidence artifacts. It does not define the current scientific frontier.

Read the root files in this order before navigating here:

1. `../LIVE.md`;
2. `../HANDOFF.md`;
3. `../CURRENT_RESEARCH_PROGRAM.md`;
4. `../CURRENT_SCIENTIFIC_PREMISES.md`, then run `python3 ../verify_current_scientific_premises.py`.

After orientation, query only task-relevant `../CURRENT_SCIENTIFIC_PREMISES.tsv` rows.

## Navigation

- `_registry/CURRENT_ARTIFACT_PATHS.tsv` is the repository-reorganization relocation ledger. Query
  it for a known old path; do not read or dump the 1,115-row table during startup.
- `_registry/README.md` explains registry semantics.
- Fixed ownership, readiness, census, preregistration, and verification tables are historical
  snapshots. Do not rewrite them to mimic later paths.
- Dated audit directories retain their own preregistration, premise ledger, raw outputs, verification,
  and maximum conclusion. Read the package itself before citing it.

## Interpretation guard

Directory placement is not scientific authority. A current path does not promote an artifact's
premise status, and an archived path does not invalidate its properly scoped evidence. When paths,
status prose, or cited sources disagree, stop and resolve the conflict from `LIVE.md`, the exact
premise registry, and the load-bearing source.

Use root `INDEX.md` for the compact current-frontier path list. It is not a startup read: the
relocation ledger is not guaranteed to contain packages created after the reorganization snapshot.

The pre-cleanup verbose research orientation is preserved at
`../archive/startup_surface_2026-08-14/research_README_before_cleanup.md`.
