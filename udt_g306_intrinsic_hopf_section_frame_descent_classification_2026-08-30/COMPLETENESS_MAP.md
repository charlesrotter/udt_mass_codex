# G306 completeness map

This package is one bounded geometric-classification tile, not a complete UDT solution.

| Criterion | Covered | Dropped or still open |
| --- | --- | --- |
| Fields | Free test unit direction over the full left/right Hopf family | No physical field population; complete coframe not evolved |
| Action terms | None used | Any action, source, coupling, or backreaction |
| Full equations | Exact metric geometry and section identities only | No field equation or Euler–Lagrange system |
| Domain and coordinates | Entire round compact S3 slice; all positive radii | Nonspherical histories, quotients, singular and topology-changing strata |
| Boundary and regularity | Boundary-free regular compact S3 | Other global completions |
| Topological sector | Both orientation-relative Hopf chiralities | Topology change and singular crossings |
| Dynamical character | Kinematic carry along supplied G305 slicing | Time-live field evolution, conservation, and stability |
| Branch/bifurcation | Complete constant-unit Killing family on round S3 | Other field classes on the same domain |
| Stability spectrum | Not tested | Entire stability and backreaction problem |
| Regime of validity | Positive G305 standard round-slice completion | All other UDT regimes |

The result characterizes a metric-defined candidate family. It does not filter the metric solution
space by demanding a particle, lump, mass, or preferred field.
