# G310 map — can one differential extension of Dual Reciprocity own G301?

Date: 2026-08-31

## Whole question

Test whether a single explicitly new differential balance statement, applied to the complete
four-dimensional metric, is sufficient to select G301's trace-free Ricci residual without importing
an action, GR field equation, source, observation, fitted scale, boundary, matter model, or
`X_max`.

The proposed statement is not assumed to follow from F1--F4 or W1--W6. G309 already supplies a
counterfamily showing that the currently founded/working chain alone does not select the residual.
G310 asks whether the smallest clean extension can be identified and classified.

## Frame

At one regular Lorentzian event, an orthonormal timelike-spacelike pair `(u,n)` has the exact
infinitesimal reciprocal metric tangent

```text
H(u,n) = 2 (u_flat tensor u_flat + n_flat tensor n_flat).
```

Its metric trace is zero. G302 found that the algebraic family of these tangents spans all nine
traceless symmetric metric directions. The retained common metric scale is the tenth direction.

The candidate new postulate, provisionally named differential Dual Reciprocity (`DDR`), is:

> On a physical solution, the first local natural complete-metric curvature response has zero
> contraction with every reciprocal pair-shape tangent `H(u,n)`.

This is a proposed law-level extension from algebraic pair reciprocity to differential balance. It
is not canon, not adopted, and not a consequence of pair normalization merely by wording.

## Scope

- full four-dimensional regular Lorentz metric at local curvature order;
- all algebraically admissible orthonormal timelike-spacelike pair directions;
- G301's conditional smooth, scale-free, local metric-only symmetric rank-two curvature-response
  class, with its nondegenerate Ricci coefficient;
- exact primary static-spherical and round time-live reductions only as downstream checks.

Omitted: higher-order and nonlocal laws, oriented parity-odd responses, auxiliary state, sources,
matter, physical query population, singular/caustic strata, global existence, observations, scale
calibration, mass, and physical `X_max`.

## Maximum possible conclusion

At most: one newly proposed differential balance premise is sufficient to select the trace-free
Ricci class inside G301's bounded operator arena, while leaving one connected-region scalar datum.
G310 cannot prove that the existing founding postulates entail that premise or that Nature adopts
it.
