# G115 completeness map

This package is one local kinematic tile, not a complete spacetime solve.

| Criterion | Covered here | Deliberately dropped / still open |
|---|---|---|
| fields | all spherical metric functions through the smooth central two-jet modulo residual areal-time slicing; active observer celestial drift; source radial congruence jet | nonspherical metric modes, higher radial jets, source fields; individual coefficients are gauge representatives |
| action terms | none | every action/source term |
| full equations | metric identities, null geodesic, Jacobi equation for supplied metric | physical EOM and variations |
| domain | one regular `X>0` central neighborhood, time live | finite radius, areal-null, global, nonspherical domains |
| boundary/regularity | exact smooth-center parity; Q0/Q2/QW/QB separated; QW zero-order phase-point gate | global boundaries and physical source boundary law |
| topology | local spherical orbit only | global topology, winding, Hopf sectors |
| dynamical character | arbitrary time derivatives at one event | integrated time history or evolution law |
| branch/bifurcation | one outgoing local radial branch; rank strata retained | nonradial, cut, multiple-image, global branches |
| stability spectrum | not applicable | all stability questions |
| regime | leading nontrivial central jet | SNe/BAO/CMB, `X_max`, micro, finite-cell regimes |

Technique category: exact symbolic algebra and independent numerical integration are conditioning
and verification only. No degree of freedom was frozen to demand an observational shape. Spherical
isotropy removes central shear as a theorem of the bounded symmetry class; that remains an explicit
blind spot for the complete orchestra.
