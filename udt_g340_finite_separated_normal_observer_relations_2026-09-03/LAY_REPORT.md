# G340 lay report

The metric supplies something more fundamental than a fitted light model: it supplies the light
cones themselves.

For two fixed-label observers, G340 can now calculate four different things without modifying the
kernel:

1. how far apart they are across one chosen same-time slice;
2. which later clock reading a specified light-cone route reaches;
3. what one observer would call radar range after an ideal send-and-return experiment;
4. the reciprocal/projective clock contrast carried by each one-way route.

These quantities are linked by exact formulas, but they are not the same definition wearing four
names. In an evolving spacetime, a radar experiment spans time while a slice distance is measured
on one slice. The projective result is dimensionless and records ordered clock response. It needs a
separate scale before it can be written as a length.

Because the spatial universe is compact in this example, the same two observers can be connected
by routes that wind around it different numbers of times. The metric predicts a separate arrival
for each route. It also identifies the earliest one, with ties at special halfway locations, but it
does not say which routes a real source emits or a detector sees.

So no luminosity, photon, or electromagnetic model was smuggled in. Radar reflection is clearly
marked as a chosen measurement procedure. A light/matter model will be needed later for brightness,
spectra, emission, absorption, and detection—not for the causal timing geometry derived here.

The bounded result is positive: the native metric and pair machinery remain coherent when extended
from infinitesimal separation to finite-separated supplied observers. What remains open is which
distance protocol and observer/path population are physical, as well as occupancy, scale,
`X_max`, matter, observations, and canon.
