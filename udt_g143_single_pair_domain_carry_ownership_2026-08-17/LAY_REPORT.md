# G143 lay report

The “carry” is not missing inside one fully specified observer-pair measurement.

Imagine the pair relation as one sheet of graph paper connecting A and B. The graph paper already
gives both endpoints a common way to write clock/ruler components. On that sheet the carry is simply
identity: keep the same graph-paper labels while moving from A to B.

Now redraw the same sheet with grid spacing that changes from one end to the other. The carry matrix
becomes nonidentity, but the endpoint calibration matrices change by exactly the opposite amount.
The complete comparison is unchanged. So this part of the carry is bookkeeping, not a new force.

That is a real simplification: G141 is the natural same-chart version; G142 is the version that stays
correct when the chart markings change.

What remains open is narrower. Two different sheets—different queries, branches, or pair
realizations—are not automatically glued together. We still need either an actual overlap, a common
atlas, or a supplied transport to compare them. And the theory still has not selected the complete
metric history or numerical `X_max`.
