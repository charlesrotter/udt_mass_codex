# G283 lay report

We asked whether the metric's familiar consistency rules secretly contain the missing score.

They do not, in this bounded test. We built an explicit family in which one central observer/light
relation looks exactly the same locally, while the neighboring light paths can be made to focus,
spread, or shear according to three arbitrary smooth functions. All the existing geometry rules
still fit together perfectly.

In the orchestra language, Cartan, Bianchi, screen carry, and network composition make sure every
musician is playing compatible notes in the same geometry. They do not write the notes.

This is progress because it closes a plausible hiding place. The missing bridge is not another
ordinary consistency identity. It must be a genuinely value-bearing UDT principle that says how
neighboring relations develop together. We have not chosen that principle, imported Einstein's
equations, or fitted it from observations.
