# Independent verification record

The independent verifier uses Python standard-library exact fractions and TSV
reconstruction. It does not import or execute the production derivation.

It independently checks determinant/trace variation identities, density's
quotient rule, the trace and trace-free integrated-curvature contractions,
conformal weights, dimensional exponents, boundary/functional/closure
counterfamilies, fixed-path holonomy linearity, systole tie stratification,
topology's discrete response, and diameter nonsmoothness.

It then validates all 26 gate rows against fail-closed invariants and exercises
22 forbidden mutations. Every mutation is rejected. `INDEPENDENT_RESULT.json`
and `CATCH_PROOFS.tsv` contain the exact machine-readable return.

A separate fresh-context adversarial source review was also completed before
banking. It returned `CORRECTION_REQUIRED`, retained the central verdict, and
caught type/credit errors in N04, N12, N14-N16, N19-N20, N24, G11, the
conditional-action principles, and the original single-row assembly test.
`ADVERSARIAL_CORRECTION.md` records the applied correction layer. This review
is not treated as a substitute for runnable evidence.
