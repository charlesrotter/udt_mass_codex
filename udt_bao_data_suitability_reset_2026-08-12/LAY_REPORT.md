# Lay report

We now have a trustworthy map of the observed clustering pattern, without adopting the conventional
story about what caused it.

Think of the released data as thirteen plotted coordinates plus a sheet telling us how their errors
move together. We verified that sheet three different ways. Six locations contain both a sideways and
a line-of-sight measurement, so their ratio gives a particularly clean description of how the pattern
changes shape with depth. The release's common scale label cancels from those ratios.

What we have **not** done is call the pattern a standard ruler, assume an acoustic origin, fit UDT, or
calculate the size of the universe. We have only established that this is suitable observational input
for the next test of the one complete UDT observer-pair relation.
