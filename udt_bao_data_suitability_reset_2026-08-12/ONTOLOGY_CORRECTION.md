# Ontology correction — BAO is a release label, not a UDT mechanism

Date: 2026-08-12  
Authority: Charles's explicit correction after preregistration

The frozen preregistration uses the collaboration's conventional names and the class label
`SCALE_READY_WITH_NUISANCE_RULER`. That label must not be read as UDT acceptance of an acoustic
origin, a standard ruler, a yardstick, or an early-universe mechanism.

For all current and downstream UDT work:

- `BAO` is only the public dataset/subject label;
- the measured clustering feature is referred to neutrally as the **observed correlation pattern**;
- `D_M/r_d`, `D_H/r_d`, and `D_V/r_d` are **published dimensionless pattern coordinates**;
- the symbol `r_d` is treated only as the release's common packaging normalization;
- if the complete published vector is used, that common normalization is a free
  `PUBLISHED_NORMALIZATION_NUISANCE` with no physical interpretation assigned;
- `D_M/D_H` is the clean shape channel because the publication normalization cancels;
- no acoustic-origin model, sound-horizon calculation, standard-ruler assumption, Lambda-CDM
  dynamics, or early-universe mechanism may enter a UDT prediction.

The preregistered class name is retained only to preserve the frozen audit contract. Its operative
meaning is corrected to:

```text
SCALE_READY_WITH_NUISANCE_RULER
  == FULL_PATTERN_VECTOR_READY_ONLY_WITH_PUBLISHED_NORMALIZATION_NUISANCE
```

This correction changes ontology and language, not the released bytes or covariance.
