# Lay report

We tested whether UDT’s rule for chaining observer comparisons was secretly the missing law of the
universe.

It is not—at least not by itself.

The rule works like addition on a ruler. If the first comparison says “five units” and the second
says “three units,” the combined comparison says “eight units.” That is real structure: arbitrary
labels that do not add correctly are rejected. But it does not tell us what physical feature of the
metric produced the five and the three.

The same distinction survives for paths. Any path can accumulate a running depth, and adjoining two
paths adds their accumulated depths. That remains true even when going around a loop does not return
the accumulated depth to zero. Demanding zero around every loop would be a new physical rule; it is
not contained in the present founding postulates.

So we found a clean stopping point. Reciprocity tells a future law how observer comparisons must
fit together, but it does not generate the missing law. Continuing to analyze composition alone
would now be circling.

The missing input remains something that determines the physical depth or the allowed complete
metric—possibly a genuine global-local/bootstrap closure, but this audit does not derive that
possibility.
