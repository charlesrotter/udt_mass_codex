# Lay report

We now know exactly what the current rules do—and do not—say about the rest of
the metric.

The two founded clock/ruler channels are like a verified two-gear mechanism:
when one gear scales down, the other scales up. The full four-dimensional
metric still has seven possible ways for that motion to be carried into the
angular part and into cross-couplings between the two parts.

Those seven settings are not just different coordinate descriptions. Each
one can change the physical metric. We also built explicit examples in which
the angular sector participates or the sectors mix while the original
reciprocal pair continues to obey all of its proven laws.

We then tested every currently registered UDT premise. None supplies an
actual equation that chooses among those seven settings. Some premises govern
only the original pair. Some describe how every observer must transform the
same geometry. The finite-cell and `X_max` ideas are global but do not yet
define an operation on these local settings. Bootstrap currently judges
finished solutions; it does not build the local metric. Strong local CSN is
inactive, and the carrier and action are not allowed to be smuggled in.

There is one useful conceptual correction. The reciprocal two-plane cannot
be a rigid plane that looks component-for-component identical in every moving
frame. It must move with the frame, just as any real geometric plane does.
That is compatible with observer reciprocity, but UDT still owes the rule that
identifies this plane and tells its motion how to extend through the angular
sector.

So this audit did not find the missing selector, but it did prevent several
false ones. The next genuine missing piece is a frame-covariant mounting rule
for the founded two-gear mechanism inside the complete metric. Only then can
we say which parts of the full metric vary together and begin an action or
dynamical derivation honestly.
