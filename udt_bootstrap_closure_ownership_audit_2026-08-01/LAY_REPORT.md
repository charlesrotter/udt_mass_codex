# Lay report

The metric already acts like a very rich instrument panel. Given a complete geometry, it can show
curvature, volume, boundary shape, transport around paths, topology labels, clock comparisons, and
other geometric readings. Some dials need you to specify which observer, path, slice, or global
completion you mean. It still does not natively label any dial “total mass” or “total energy.”

Bootstrap needs more than an instrument panel. It needs a control linkage: the readings of the
whole universe must feed back and restrict which local geometry and matter patterns can exist.
Writing down the readings does not create that linkage. Mathematically, “the readings equal what
this geometry produces” is true for every geometry and therefore selects nothing.

P4 found something shaped like part of such a linkage, but only inside a particular conditional
branch. Change the still-unselected pairing and the tie disappears. So it is a clue, not yet the
universal rule.

The useful narrowing is this: we are not missing a longer list of geometric ingredients. We are
missing the joint—or table leg—that turns the universe's global readout back into a law for the
same universe. That law need not be an action, but it must be more than self-description.
