completion data. Determine, in order:

1. which global objects the complete metric already computes as a typed map `R_metric[X]`;
2. which are only bounded, conditional, queried, or type-only objects rather than components of one


cosmology. A scalar integral is not automatically a physical observable; a configuration label is

## Closed-loop gate

A native loop passes only if one compatible premise assignment supplies:

- one complete domain `U_full`;
- one typed `R_metric: U_full -> O`;
- one typed nonidentity `A: U_full x O -> Y`;
- all boundary/corner/completion and global-modulus inputs;
- an exact common fixed-point problem with no undefined mass, energy, source, pairing, or
  normalization; and
- at least one proof that the loop is more than the tautology `O=R[X]` with no restriction on `X`.

No scalar objective, minimization, density equality, or action is privileged by familiarity.
