# G137 lay report

The metric's complete orchestra first builds the relationship between observers A and B. That
relationship contains a signed imbalance: which way B lies relative to A and how deep the
clock/ruler dilation has become.

Your adopted clarification says that this imbalance is physical normalized position. The result is

\[
\frac{x_{AB}}{X_{\max}}=\tanh\phi_{AB}.
\]

If we forget direction and ask only “how far apart?”, we take the magnitude:

\[
\frac{s_{AB}}{X_{\max}}=|\tanh\phi_{AB}|.
\]

Direction matters when relations are chained. Two equal steps can reinforce or cancel, so signed
position composes but bare distance does not retain enough information to compose on its own.

This suggests “co-present relational spacetime” as a useful qualifier. We do not need to discard
the word spacetime: UDT still has a metric geometry. The qualifier reminds us that physical
position is made by observer relationships rather than placed on an independent background ruler.

The shape is now fixed, but the size of the tape—`X_max` in physical units—is still unknown.
