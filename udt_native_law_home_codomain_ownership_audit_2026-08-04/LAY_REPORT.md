# Lay report

We found that “the law” was hiding several different jobs under one name.

UDT already has a rule for comparing two observers' clock/ruler channels. That rule naturally lives
on the **comparison between the observers**. It is like a conversion ticket: it has a starting side,
an ending side, and a reversal rule. It is not a field equation that tells spacetime how to behave.

The metric's ordinary geometry lives somewhere else: directly on spacetime. Curvature exists at a
place whether or not anyone asks a particular observer-pair question.

Some quantities—such as how curvature splits into the reciprocal plane and angular screen—really do
depend on which observer/ruler pair is being used. They can remain comparison-dependent, or become
one physical spacetime field only if the metric itself selects a plane on that branch. At symmetric
or degenerate places that selection can split or disappear, so a still-missing rule must say how to
cross those places.

The especially useful new distinction is this: a formula that depends on an observer pair is still
ambiguous until we say whether it must hold for **every** pair, only for the pair being observed, for
one physically realized pair field, or for a pair derived from the metric. Those versions vary
different things and are not the same theory.

So we did determine several homes exactly, but we did not uncover the complete native dynamical law:

- reciprocal comparison belongs to the observer-pair/query layer;
- ambient geometry belongs to spacetime;
- pair-resolved response belongs to the query layer or a metric-derived reduction;
- the law that decides which complete metrics are physically allowed still has several honest
  mathematical homes.

The SNe result helps modestly. It says any successful completed architecture must keep clock
redshift, angular/area distance, optical distance, and proper pair distance distinct. It does not
tell us which upstream law produced the metric. In the engine/dashboard metaphor, SNe tells us the
dashboard needs four separate gauges and confirms one conditional relationship among three of them;
it does not choose the engine design.

This is progress because the next question no longer begins with “guess an action.” It begins with:
what kind of rule can select whole metric solutions while treating observer queries correctly and
remaining defined across the metric's symmetric and degenerate strata?
