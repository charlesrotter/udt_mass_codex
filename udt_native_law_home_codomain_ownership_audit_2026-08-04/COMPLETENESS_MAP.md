# Completeness map

This audit is one type/architecture tile, not a spacetime solve.

| Criterion | Covered here | Dropped/open |
|---|---|---|
| Fields | distinguishes base metric, query arguments, realized and derived reductions | selected physical field census |
| Action terms | none assumed | complete action and all terms |
| Full equations | possible homes/codomains classified | native equations absent |
| Domain/coordinates | abstract global metric/query architecture | realized manifold, charts and solution branch |
| Boundary/regularity | base, query, reduction and defect types separated | native boundary functional and joins |
| Topological sector | discrete sectors typed as non-tangents | sector selection and complete classification |
| Dynamical character | native dynamics explicitly unselected | constraints, evolution and time-live law |
| Branch/bifurcation | regular versus collision/defect strata retained | solution branch atlas |
| Stability | not tested | all unconditional stability |
| Regime | exact bounded architecture universe and registered static SNe anchor | arbitrary future architectures and physical regimes |

No dropped criterion is treated as absent physics. The calculation uses only category-A exact
algebra and classification. It does not filter solutions by shape, matter content, or agreement with
the SNe branch.
