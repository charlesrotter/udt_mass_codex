## What was genuinely learned

The exact block reduction proves that a fixed-background calculation need not
have the same linearized kernel as the coupled global-local calculation. The
feedback term `A_O R_X` changes the kernel condition itself.

This validates the *type* of the bootstrap concern. It does not prove that UDT
has supplied the physical maps or that a resulting kernel is matter.

### The bootstrap cannot generally be one density or curvature number

Proper volume is blind to trace-free angular deformation. Density can see that
channel only through native mass variation, which remains absent.

A curvature functional can carry trace-free response, but two algebraic Ricci
triples with the same scalar trace have different contractions against one
trace-free angular direction. Therefore an unstructured density scalar plus
an unstructured scalar-curvature datum does not determine that pointwise
response absent a same-branch realization law. Structured curvature,
directional/spectral data, boundary information, holonomy, or native
energy/mass response may be required. Their exact native census is open.
