# Lay report

The bootstrap idea now has a precise mathematical form.

Imagine testing whether a violin string can vibrate while the body of the
violin is held fixed. It may appear unable to support the desired note. But
the string also moves the violin body, and the moving body feeds back into the
string. That feedback can create a possible vibration pattern in the
first-order test that did not exist in the fixed-body test—or remove one that
did.

UDT's corresponding tuning operator is

```text
local response + global feedback.
```

We proved exactly that the global-feedback part can create or remove a
first-order zero mode. This means a fixed-background zero-mode result cannot
automatically be treated as the coupled bootstrap result. It does not yet say
that a real nonlinear matter branch exists.

But a zero mode is not automatically matter. It might be an unphysical
coordinate freedom, be killed by the finite-cell boundary, fail to close
around the universe, or disappear when the full nonlinear equations are used.
Indeed, two exact toy closures can look identical to first order at the
critical point while one has no neighboring real branch and the other has two.

We also learned that one density number and one scalar-curvature value are too
coarse. Different algebraic arrangements can have the same curvature trace
and still respond differently in an angular direction. The bootstrap
“orchestra” may therefore need information about how curvature is organized,
not merely how much there is.

The most promising pieces are visible:

- reciprocal clock rate;
- angular or tidal curvature;
- finite-cell boundary and holonomy;
- global volume and diameter;
- and possible topological organization.

They have not yet been joined on one complete solution. The next task is to
derive the metric-only global recomputation map as completely as possible,
then determine whether the founding UDT rules supply the reverse law that says
which local structures those global data permit.

So the deep conceptual lead survives in a disciplined form: matter may be a
nontrivial whole-universe/local self-consistent pattern, with an action perhaps
describing a closure already selected rather than doing the selecting. The
feedback mathematics supports that architecture, but the metric has not yet
supplied the two physical arrows needed to make it a UDT result.
