receiver proper-time intervals on an actual null branch. Its variation argument

knowing only Z as a function of source time determines F only up to an additive
arrival-time origin: finite counts in a fixed receiver window need alignment
or the actual event correspondence as well.

3. A supplied counting measure mu_e on source proper time transports to
mu_o(B)=mu_e(F^{-1}(B)). For atoms this means moving the timestamp and retaining
the assigned multiplicity/weight. If mu_e=r_e(s)ds and F is a differentiable

it does not supply which source ticks occurred, their rates, multiplicities,

Discrete timestamps have finite differences, not automatically a differentiable

pushforward counting measures is a defined unlabelled total; retaining labels
