# G196 in lay language

G195 let the screen instruments change with time. G196 also let them change with position along the
line between the observers.

The result is cleaner than “two more knobs.” For the outgoing observer pair tested here, time-change
and along-the-line spatial change lock together. The pair hears only the change **along its own
outgoing direction**. The metric itself combines them; we did not fit a weighting coefficient.

The ordered orchestra still interlocks, and the exact no-caustic sign proof survives. Pure rotation
still turns the screen without independently magnifying its area.

But one listening line does not hear the whole room. Two fields can be identical along that line and
different elsewhere. So the next useful question is whether several differently directed pair germs
together constrain the surrounding metric field. G196 does not yet answer that global question.
