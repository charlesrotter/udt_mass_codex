# G235 map — the quantifier under test

## Three statements that must remain separate

1. Every supplied completed physical pair obeys Dual Reciprocity.
2. There exists one smooth rank-complete matched network of such pairs.
3. Every conceivable admissible observer germ is physically populated and shares an observer-only
   endpoint calibration.

G176 supplies statement 1 conditionally. G129/G213/G214 describe how a supplied instance of
statement 2 reconstructs and descends. Statement 3 is stronger and is not currently owned.

G235 tests statement 2 exactly. If every smooth time-oriented metric in the bounded arena admits
such a network after a common clock field and rank-complete ruler bearings are supplied, then its
existence is reconstructive rather than selective.

## Proposed construction

At each event use one common timelike clock vector `U` and the ruler bearings

```text
e1, e2, e3, e1+e2, e1+e3, e2+e3.
```

Their full pair pullbacks have rank ten. Every pair shares

\[
\Phi(p)=-\frac12\log[-g(U,U)]
\]

at the same incidence. G176 then completes each pullback independently, while matched edge depths
are potential differences. The question is whether any remaining equation couples the values at
different events. The preregistered twin decides that question.
