# G235 lay report

We tested whether assembling all the reciprocal pair pieces into one complete observer network
finally forces the universe's distance profile.

It does not. The network is like a perfectly wired orchestra:

- it hears every instrument;
- every instrument uses the same tuning convention;
- neighboring pages of the score line up;
- intervals add correctly through a middle observer.

But those rules still allow many different melodies. We built the full network around two
geometries that agree through the already tested local order but differ by a real curvature
invariant. Both passed every network rule.

This is useful closure, not a setback. Rank completeness, matched incidence, and completed
Reciprocity are now firmly classified as the faithful language in which a metric is expressed—not
the missing rule that chooses its profile.

The next useful step requires an actual new candidate: either an invariant property that naturally
shrinks the metric family, or a stronger global relation condition that rejects one regular
network for a reason stated before seeing the desired answer.
