## 1. The problem in ordinary language

UDT begins with a reciprocal relation between clock and ruler comparisons. If one side of the
comparison acquires a factor `exp(-delta)`, the reciprocal side acquires `exp(+delta)`. That exact
two-channel operator is known, including how it composes.

What is not known is how the **complete geometry of two physical observers** determines the number
`delta` in the first place.

The missing rule must compare observer A with observer B, include the complete angular and mixing
geometry between them, and return one signed clock/ruler depth. If A is compared with B and then B
with C, the two answers must combine into the A-to-C answer on the corresponding concatenated
comparison data. This does not assume that every path with the same endpoints is equivalent.
Reversing the comparison must reverse the sign. Changing the arbitrary coframe used to describe
either observer must not change the physical answer.

Mathematically, those requirements place the answer in a real-valued cocycle on an
observer/event/path comparison groupoid. The phrase *groupoid cocycle* names the required
composition behavior. It does **not** supply the physical cocycle, prove that it is unique, or prove
that it must arise from a connection or one-form.

The challenge is therefore:

> Does the UDT metric and its complete coframe structure already contain a natural rule that maps
> each admissible ordered observer comparison to the physical signed reciprocal depth? If so,
> derive and classify it. If not, prove the remaining nonuniqueness sharply and identify the
> smallest additional premise that would select it.

An equally valuable answer is a rigorous no-go theorem showing that the present premises cannot
select such a rule.
