## Question and preliminary disposition

Can the existing working asymptotic received-slowing commitment exclude a
physical realization whose endpoint clocks and connecting null rays remain
inside one regular compact region with controlled causal duration? More
precisely, can ordinary proper clocks and the one-metric null-clock interface,
together with the physical asymptotic statement, rule out an arbitrarily large
received-tick ratio in a compact temporal region with bounded endpoint boosts,
without assuming a curvature sweep, field equation or spacelike completion?

This is a proposed global causal version of the asymptotic exclusion, not a
new law. Source-first inspection already finds a serious usefulness obstacle:
the existing positional commitment does not identify a net-ratio family to
which the proposed bound applies. ACI1 explicitly retains that same boundary.
I therefore recommend **no substantive probe allocation unless the coordinator
can articulate a source-supported physical implication beyond this generic
bound**. This is a source-grounded recommendation for this route, not a result
that every existing-premise geometry route is exhausted. The proposal is
preserved rather than replaced after that adverse source finding.

## Possible consequences

Favorable: an owned physical family is identified and the lemma survives. Then
that particular asymptotic realization cannot stay within the stated compact
causal and endpoint controls. A physical completion must violate at least one
of those controls. This excludes a class of comparison realizations; it does
not choose curvature, a field equation, distance, scale, observer population,
X_max, or one universe. No curvature singularity follows.

Adverse: the source implication is absent, or the compact-region lemma fails.
Return the precise unsupported inference or a scoped counterexample. A true
conditional bound alone does not count as a new native constraint. The sources
already suggest the first adverse outcome, so declining computation is sensible.

Ambiguous: the owner asymptote permits several inequivalent physical comparison
assignments and only some are excluded. Retain the distinction and return an
unresolved assignment question; do not turn an assistant's selected experiment
into the owner's intended universal observable.
