# G275 lay report

The new W5 rule gives us a complete **shape and position reading** for an observer pair, including
the angular directions. But that reading is normalized: it is like knowing that a point lies 70%
of the way across a map without yet knowing whether the map is one metre or one billion
light-years wide.

G275 shows that only one common size multiplier remains. One honest measurement of the very same
geometric object can set that multiplier. A second kind of measurement does not add a second knob;
it must agree or the proposed dimensionless universe fails the test.

The angular machinery was not turned off. In nonspherical cases the complete frame transport is
still needed to combine observer relations. Multiplying by a ruler scale does not reduce the
orchestra to the radial note.

The scale is also not automatically \(X_{\max}\). It becomes the maximum only if the physical
observer relations actually extend all the way toward the edge of the normalized projective
state. That global population/completion fact has not yet been derived.

So the clean result is: **the kernel supplies normalized position; one external anchor supplies its
units; a separate global theorem is still needed to call that unit scale the universe's maximum.**
