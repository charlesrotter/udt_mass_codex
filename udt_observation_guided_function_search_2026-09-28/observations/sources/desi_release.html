    DESI Data Releases¶

    Spectroscopic Data Releases¶

    Data Release 1 (DR1) — March 19, 2025¶

    Data: https://data.desi.lbl.gov/public/dr1
    Paper: DESI Collaboration et al. (2026), Data Release 1 of the Dark Energy Spectroscopic Instrument
    Overview: DR1 Documentation

    Data Release 1 (DR1) is the first release of DESI Main Survey data, including 18.7 million new spectra observed from May 2021 through June 2022. It also includes a reprocessing of Survey Validation data previously released with EDR using the latest algorithms and calibrations.

    Early Data Release (EDR) — June 13, 2023¶

    Data: https://data.desi.lbl.gov/public/edr
    Paper: DESI Collaboration et al. (2024), The Early Data Release of the Dark Energy Spectroscopic Instrument
    Overview: EDR Documentation

    The DESI Early Data Release includes spectra for 1.8 million unique targets from Survey Validation observations taken from December 2020 through June 2021, as well as a few commissioning and special tiles observered during the same time period. Read more…

    Note

    DESI data are released under the Creative Commons Attribution 4.0 International License (CC BY 4.0). Use of DESI data requires including the citation and acknowledgment text given on the Data License and Acknowledgments pages.

    Targeting Data Releases¶

    Early Target Selection (ETS)¶

    Data URL: https://data.desi.lbl.gov/public/ets

    The Early Target Selection (ETS) release includes the output of desitarget algorithms applied to DESI Legacy Imaging Surveys DR9 photometry to select the targets observed for DESI Survey Validation and Main Survey observations.

    Other DESI Data¶

    Education and Public Outreach (EPO)¶

    Data URL: https://data.desi.lbl.gov/public/epo

    Example DESI data and visualizations used for Education and Public Outreach (EPO).

    • DESI-HighSchool: datasets used by the DESI High: School of the Dark Universe outreach program
    • desi3d: interactive 3D visualization of DESI data obtained in 5 hours of observing
    • desifp: (UPCOMING) description of the DESI focal plane for a general audience

    Transients¶

    Data URL: https://data.desi.lbl.gov/public/transients

    Ad-hoc releases of (meta)data for DESI observations of transients. This directory is largely deprecated in favor of posting to Zenodo, but it could have future datasets that are larger than viable for Zenodo.

    Data Supporting Published Papers¶

    Data URL: https://data.desi.lbl.gov/public/papers
    Zenodo: https://zenodo.org/communities/desi-pub
    Value Added Catalogs: VAC documentation page

    Supporting data for individual published papers are available via Zenodo or https://data.desi.lbl.gov/public/papers when the supporting dataset is too large for Zenodo:

    • cosmosim/nbody_code_comparison2021: supporting files for Grove et al. (2022): The DESI N-body Simulation Project I: Testing the Robustness of Simulations for the DESI Dark Time Survey
    • DR2 cosmology chains and posterior maximization results: supporting files for DESI Collaboration et al. (2025), DESI DR2 results. II. Measurements of baryon acoustic oscillations and cosmological constraints

    Papers may also release their supporting data as a Value Added Catalog accompanying a data release.
