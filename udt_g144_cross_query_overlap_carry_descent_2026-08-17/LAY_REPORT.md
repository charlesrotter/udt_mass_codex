# G144 lay report

We can now say exactly when two measurement sheets may be sewn together.

If they overlap over a genuine patch and describe the same geometric relation there, the change of
grid between them is the carry. It is ordinary, exact atlas glue. At the same physical event it can
only change the description, not create new positional dilation; in the positive triangular gauge
used here, the complete overlap transition is identity.

Sharing the same two observer boundaries is not enough. Two flexible sheets can be attached to the
same edge wires while bowing through different interiors. The exact counterexample does precisely
that: both sheets are regular, both touch the same observer worldlines, but their interiors never
overlap. There is then no derivative map sewing one sheet to the other.

So the carry puzzle has split cleanly:

- inside one sheet, the chart supplies it;
- across genuinely overlapping sheets, the overlap map supplies it;
- across different sheets, no glue should be invented.

What remains is not a missing carry formula. It is the physical question of which complete relation
sheets and metric history the universe realizes.
