# G154 preregistration execution note

Date: 2026-08-18

The preregistration allowed smooth diagonal metric counterfamilies with positive free witness
exponents and required common-scale covariance to remain visible. During production the initially
obvious construction varied the reciprocal-profile exponent between response classes. Before any
verdict or banking, it was replaced by a stronger within-scope construction:

- one fixed profile `phi=epsilon*(-1/3)*log(q)`;
- one fixed positive `X_star`;
- one identical terminal position `rho(q)=X_star*tanh(phi(q))`;
- only the retained metric ruler/common-scale exponent in `L=q^(-ell)` varies.

The values `ell=1/2,1/3,1/4` realize quiet, finite-live, and divergent normalized spatial response.
An additional positive oscillatory common-scale witness realizes nonconvergence. `ell` is
`FREE_AND_EXPLORED_COUNTERFAMILY` data, not a physical coefficient or fit.

This refinement does not change the preregistered question, candidate list, certification gate, or
maximum conclusions. It removes a possible false explanation by showing that different terminal
reciprocal profiles are not required for the nonselection result.
