# G154 lay report

The network gave us one clean refusal and one durable conditional result.

The normalized composition rule does **not** choose a fixed `X_max` scale. Our first proof appeared
to do so only because it started by putting one fixed scale into the dimensionful rule. If we
separately declare that one-scale rule, then the scale cannot change inside it—but that is a
consistency result, not a derivation of Nature's rule.

But that does **not** tell us how sharply the universe approaches the limit. Think of several cars
all approaching the same destination. They can coast gently to a stop, arrive with finite speed,
accelerate violently, or oscillate while getting arbitrarily close. The endpoint alone does not
specify the manner of approach.

Here the hidden control is the metric's common scale—the part measuring the absolute size of the
local clock/ruler frame that terminal reciprocal imbalance does not see. We held the reciprocal
position curve and `X_max` exactly fixed and changed only that common scale. All four approach
patterns survived.

So the failed claim was not papered over. `dX_max` remains a live part of the general exact
differential unless a fixed-scale family is independently justified. We also located the remaining
hole more precisely: the metric still needs to own the common-scale/history rule that tells both
how the scale is carried and how reciprocal depth changes relative to a normalized ruler or clock.

That missing rule is now suitable for a cold external review starting from the metric. More local
endpoint algebra will not choose it.
