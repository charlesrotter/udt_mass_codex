# Parent-found decision-scope precision issue

This issue was raised by the parent after DIRECT_REVIEW_SEAL.json. It is not
independent reviewer discovery. The original candidate and direct review remain
preserved; this addendum controls their bundled statement of physical gates.

INITIAL_CANDIDATE section8 bundles an independently justified population,
comparison-clock protocol and state/metric variation rule as requirements for
using u_M as the actual comparison assignment. Read literally, the last
requirement is too broad. The pointwise theorem already assigns u_M to supplied
(g,nu), and on a suitable region smooth data supply the flow. With specified
clocks/endpoints and a regular query, fixed-geometry conditional comparisons
can proceed without deciding how the population changes under an off-shell
metric variation. Physical interpretation still needs population provenance
and a justified identification of clocks with the chosen flow, but it does not
need a response law merely to evaluate those comparisons.

A state/metric continuation rule is needed if the claim is a metric response of
those data, such as L1's full first variation and its identification with the
response constrained by DDR. INITIAL_CANDIDATE section7 correctly places that
requirement in the variational setting. A dynamical population prediction would
likewise need whatever transport/state information its separate claim invokes;
that is not imposed as a prerequisite for a supplied fixed-geometry readout.

The smallest repair is a controlling REPAIR.md that splits section8's gates:
(1) supplied population plus justified observer/clock identification and regular
query for fixed-geometry comparisons; (2) full state/query/measure continuation
under g variation, differentiability and the requisite response representation
for L1/DDR response claims. No equation, population theorem, raw-moment
obstruction, CCR1 limit or existing physical premise changes. No further exact
algebra run is justified by this prose-scope correction.

DIRECT_REVIEW.md's physical-seam assessment remains valid for the response
claim, but its endorsement of the decision brief did not flag this overly
bundled prerequisite. Final review must verify the controlling repair and central
wording explicitly preserve conditional fixed-geometry comparisons without
requiring local-response selection first, consistent with central R17/R18.
