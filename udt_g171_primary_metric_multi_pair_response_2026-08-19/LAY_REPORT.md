# G171 lay report

The metric does not give observer B one permanent dial reading that must be reused in every
comparison. It gives B a reading **as part of the complete B-with-A comparison**, and another
reading as part of the complete B-with-C comparison.

That is not extra machinery. It is what happens when the same metric is applied to two different
pair geometries—like one instrument participating in two different chords.

For each chord, the rule is simple:

```text
directed pair response = far-end reading - near-end reading.
```

Play that same chord backward and the sign reverses automatically. But three separately built
chords do not have to add like points on one straight ruler. They add only when their shared
endpoint readings actually match. In the general angular, directional pair network, they need not.

The exact test held the metric, event, observer clock, and radial components fixed and changed only
the angular participation of the second pair. The endpoint reading changed. That demonstrates that
the orchestra is already in the metric pullback; no calibration-carry machine needs to be bolted
onto the kernel.

What remains open is which complete pair germs are physically realized across the universe—not how
to invent another scalar rule for them.
