# General-screen complete-cell atlas

Exact stationary off-shell geometry for the full invertible `2 x 2` angular screen on the registered
complete twisted `S3` control.

Read in this order:

1. `AUDIT_REPORT.md`
2. `LAY_REPORT.md`
3. `EXACT_DERIVATION.md`
4. `STATUS_LEDGER.tsv`
5. `PREMISE_LEDGER.tsv` and `COMPLETENESS_MAP.md`
6. machine-readable atlases and verification records

This package does not select a UDT action, source, carrier, boundary, density, scale, matter state,
or physical branch.
