# Completeness map

| Axis | Covered here | Not covered |
|---|---|---|
| Fields | Founded reciprocal pair plus every smooth invertible `2 x 2` screen coframe and all three spatial first jets | Direct pair-screen metric off-blocks, independent matter, generic ten-component metric |
| Action | None | Every action and variation domain |
| Equations | Off-shell identities only | Native field equations and on-shell selection |
| Domain | Global stationary `R x S3` control | Time dependence and actual joined metrics for other completions |
| Boundary | Compact boundaryless `S3`; explicit descent/join requirements for all FC classes | Unsupplied caps, seams, boundaries, and their functionals |
| Topology | Constructive `S3`; all twelve FC labels retained | No topology selected; most FC classes lack actual metrics |
| Dynamics | Stationary first-jet response | `E0(P)`, evolution, characteristic data, persistence |
| Branches | Both determinant components, polar strata, slice-sign strata, and det-zero boundary | Unregistered full-spacetime branches |
| Stability | Explicitly not tested | All spectra and nonlinear persistence |
| Regime | Smooth finite `phi`, smooth `P in GL2`, nonzero `kappa`, block-screen `S3` family | Matter, singular limits, different complete coframes, physical selection |

The package is full only relative to this bounded configuration family. It is not a completeness
claim for UDT.
