# Regression root cause and durable fix

The failure was semantic source selection, not tensor algebra.

1. The July 26 degree-of-freedom audit froze an older seven-branch configuration atlas but omitted
   the later July 25 source that had already settled founded `phi`'s identity.
2. The older atlas correctly contained an independently varied scalar as a chosen exploration
   branch. The new audit read that branch as a coequal possible native ontology.
3. “The physical `phi` profile/assignment/extension remains open” was then allowed to blur into
   “what `phi` is remains open.” Those are different claims.
4. Strong local CSN was retained as an easy arithmetic sensitivity branch without a sufficiently
   strong operational warning that it is a challenged owner postulate and inactive.
5. Startup controls routed through the global-local frontier but not the later source-specific
   founded-`phi` and CSN corrections. There was no machine-readable current premise registry to
   make a stale source fail closed.

The durable repair has four layers:

- `CURRENT_SCIENTIFIC_PREMISES.tsv` records 16 high-risk meanings, statuses, allowed uses, open
  scopes, forbidden regressions, and controlling evidence.
- all nine startup/navigation controls route through that registry after `LIVE.md` and `HANDOFF.md`;
- the full frozen 754-path candidate universe is individually dispositioned, while six exact older
  ambiguities receive path-specific supersession rows; and
- both the corrected DOF verifier and the repository-level semantic verifier exercise mutations
  that try to revive every forbidden promotion.

This cannot make future reasoning infallible. It changes the failure mode: an instance must now
either honor the current source hierarchy or trip a visible verification error. Terms outside the
16-row universe still require a new source audit rather than analogy or conversational memory.
