# G180 lay report

The local reciprocal kernel now joins into one smooth measuring tape along any supplied regular
observer-pair family. No new formula or fitted coefficient is needed between neighboring points.

The angular orchestra is not turned off. It changes how quickly the completed tape accumulates as
the pair moves through the metric. That changes which areal radius corresponds to a given physical
separation. Once the tape has been built, the reciprocal clock/ruler depth is simply the metric's
`phi` evaluated at that mapped radius.

So the old picture—add an angular correction to an already computed depth—was the wrong placement.
The cleaner picture is: the whole metric builds the tape first; Reciprocity reads the depth on that
tape. A common metric scale is heard too, rather than canceling out.

What remains open is which complete observer-pair family Nature realizes and how regular families
join through global or singular regions. This result does not yet make an observational fit.
