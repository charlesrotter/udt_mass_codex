# Exact derivation — UDT joint-realization closure

This is a type and source theorem about the registered record. It does not derive a new UDT
equation, boundary, action, carrier, or solution.

## 1. The quantifier that must close

Let `U_full` be the still-partial complete finite-cell configuration space. For one candidate
configuration `u`, let `r_s`, `r_t`, and `r_a` be its restrictions to the registered static,
time-live, and angular-live response modules. Let `L_t` and `L_a` test whether the two live sectors
are genuinely nonzero. A native whole-system problem is typed as

```text
Pi_native = (E_native, B_native, P_compatible),
```

where `E_native` is a complete equation or equivalent response operation, `B_native` is its
differentiable finite-cell boundary/corner/completion operation, and `P_compatible` is one premise
assignment. The required realized set is

```text
R_live(Pi_native) = {
    u in U_full :
    r_s(u) in M_s,
    r_t(u) in M_t,
    r_a(u) in M_a,
    L_t(u) != 0,
    L_a(u) != 0,
    E_native[u] = 0,
    B_native[u] = 0
}.
```

The question is whether the frozen record supplies one `Pi_native`, one compatible `u`, and proofs
that `u` belongs to this set. This is a pullback/fiber-product condition over one whole object. It
is not a literal intersection of response-module coordinate lists.

## 2. What the registered modules establish

The source anchors in `SOURCE_ANCHOR_LEDGER.tsv` establish four distinct facts.

1. Route-A Slice 2 and Slice 2b contain exact stationary solutions in their declared reduced
   scopes. Slice 2b explicitly stamps `time-live OUT`.
2. T2 supplies an exact pointwise time-live module but explicitly says that no response law is
   selected and no solve is performed.

   angular-live on-shell coexistence unproved.

Therefore the true registered quantifier is of the form

```text
each formal module has exact members and recovery maps,
```

not

```text
there exists one u in R_live(Pi_native).
```

The latter does not follow from the former.

## 4. Exact finite-set controls

These controls establish logical non-implications only.

### Separate live sectors

Take `U={z,t,a}`, with `L_t={t}` and `L_a={a}`. Both live sets are nonempty, but

```text
L_t intersect L_a = empty.
```

Separate time and angular existence therefore does not establish one common field.

### Static zero mode

Let `z` pass all formal restrictions, equation, boundary, and premise checks, while
`L_t(z)=L_a(z)=0`. It passes structural compatibility but fails the preregistered live gate. Thus
mode-zero recovery is an exact regression control, not a live witness.

### Equation/boundary mismatch

Take two live fields `p,q`, with the equation zero set `{p}` and the boundary zero set `{q}`. Both
sets are nonempty, but their intersection is empty. A live field, equation, and boundary can each
exist separately without forming one solved boundary-value problem.

### Premise splice

On premise branch `A`, supply the time and equation clauses but not the angular and boundary
clauses. On incompatible branch `B`, supply the complementary clauses. The union of the prose
clauses looks complete, but neither premise assignment passes. This is why conditional action,
carrier, reading, posture, and completion branches cannot be merged.

### Problem without a witness

On `U={0,1}`, let the equation and boundary vanish only at `0`, while the live predicate holds only
at `1`. A well-typed problem exists but its live solution set is empty. Deriving a future action or
whole-system equation would still leave existence to prove.

## 5. The minimum missing certificate

The smallest complete evidence object for the present question is

```text
JR_CERT_NATIVE = (
    Pi_native,
    u,
    proofs that all three restrictions hold,
    proofs that both live predicates are nonzero,
    proofs that E_native[u]=0 and B_native[u]=0,
    proof that one premise assignment owns every clause
).
```

This is a certificate type, not a proposed physical law. An action could produce parts of it, a
bootstrap closure could produce parts of it, or a different metric-native whole-solution operation
could produce it. The audit does not privilege one packaging.

Each component is load-bearing: deleting common field identity permits the separate-sector false
positive; deleting liveness admits the zero mode; deleting the equation or boundary admits the
disjoint-zero-set control; deleting premise compatibility admits the branch splice; and deleting
the witness turns problem definition into an existence claim.

## 6. Bounded theorem

Within the exact 140-source preregistered universe,


This is not a theorem that no UDT joint realization exists. It says that the current registered

adoption are not authorized by this result.
