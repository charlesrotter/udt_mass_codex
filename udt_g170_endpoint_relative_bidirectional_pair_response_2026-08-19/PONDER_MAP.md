# G170 ponder map — subtract the endpoints before judging reversal

Date: 2026-08-19

## Hidden-in-plain-sight candidate

The original terminal reciprocal-`c_E` work already distinguished an endpoint density from an
ordered pair depth:

```text
endpoint X:  Phi_X=(1/2) log(L_X/T_X)
ordered pair: delta_AB=Phi_B-Phi_A
```

G169's flat surface witness obtained the same nonzero `Phi` at both ends and treated both values as
directed arrow depths. Under the earlier endpoint-relative rule, the same witness instead gives
`delta_AB=0` and `delta_BA=0`, which is exactly reciprocal.

## What is being tested

```text
one metric + one observer-pair endpoint dataset
    -> complete pullback h_A and h_B
    -> terminal q_A and q_B after each full orchestra is assembled
    -> relative q_AB=q_B/q_A
    -> delta_AB=-(1/2)log(q_AB)
    -> reversal by swapping A and B.
```

No ontological co-presence statement appears in this chain. The pair is an input to the evaluator,
as endpoints or an experimental setup are inputs in ordinary metric physics.

## Discipline

This is not permission to call `abs(delta)` a positive metric-space distance. It tests whether the
directed reciprocal response is already derived. The complete pair response remains richer than
its scalar depth, and nonmatched multidirectional triangles remain outside one-dimensional scalar
composition.
