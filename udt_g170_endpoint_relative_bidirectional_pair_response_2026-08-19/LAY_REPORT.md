# G170 lay report

We had accidentally compared the wrong things.

Each end of an observer pair has a complete metric response—a chord played by the full local
orchestra. That endpoint chord is not yet the directed separation. The directed reciprocal depth
is the difference between the two endpoint chords.

If A reads 3 and B reads 5, the A-to-B change is `5-3=2`. Looking from B to A uses the same numbers
in the opposite order: `3-5=-2`. No second law is needed to command the sign change.

G169's supposed counterexample gave the same nonzero endpoint reading at both ends. It called those
two equal readings the two directed depths and complained that they had the same sign. But the
actual endpoint difference is zero in both directions, so reversal works exactly.

The angular sector is not discarded. It helps determine each endpoint chord before the two are
compared. What remains separate is the richer orientation and transport memory that one scalar
cannot carry.

There is one important boundary: A and B must be readings on the same calibrated tape. If two
experiments independently move the zero of reciprocal depth, subtracting their numbers does not
repair that mismatch. A lawful calibration carry is still needed before those experiments can be
joined.

Co-presence played no mathematical role. The two observers are simply the arguments supplied to
the metric calculation, much as ordinary physics supplies the events or objects it wants to
compare. That does not make the metric choose which events belong to one experiment.
