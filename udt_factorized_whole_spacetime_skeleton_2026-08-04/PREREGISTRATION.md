# Factorized whole-spacetime skeleton — preregistration

Date: 2026-08-04  
Branch: `grok`  
Mode: Phase A, CPU-only sparse symbolic audit; no solve

## Whole question

Can the UDT structures already established in tracked post-July evidence be assembled into one
factorized, four-dimensional configuration skeleton in which every object, degree of freedom, gauge
action, identity, conditional equation and missing physical law has an explicit type and provenance?

This phase asks whether the existing pieces form a coherent mathematical arena. It does not ask which
configuration is the universe, which action is correct, whether matter emerges, or whether a selected
branch agrees with observation.

## Frame and bounded regime

- **Metric-led:** yes. The construction begins with the founded reciprocal pair and the audited
  complete-coframe extension class.
- **Whole frame:** the typed complete configuration, including local coframe blocks, observer/event
  comparison, connections, charts, transitions and global completion slots.
- **Bounded reductions:** the registered reciprocal two-slot action, spectator/no-mixing extension,
  stationary physical-comparison branch, and stationary general-screen branch are used only as
  exact reduction checks.
- **Excluded:** native action search, native response derivation, time-live evolution, boundary
  selection, bootstrap scans, `Xmax` evaluation, matter/carrier/source work, GPU work, and global
  polynomial elimination.

## Premise ledger

### Pinned by current UDT evidence

- `phi` is the founded additive logarithmic depth of the reciprocal clock/ruler pair.
- The reciprocal two-slot action is `diag(exp(-phi), exp(phi))`.
- The complete triangular coframe extension has seven pointwise extension directions before
  optional restrictions.
- Metric/coframe, Cartan, observer-comparison and chart-transition identities retain the statuses in
  their controlling audits.
- `c_E` and `G_obs` are observed calibration anchors, not dynamical selectors.

### Free and represented, not selected

- `phi` profile and causal type;
- angular generator/screen shape and gauge representative;
- reciprocal-angular mixing variables;
- connection and transition representatives consistent with identities;
- chart cover, topology, seam/seal/boundary posture and global completion family;
- observer/event arrows and physical path-family data outside the stationary bounded branch.

### Conditional or comparison-only

- stationary Killing comparison;
- EH and `C^2`/Bach equation lanes;
- `S^2` carrier and `L2+L4` Hopfion branch;
- SNe/GR/BAO/CMB readouts.

### Forbidden silent premises

No strong local CSN, preferred frame, selected carrier, round angular section, no-mixing condition,
stationarity, spherical symmetry, field equation, action, source, boundary condition, bootstrap
return map, density value, or desired physical branch may be promoted into the parent skeleton.

## Preregistered checks

- Every object and symbol identity is unique and has a tracked controlling source.
- Each skeleton slot is exactly one of `DEFINED`, `IDENTITY_CONSTRAINED`,
  `CONDITIONAL_EQUATION`, `OPEN_LAW_SLOT`, or `OBSERVATIONAL_ANCHOR`.
- The seven complete-coframe extension directions are explicitly accounted for and are not called
  propagating fields.
- Gauge freedoms are separated from physical degrees of freedom and unresolved selection.
- No conditional equation appears as a native UDT law.
- The sparse block construction exactly reproduces the reciprocal two-slot action and the registered
  determinant/no-mixing reductions without global component expansion.
- Each reduction is labeled as a consistency check rather than a parent-theory selector.
- Catch-proofs reject a missing or duplicate slot, a promoted conditional action, an `S^2` carrier
  promotion, an active strong-CSN assumption, a hidden stationarity/no-mixing restriction, and a
  time-live equation with no native law.

## Certification and falsification

The construction fails if the controlling audited structures cannot be embedded into one typed
factorized object without contradiction, if a necessary slot lacks provenance, or if a claimed
reduction requires an undeclared physical assumption.

A successful return establishes only that the current derived geometry admits a coherent factorized
configuration skeleton and identifies its empty law slots. It does **not** derive a native action,
response, evolution, boundary completion, bootstrap theorem, `Xmax`, source, carrier or mass.

## Resource contract

- CPU only; no long-running process.
- Sparse matrices, block determinants and exterior-form identities only.
- No Gröbner basis, global polynomial expansion, ODE/PDE solve or numerical scan.
- Expected runtime under one minute and negligible RAM. Exceeding that limit is an operational design
  failure, not a scientific result.
