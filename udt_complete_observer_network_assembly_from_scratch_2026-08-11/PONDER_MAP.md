# Ponder map — gears versus assembled machine

G61 showed that the regular local coframe supplies ten independent geometric controls. That is a
statement about the available parts, not automatically about the relations among every observer's
use of those parts.

The possible assembly joints are:

1. object-state differences (`Delta kappa`, `Delta phi`);
2. shift/query state (`beta`);
3. path-labelled angular transport (`U_gamma`);
4. complete coframe or non-isometric comparison arrows;
5. causal-order preservation/reflection;
6. terminal reciprocal calibration by `c_E`;
7. direct-versus-composite triangle closure;
8. four-observer loop/tetrahedral coherence.

The main danger is to demand a flat machine because flatness would generate an equation. UDT's
banked path/holonomy structures explicitly permit route information, so the audit must first ask
whether route independence is owned. Conversely, merely declaring every edge independent would
avoid the assembly question. Both endpoint-state and path-labelled realizations must be built.

The decisive contrast is therefore not local versus global in the abstract. It is:

- identities required for any correctly typed assembly;
- nontrivial holonomy or route data allowed by the assembly;
- additional conditions that would actually select histories;
- which of those conditions UDT presently owns.
