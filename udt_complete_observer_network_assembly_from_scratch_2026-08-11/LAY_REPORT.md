# Lay report — the gears assemble, but the machine may remember its route

The pieces are not lying loose after all. They assemble in two coherent ways.

If every observer is reading one shared calibrated map, going A→B→C gives exactly the same frame
change as going A→C. This remains true no matter how the complete geometry changes with time. It
is like assembling meshed gears from one common axle: their matching is automatic.

If comparisons carry the route through the angular/global geometry, the machine can remember which
route was taken. Going around a loop may rotate the angular readout or return a different reciprocal
calibration. That is holonomy—lawful geometric memory, not a broken gearbox.

With four observers, the loop memories obey a bookkeeping identity automatically—much like every
closed accounting table balancing. It confirms that the pieces were assembled consistently, but it
is not a new law and still does not dictate how the machine must move.

A genuine selecting equation appears only if UDT says that physical comparisons must forget every
route and depend solely on their endpoints. That would force the relevant holonomies to vanish.
The current foundations do not yet say this universally, and some banked geometry explicitly keeps
path memory.

So the narrowed missing conceptual joint has two parts: which complete observer-to-observer
relation is physically the machine in the first place, and then whether that relation is
endpoint-only, remembers a path, or treats some path differences as equivalent.
