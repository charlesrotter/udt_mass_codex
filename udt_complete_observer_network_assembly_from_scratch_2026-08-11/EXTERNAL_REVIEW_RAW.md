**Evidence**
- Scalar `K4`: if `delta_ij = phi_j - phi_i`, then `delta_ij + delta_jk - delta_ik = 0`. If `e_ij = -e_ji`, then `omega_ijk = e_ij + e_jk + e_ki` and `omega_123 - omega_023 + omega_013 - omega_012 = 0`. This is exact combinatorics, not physics.
- Typing: additivity is only on matched enriched states/common family. Arbitrary separately rebuilt pair surfaces need an explicit middle morphism `M_B`; otherwise `J_BC J_AB` is not even the right typed composite. This is exactly the G40 correction: [G40 derivation](/tmp/udt_g62_review_sQ1Fy7/sources/udt_three_observer_overlap_calibration_carry_audit_2026-08-10/EXACT_DERIVATION.md:97).
