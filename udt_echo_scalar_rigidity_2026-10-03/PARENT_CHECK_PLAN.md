# ESR1 parent verification design

This exposed check follows the initial candidate and brief independent reviewer
concordances. It is not a blind discovery or a fit. One script, three families:
(1) exact arbitrary-Q derivative/zero-leading/reversal algebra from IEC1's
reviewed p/q coefficients; (2) original signed-curvature first and actual-return
incidences, exact endpoint identities plus16 direct80-digit root cases and a
separate flat control; (3) explicit unused-side smooth-Q freedom, with six finite
values supplementing its analytic flat-function proof. At most30 scalar cases;
no matrix classification is inferred from this finite list.

All symbolic identities must vanish exactly. Numeric original-incidence residuals
and p/q comparisons require absolute error<1e-65, with actual future b>0,a>b,
positive p,q and p<sqrt2. Signs κ=±1,±9/4 and L=1/20,1/10,1/5,2/5 are
FREE-AND-EXPLORED controls; the chosen largest positive κL² still lies within
the direct echo sector. Failed roots/checks are preserved, not filtered out.
The incidence is generated from metric quadric data, never from Q. Null first
and return roots are solved separately before comparison. No original-equation
residual is replaced by a preconditioned quantity.

Use existing capture.py:2GiB virtual memory, one BLAS thread, no elapsed/CPU
timeout. Finite symbolic degree and40 Newton iterations/case are numerical
stops, not physical assumptions. No GPU, data or long solve. Preserve candidate,
script, plan and source hashes before execution; reviews inspect the actual
proof and returned outputs. Both reviewers independently chose curvature-rank
checks; this parent check instead covers original proper-clock incidences.
