# G311 ponder — what “full covariance” can and cannot supply

Date: 2026-09-01

The likely simplification is that two questions have repeatedly been mixed together.

First: does reciprocity constrain the complete metric rather than one radial diagram? Yes, if every
possible local observer/ruler orientation is included. In ordinary local Lorentz geometry those
orientations can be realized as nearby observer-pair germs. Their reciprocal changes cover every
way to alter metric shape while preserving the common clock/ruler volume.

Second: which curvature-response operator is being balanced? Reciprocity can force the shape part
of that operator to vanish. It cannot, by grammar alone, decide whether the operator is the first
curvature response classified by G301 or a different higher-order/nonlocal object. The favorable
G301 branch is physically well motivated by the quiet GR limit, universal metric coupling, absence
of an owned vacuum length, and a nondegenerate local principal response, but those links must be
audited rather than silently promoted.

If the conditional G301 branch survives, “history” changes meaning. The field equation would define
the space of lawful evolving metrics. Initial data would choose one member, just as initial
conditions are required by any dynamical theory. Failure to select one unique universe would no
longer be a missing field law. The remaining scalar curvature datum and initial data would be
legitimate state data to constrain independently, not an arbitrary fitted function for `phi`.
