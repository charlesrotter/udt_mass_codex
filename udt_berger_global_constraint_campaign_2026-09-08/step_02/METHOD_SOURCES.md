# BG2 imported mathematical methods

Scientific inputs remain the exact repository sources and reviewed conditional
BG1/BI1 candidates with ENTIRE reviews. The methods below are mathematical
tools, not a metric law, carrier, physical cutoff, selected frequency or scale.

- Richard Melrose, *Lectures on Pseudodifferential operators*, MIT18.157,
  revision29-Nov-2006, Proposition18/equationL9.1, printedpp81--82:
  https://math.mit.edu/~rbm/18.157-F05.pdf . An elliptic operator on a compact
  smooth manifold has a generalized inverse of opposite order, with smooth
  finite-dimensional kernel projections. Apply to the already checked
  self-adjoint order2 P=div L, using its actual kernel complement. No inverse
  on the kernel, boundary parametrix, index theorem or physical action is used.
- Semyon Dyatlov, *Pseudodifferential operators and elliptic regularity*,
 15-Apr-2010, section3, especially(Alg),(Symb),(Diff), printedpp7--9:
  https://math.mit.edu/~dyatlov/files/2010/psdoer.pdf . Orders add under
  composition; leading symbols multiply; local oscillatory evaluation extracts
  the leading symbol. The argument uses smooth finite-rank bundles and a
  compact boundary-free manifold. Lower-order/smoothing terms cannot make an
  operator with nonzero leading symbol vanish. No PDE discretization involved.

checks only the finite symbol and tensor identities; functional existence and
