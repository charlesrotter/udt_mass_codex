# Complete-branch founded-pair pullback audit — preregistration

Date: 2026-07-26

Base: `75b13ca7e7ea1be81dc4346d742322905fc123ce`

## Whole question

Do any already registered complete finite-cell metric representatives supply, without cross-branch
splicing, a smooth metric-selected founded clock/ruler pair `(u,n)` throughout their regular domain
and reduce the complete 22-dimensional first-jet one-form vocabulary to a globally compatible
closed and normalized founded-depth line?

This is a metric-led pullback and availability audit. It is not a search for a branch that produces
a desired answer.

## Frozen candidate universe

The audit keeps three source categories distinct:

1. all twelve `FC01`–`FC12` registered completion classes in
   `COMPLETION_CLASS_REGISTRY.tsv`;
2. every concrete configuration in `CORRECTED_CONFIGURATION_REGISTRY.tsv` and every branch in
   `BRANCH_COCYCLE_ATLAS.tsv`; and
3. the 22 one-form basis elements frozen by the immediately preceding first-jet atlas.

A parametric topology/completion rule is not counted as a complete metric representative unless the
source records an actual globally defined metric profile with its domain and joins. A complete
off-shell configuration remains off shell. A local metric remains local.

## Pinned and free inputs

- Metric and branch formulas: `pinned-by-THEORY` only at the exact conditional or observed status
  recorded by the frozen sources.
- Pair `(u,n)`: `free-and-explored` when a branch admits choices; `pinned-by-THEORY` only if the
  metric and registered UDT premises intrinsically distinguish both lines.
- Screen orientation and ruler sign: `free-and-explored`; no supplied orientation or sign may be
  smuggled into a founded conclusion.
- First-jet vocabulary: `pinned-by-THEORY` to the complete bounded 22-form atlas for a supplied
  orthonormal pair.
- Boundary, seam, cap, cut-locus, and chart transitions: `pinned-by-THEORY` only when the concrete
  representative supplies them; otherwise `OPEN`.
- Action/on-shell status: retained exactly from source; no action is adopted by this audit.
- `c`: retained as the registered observational calibration anchor; it does not select a pair or a
  branch in this audit.
- Carrier, source, density, bootstrap functional, `G`, physical scale closure, and `Xmax`:
  excluded and not inferred.

## Required branch gates

For each candidate record:

1. whether an actual complete four-dimensional Lorentzian metric representative exists;
2. whether its global domain, joins, axes, seals, caps, cut loci, and causal-type changes are given;
3. whether a smooth global unit timelike `u` is supplied;
4. whether a smooth global orthogonal unit spacelike `n` is supplied and metric-selected rather than
   arbitrarily chosen;
5. which of the 22 motifs survive for every intrinsically allowed pair or for an explicitly stated
   conditional pair;
6. rank of the realized motif span and exterior derivatives;
7. whether a nonzero closed line is global, exact or period-bearing, and chart/seam compatible; and
8. whether its normalization and identity as founded reciprocal depth are derived.

- Recompute the round ultrastatic `S^3` control with both an arbitrary Hopf pair choice and the

- Distinguish existence of some global vector field from metric/UDT selection of that field.

## Certification and falsification contract

The production implementation will reconstruct the candidate universe and exact homogeneous-frame
algebra. An independent implementation must recompute the representative counts, intrinsic-line
gates, surviving motifs, closure, exactness, and global-status rulings without importing production
code or its generated outputs. Every catch in `FALSIFICATION_CONTRACT.tsv` must be exercised.

If no registered representative passes all eight gates, return
`NO_REGISTERED_COMPLETE_PULLBACK_WITNESS`. Do not proceed to arbitrary higher jets or invent a
connection.
