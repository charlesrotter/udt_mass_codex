# Exact relational fixed-point architecture

## 1. The relational correction survives

UDT's founded reciprocal object is naturally attached to an ordered observer/ruler comparison. The
corrected pair-frame path groupoid proves that one global ruler field is not required for kinematic
composition. Each typed path arrow may carry its own ordered pair, with explicit vertical changes
when the outgoing pair differs from the incoming one.

This means the recent failure to find one globally selected smooth `(u,n)` field is not itself a
failure of relational UDT. It rules out a stronger absolute-field shortcut.

## 2. The complete forward chain

Given a complete metric and a typed path, the metric supplies distance, endpoint directions,
Levi-Civita transport, Jacobi transport, and path holonomy. Independently, the founding postulates
supply the abstract additive reciprocal coordinate and its inverse-exponential action.

Given additionally:

- a complete lift `X_lambda(u,n)`;
- a signed additive depth `delta_gamma`; and
- explicit vertical pair changes;

the full pair comparison composes and reverses exactly on the typed path groupoid. This is a strong
kinematic capability. It does not derive the missing inputs.

## 3. Why the two missing “one-forms” are not one object

The signed depth has type

```text
delta : typed path arrows -> R,
delta(gamma2 compose gamma1)=delta(gamma2)+delta(gamma1).
```

It is odd under arrow reversal and supplies a kinematic comparison coordinate.

The off-shell response has type

```text
alpha_X : T_X C_complete -> R.
```

It is linear in an admissible variation of an entire field-plus-boundary configuration and would
supply equations or, after further integrability tests, an action differential.

Their domains, arguments, linearity laws, and roles differ. Calling both “one-forms” does not give a
canonical isomorphism. Current UDT supplies no map from path arrows to configuration variations or
pairing that identifies them.

A future same-solution closure could couple them—for example, a global solution could determine a
depth law while that law participates in the configuration response. Coupling does not make them
the same mathematical object.

## 4. Why there is not yet a fixed-point operator

A genuine bootstrap fixed point requires either a self-map

```text
B : C_complete -> C_complete
```

or a fully defined equivalent zero problem on the same complete configuration domain.

Current evidence lacks:

1. the selected complete founded extension and variation domain (`E07`);
2. the metric-native signed depth assignment (`E05`);
3. the off-shell global-local response (`E08`); and
4. a comparison-to-metric reconstruction/feedback map (`E16`).

The current bootstrap is an after-solution admissibility hypothesis. It is not an off-shell update
map. Consequently “global-local fixed point” is a coherent architectural lead, but no actual
fixed-point operator has yet been derived.

## 5. Exact independence controls

The registered controls separate the arrows:

- B19: conditional complete geometry with trivial clock—complete geometry does not imply depth or
  response.
- Squashed `S3`: complete off-shell geometry and a metric-selected angular line with trivial
  clock—angular structure does not imply depth or dynamics.
- WR-L: nontrivial local clock profile without complete all-observer geometry—local depth does not
  imply global completion.
- Conditional Hopf prototype: nontrivial topology with supplied weights, phases, and caps but no
  response—topology does not imply matter or feedback.
- Pair path groupoid: exact composition given inputs but no selection of those inputs or reverse
  response—kinematic closure does not imply dynamical closure.

These are countermodels to shortcut implications, not pieces that may be spliced.
