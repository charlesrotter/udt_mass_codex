# Lay report

We found the exact mathematical shape of the next joint, but not a law choosing it.

Imagine the already-derived reciprocal clock/ruler pair as a two-gear transmission inside a
four-part machine. If we require the whole machine to preserve those two gears exactly, the metric
forces a one-way block structure: the other two directions may respond to the clock/ruler pair, but
they cannot feed back into what the quotient calls the founded pair.

That condition alone still permits eight arbitrary functions. If we additionally require the whole
four-part transformation to compose with depth exactly as the founded pair does, those functions
collapse to eight fixed generator numbers.

The metric's first change can see seven of them. The eighth is a rotation of the two-dimensional
angular screen. The earlier seven-parameter triangular construction had silently chosen an angular
flag—rather like choosing which way is “up” on a round dial—to remove that eighth number.

The subtle finding is that the missing rotation is not always harmless. On a perfectly isotropic,
unmixed angular screen it only spins the coframe and leaves the full metric unchanged. If the angular
screen is anisotropic, or if it mixes with the clock/ruler pair, that same rotation changes the
metric at the next derivative. So it is generically real finite metric information, not a gauge
artifact, even though the first derivative cannot see it.

What remains missing is now sharper: UDT has not yet told us that the complete coframe must be this
quotient representation, which seven-component metric response is realized, or what fixes the last
screen rotation/global flag. Nothing here selects an action or matter law.
