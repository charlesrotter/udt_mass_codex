# G240 lay report

Suppose one distant galaxy can reach us along several different light routes. Earlier work left a
free choice: how much importance should we assign to each route?

G240 tests the cleanest metric-native answer: do not choose a favorite route. Count every regular
image that the supplied metric actually produces, once. Under that rule, the metric automatically
determines both how many images appear in each sky direction and which image pairs share the same
parent. Those sibling pairs can create an observed pattern even when the parent galaxies are
otherwise randomly distributed.

This removes one possible layer of scaffolding—arbitrary branch weights—but only conditionally. We
have not proved that every physical detector sees every image, nor chosen the universe's evolving
metric, galaxy population, transfer physics, or treatment of caustics. No BOSS result has been used.
