# G299 map — complete relation versus pair-query projection

Date: 2026-08-29

## Whole question

G298 derives, from one supplied regular directed null leg, a complete path-labelled relation state
`R_gamma` and at least two natural gauge-inequivalent rank-two pair one-jet projections. Does an
active UDT premise require one projection to be the physical kernel input, or does it already type
the richer relation state as physical while rank-two germs remain query projections?

The bounded factorization under test is

```text
supplied metric + observers + regular directed route
    -> complete path-labelled relation state R_gamma
    -> typed query projection pi_q(R_gamma)=J_q
    -> complete pullback h_q=J_q^T g J_q
    -> W1 terminal and other typed outputs.
```

## Frame

- **Observing, not targeting:** census what F1--F4, W1, W4, W5, G269, G274, G297, and G298
  actually own. No desired projection is assumed.
- **Metric-led:** every state, transport, projection, and pullback must be constructed from the
  supplied metric relation. No template pair plane is imported.
- **Bounded regime:** regular directed null legs with active screen carry and regular rank-two
  endpoint projections. Singular/caustic strata, route population, history dynamics, scale,
  observations, matter, sources, and `X_max` are excluded.
- **No solve:** this is an exact ownership/factorization audit, not an ODE, PDE, or GPU calculation.

## Exact distinction

The question is not whether `J_T` and `J_L` are useful. Both are natural projections. The question
is which mathematical type W5 calls physical:

1. one selected rank-two germ;
2. the complete path-labelled projective relation, with rank-two germs supplied by typed queries;
3. neither, leaving the architecture open.

Scalar equality is not allowed to erase different screen/path carry.

## Maximum scope

G299 may close only the local kernel-domain architecture at the grade of the active working
premises. It may not canonize W5, populate observers or routes, select a metric history, derive a
field equation, attach an absolute distance, or determine `X_max`.
