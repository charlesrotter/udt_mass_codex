# G259 map — metric-only parent-operator fork

## Whole question

Do UDT's existing metric-native structure and provisional GR quiet-limit requirement now determine
the missing history law, or do they only narrow the possible *type* of that law?

This is `METRIC_LED` and `OBSERVING`. It does not seek an equation that fits SNe, BAO, CMB, an
`X_max`, or a desired loud-end profile.

## The fork in lay language

There are two materially different possibilities:

1. The local rule for the metric remains the GR rule. UDT's new physics then lies in how complete,
   finite-separation observer pairs read the same evolving metric, plus whatever source/history data
   populate it.
2. The local metric rule itself changes at extreme regimes. Then UDT must own additional structure
   beyond the present reciprocal representation—higher derivatives, a nonlocal relation law, an
   extra reciprocal state, or a new scale/source attachment.

The easy route would simply declare the Einstein equation to be UDT's law. That is forbidden as a
derivation. The pure route is to state the exact assumptions under which mathematical uniqueness
selects the Einstein tensor, then audit whether UDT already owns those assumptions.
