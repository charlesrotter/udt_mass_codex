# G139 lay report

The clean picture is now a map plus a compass.

For one declared physical observer-pair family, the map location is an endpoint fact: observer B's
signed position relative to observer A is the reciprocal coordinate already derived in G137. Taking
a different route does not secretly move B to a different map location.

But the compass can remember the route. Two routes to the same endpoint can rotate, shear, or carry
the screen differently. A round trip can return to the same position while returning an oriented
screen in a different direction. That is not a contradiction; position and orientation memory are
different outputs of the same complete geometry.

The orchestra has not been moved outside the kernel. Angular and mixing geometry first help build
the complete pair metric and its terminal depth. Any angular memory left after that readout travels
in its own route-labelled channel. If two routes really yield different terminal positions, they
must be named as different pair branches rather than averaged together or disguised as a rotation.

This is a substantial simplification, but it does not yet choose the universe, the realized pair
branch, the value of `X_max`, or a theory of light.
