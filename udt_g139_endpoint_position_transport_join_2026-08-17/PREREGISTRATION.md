## Preregistered construction and tests

For a route `gamma:A->B`, test the typed joint object

```text
J(gamma)=(phi_AB, xi_AB, U_gamma),
xi_AB=tanh(phi_AB),
```

where `phi_AB` and `xi_AB` descend to the endpoints of one declared relation family, while
`U_gamma` is an arrow between the route's endpoint screen fibers. For composable routes with one
matched middle calibration/fiber, test

```text
phi_AC=phi_AB+phi_BC,
xi_AC=(xi_AB+xi_BC)/(1+xi_AB xi_BC),
U_(gamma2 o gamma1)=U_gamma2 U_gamma1.
```

Test inversion and identity in each type. Test two routes with identical endpoints and identical
terminal positional coordinates but different transports. Test closed loops with zero positional
return and nonidentity transport. Test that route transport cannot change endpoint position without
either violating endpoint descent or defining a separately labelled terminal branch.

Test the converse boundary: a nonzero positional cycle can be retained only as a path-labelled
positional arrow when distinct routes remain distinct physical arrows, as classified in G138.
