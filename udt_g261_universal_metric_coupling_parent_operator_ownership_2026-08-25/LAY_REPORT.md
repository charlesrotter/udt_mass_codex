# G261 lay report

The equivalence principle helps, but it does not finish the theory.

It tells us something important and clean: UDT has one metric. The same geometry governs local
clocks, rulers, falling objects, and light. The unusual finite-distance reciprocal effects are
readouts of that one geometry; they are not a second kind of spacetime or a second speed of light.

It does **not** change the metric formula we already derived. It also does not tell the metric which
complete shape or evolution to take. Many different smooth UDT metric profiles still have perfectly
ordinary local freely falling frames.

So the gap is now sharper. We do not need another measuring rule. We need one rule saying which
complete metric histories are physically allowed. Einstein's equation is one conditional outcome
if we additionally assume a very specific minimal class of local metric laws, but that extra
minimality statement has not been adopted or derived.
