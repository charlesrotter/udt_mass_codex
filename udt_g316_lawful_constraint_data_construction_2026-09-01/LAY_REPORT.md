# G316 lay report

We now have a more practical answer to “what counts as a possible starting universe?”

The field equation does **not** let us freely draw any starting geometry and press Run. We may
choose a set of mathematical ingredients—roughly, the initial spatial shape, its distortion and
its initial rate of change—but then two coupled consistency equations must be solved. Some choices
produce valid starting data. Some choices provably cannot be completed into valid data. Some give
the same physical data in different mathematical dress.

The null/light-cone version has a similar caution. Fixing the relative normalization of the two
lightlike directions still leaves a local rescaling freedom. That rescaling is bookkeeping, not a
new physical tape measure. Information on one lightlike sheet also does not manufacture the
independent information on the crossing sheet.

So this is solid forward progress: we can construct and reject classes of candidate initial data
before evolving them. But it does not choose which valid candidate Nature uses. The metric,
reciprocal kernel, angular cancellation, and observational machinery were not changed.
