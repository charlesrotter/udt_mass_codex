# Lay report — one table leg, not three missing gadgets

We had been talking as though UDT might be missing three separate parts: a rule for variation, a
source of matter, and a bootstrap feedback mechanism. The audit finds that these are probably
different levels of one unfinished structure.

Think of the metric as describing all the pieces that could make a machine. We still need the rule
that says which complete assemblies actually operate. Once that rule exists, it also tells us which
parts are allowed to move when we test the machine. A “source” can then mean how one moving part
pushes on another, and “mass” can be a properly calibrated reading of the completed operating
machine. They need not be three extra substances bolted on beforehand.

There are two honest ways the missing rule might appear:

- **Response first:** the whole universe and its local structures must answer to one another. That
  feedback rule comes first. If it can be summarized by an action later, good—but the action is not
  assumed in advance.
- **Action first:** nature supplies a special mathematical functional first. Varying it gives the
  response, and its complete solutions realize bootstrap.

Neither order is proved. Response-first is the better next experiment because UDT already shows a
small piece of global-to-local feedback: global completion choices really change which local joins
are legal. That is not yet a working engine, but it is a physical-looking hinge already present in
the metric. Every known action-first route begins by adding rules that the foundation has not
selected.

The next test is modest. We inspect that existing hinge and ask whether it carries a genuine
directional push—a response—or merely says which boundary pieces fit together. If it carries only
boundary bookkeeping, response-first has not yet advanced. If it carries a nontrivial response, we
have found part of the missing table leg, not the whole theory.
