# P02 full-local-jet strata package

This package contains the preregistered P02-A Cartesian local two-jet atlas and
the append-only P02-B repeated-tidal Hessian-response completion.

Read in this order:

1. `PREREGISTRATION.md` and `P02B_REPEATED_TIDAL_PREREGISTRATION.md`;
2. `AUDIT_REPORT.md` and `STATUS_LEDGER.tsv`;
3. `LAY_REPORT.md` for the plain-language interpretation;
4. `STRATUM_CENSUS.json` and `P02B_CENSUS.json` for compact counts;
5. `STRATUM_LEDGER.tsv`, `P02B_CANDIDATE_LEDGER.tsv`, and the axis/causal
   censuses for row-level evidence;
6. `CPU_ANCHOR_VERIFICATION.json`, `P02B_CPU_ANCHOR_VERIFICATION.json`, and
   `P02B_PACKAGE_VERIFICATION.json` for independent computational checks; and
7. `NEXT_STEP.md` for the proposed, not-yet-authorized global map.

`JET_ATLAS.npz` and `REPEATED_TIDAL_ATLAS.npz` are the raw load-bearing
artifacts.  Neither atlas contains field-equation solutions or physical time
evolution.
