# G212 multi-agent whiteboard synthesis

Date: 2026-08-22

## Shared result

All three independent roles agreed on the central distinction:

```text
complete valued rank-sufficient pair network
    = a lawful relational representation of one metric state

reciprocity + compatibility + smooth descent
    != a generator of that network's numerical values from finite anchors
```

The rank/reconstruction result is not new; G129--G130 already established it for full calibrated
pair pullbacks. The G212 advance is to reconcile that result with G176--G211 and identify the exact
next proof obligation for the completed reciprocal kernel.

## Board positions

### Relational-state theorist

Treat the complete bidirectional pair network as the state and reconstruct `g`. This removes the
redundant idea that a second history object must be selected after the network exists. Associativity
does not select one numerical network. A finite-dimensional distance flow would require a local
jet-closure theorem.

### Anchor/completion theorist

Two generic completed clocks reconstruct `Omega,q` algebraically at one germ. A sweep reconstructs
the functions pointwise, but consumes function-valued data. Causality is blind to `Omega`; null
completeness leaves infinitely many common-scale functions. A finite number of anchors is
insufficient without a finite-moduli theorem.

### Adversarial differential geometer

An arbitrary smooth completed reciprocal family has exact reversal, composition, metric carry,
and flat Maurer--Cartan compatibility. Standard geometric identities evaluate every smooth metric
and do not select a rate. Full all-point/two-frame isotropy can force constant curvature, but that
is an additional symmetry premise and is much stronger than one-center spherical symmetry or a
universal scalar response.

## Adjudication

The whiteboard rejects both extremes:

- It rejects “UDT still needs a mysterious mechanism to choose a metric after the complete valued
  relation state is known.” That was a category error.
- It also rejects “the current kernel predicts the whole relation state from `c_E`, `G_obs`, and a
  few anchors.” Arbitrary functional freedom survives current identities.

The native path is to finish **information closure**, not invent **history selection**:

1. census the determinant-one spatial remainder;
2. build a finite multidirectional completed-pair design;
3. compute whether its full typed data have rank ten on the metric germ;
4. then extend the rank test to the minimal metric jet required for connection/Jacobi propagation.

That is the bridge from one chord to a locally complete score. It can succeed without an action,
source, fit, `X_max`, or preferred center. It will not, by itself, turn the state into a prediction
from finitely many constants.
