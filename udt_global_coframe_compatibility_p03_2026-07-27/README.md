# P03 global coframe compatibility package

The package preregisters and completes the P03-A source-availability gate.
P03-B was not launched because the registered universe contains no complete
founded `(g,phi)` finite-cell object and the frozen P03 inputs omit the detailed
P02 ledgers required for a lossless motif projection.

Start with:

1. `AUDIT_REPORT.md`
2. `STATUS_LEDGER.tsv`
3. `P03A_CENSUS.json`
4. `P03B_GATE_LEDGER.tsv`
5. `SOURCE_ADJUDICATION.tsv`
6. `NAMED_OBJECT_ADJUDICATION.tsv`
7. `INDEPENDENT_VERIFICATION.json`
