# G335 lay report

G333 and G334 found how the metric begins to change at one instant. G335 asks whether that initial
change immediately disappears or whether it extends into real elapsed time.

The answer is positive whenever the starting response is not exactly zero: smooth spacetime
evolution forces the response to keep the same sign for at least some small interval. The duration
depends on the particular starting geometry; the theorem does not supply a universal number of
seconds.

The lawful solution space has two useful kinds of starting data:

- Some data make every spatial direction initially change in the same broad sense. Because the
  starting slice is compact and the response stays safely away from zero, one small time interval
  works across that entire fixed slice.
- Other equally lawful data contain exact silent directions. The first response is zero there, so
  the next derivative must be examined. Those directions were retained, not rejected.

Observer motion still matters. If we continually adjust the measuring frame to remain perfectly
orthonormal, its displayed matrix entries can stay constant while the underlying metric is
changing. The geometry has not vanished; the change has moved into how the frame is carried.

So this is the first rigorous step from a frozen snapshot into a genuine local spacetime history.
It is not yet a full evolution, a stability result, a selected universe, a scale, or an
observational prediction.
