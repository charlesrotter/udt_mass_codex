# G116 lay report

The clock comparison and the positional tape are not two unrelated mechanisms. The same live
metric connects them.

Near a smooth central observer, the tape's direct clock-versus-ruler imbalance begins quadratically.
The comparison with a source clock can begin linearly because the source and the tape may move
relative to one another. That relative motion is the invariant `b-q`; it is not a fitted velocity.
At the next order, the same geometric quantity that focuses the angular
beam also enters the clock-frequency comparison.

Schematically:

```text
source-clock frequency depth
  = terminal positional depth
  + relative source/tape drift
  + time change of that drift
  - one quarter of the already-derived optical focusing term.
```

There is no fitted coefficient in this relation. The orchestra has not been attached afterward;
its timing, source motion, and focusing are different readouts of one metric/query construction.

On the simple stationary reciprocal branch, the drift and optical correction vanish. Then the old
simple relation returns exactly:

```text
frequency depth = terminal pair depth,
c_eff/c_E = exp(-2 frequency depth).
```

Away from that branch, using `exp(phi_pair)` as the source-frequency ratio would omit live metric
information. Adding `phi_pair` and frequency depth as two independent effects would instead count
some of the same geometry twice.

What remains open is smaller and cleaner. A declared direct frequency-measurement query canonically
reads the source/observer ratio. A positional-tape query separately reads `phi_pair`. The founding
reciprocal algebra alone does not declare that every possible physical observation must use one
universal mixture of those two readouts. No free mixing coefficient is authorized.

This is more scaffold-free locally: fewer independent knobs, more forced connections. It still does
not determine the complete history that supplies the invariant drift and focusing functions.
