# Whiteboard method

The user explicitly requested a far-zoomed multi-agent whiteboard to test whether “missing history
equation” language was itself scaffolding.

Three independent roles were used without file edits or protected-package access:

1. a foundation minimalist subtracted every optional structure and rebuilt the implication chain;
2. a global co-presence geometer tested reconstruction, recentering, overlap, causality, and compact
   bump counterfamilies;
3. an outside-box anchor theorist tested whether `c_E`, `G_obs`, causal structure, and a possible
   scale carry could reduce the residue to calibratable constants.

The synthesis was adversarial rather than a vote. A proposed simplification survived only if the
counterfamily role could not defeat it. This package records a `PONDER_LEAD`; it was not
preregistered before the whiteboard and is not an independently verified derivation.
