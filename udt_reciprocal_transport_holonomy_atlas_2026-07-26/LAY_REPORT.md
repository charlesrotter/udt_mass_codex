# Lay report

We have now answered part of the last question positively.

Once you give the metric a complete shape, the metric already knows how to
carry a clock-and-ruler frame along a chosen route. We do not need to invent a
new transport mechanism. This is like carrying a gyroscope along a road: the
geometry tells us how it turns.

The remaining difficulty appears when there is more than one route between
the same observers. Going around different routes can return the frame with a
different rotation. That difference is holonomy. It is genuine information
about the complete geometry, not automatically an error.

The calculation found three particularly clean possibilities:

- If the universe preserves a clock direction while allowing every spatial
  direction to rotate into every other, all three spatial directions must
  dilate together. This is `lambda=+1`.
- If it instead preserves one ruler direction while the clock and the other
  two directions mix together, the matching value is `lambda=-1`.
- If crossing a reciprocal seam swaps clock and ruler and reverses the whole
  reciprocal object, the two angular directions must stay spectators. This
  is `lambda=0`.

These are not arbitrary alternatives. They are three recognizable global
shapes the same local metric structure could inhabit. We have not yet derived
which global shape the UDT universe chooses.

So the advance is:

> Local frame transport is supplied by the metric. The remaining missing
> joint is the universe-wide choice of geometry, loop structure, and whether
> reciprocal reversal is an ordinary frame return or a sign-twisted return.

That is a smaller and more structural open problem than “invent a connection.”
