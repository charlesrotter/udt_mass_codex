# Lay report

We asked what kind of “road system” each already-built complete geometry actually contains.

The answer is not one universal road system:

- The richest twisted and general-screen geometries naturally support routes whose result can
  depend on the route taken. That is legitimate holonomy, not a contradiction.
- One simpler static geometry has a single clock-calibration field shared everywhere, so its clock
  comparisons depend only on the two endpoints.
- One toric structure naturally changes type: it chooses one shortest direction inside a chamber,
  but only an unordered pair at a tie wall.

Those are real structural gains. But none yet tells us which road is the physical observer-to-
observer comparison in UDT. The path system is isometric transport, the endpoint system has only
the clock half, and the toric system is a direction set rather than a complete calibrated pair.
So we have classified the surviving pieces without pretending that one piece is the finished law.
