# Scope of the full tracked-path inventory

Every baseline tracked path receives one maintenance disposition. This is not
an assertion that every file was read, every scientific result was re-proved or
every dynamic dependency was found. Default retention keeps evidence intact at
its existing address; it does not declare the evidence scientifically current.
Individually reviewed overrides own actual archival eligibility and its reasons.

| Reason | Default maintenance decision |
|---|---|
| P01 | Protected package path metadata only; never inspect or relocate payload |
| C01 | Maintained startup/navigation/registry entrypoint; keep accessible |
| C02 | Foundational/canonical source; preserve authority and bytes |
| C03 | Explicit live guarded/fixed historical root interface |
| C04 | Current method/compatibility/test interface; no execution authorization inferred |
| H01 | Already in archive; preserve historical contents and evidence |
| H02 | Existing reorganization provenance; fixed snapshots remain unchanged |
| E01 | Organized research evidence; preserve coherent provenance layout |
| E02 | Root executable/configuration; preserve runtime/path semantics |
| E03 | Root evidence/data retained unless a specific reviewed override clears relocation |
| E04 | Coherent package retained; directory name does not establish scientific grade or active status |
| A01 | Full document review plus separate dependency review clears byte-preserving archival placement |

The old ledger's status is only a recorded lookup result for known baseline paths.
ROOT_RETAINED is not automatically a present relocation prohibition. Actual
current executable/authority/evidence consumers, historical replay scope and
reviewed content determine the more specific decision. New output files are
separately covered by the publication manifest rather than added to their own
closed baseline inventory.

Untracked/ignored/external contents are excluded from this census. Baseline
untracked status strings are preserved separately without reading payloads.
