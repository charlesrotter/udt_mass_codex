# G152 lay report

G151 found the rule curvature would use if a positional separation were carried continuously through
a family of observer comparisons. G152 asks a simpler ownership question: does the pair surface we
already have automatically supply that carried separation?

It supplies two natural candidates. Its coordinate grid has a sideways vector, and its metric turns
that into an orthogonal ruler vector. But the working positional chord has a separately calculated
length,

\[
\rho=X_{\max}\frac{L-T}{L+T}.
\]

Those vectors point along the same ruler line, but they are not automatically the same length. The
coordinate vector can also contain a clock-direction shift. Even when the lengths match, lapse and
shift changes can prevent the ruler marks from being carried together by the normalized observer
clock.

The useful advance is that all of this is now exact rather than verbal. We know the precise
magnitude, shift, lapse, and commutator conditions that would make the working chord equal to—and
move with—the pair surface's own ruler variation. We also have exact examples proving that matching
length and connecting carry do not imply one another.

So the pair immersion owns the ingredients and the test, but not an automatic yes. If a coherent
physical family does satisfy the equality, it returns a candidate value

\[
X_{\max}^{(\epsilon)}=\epsilon L\frac{L+T}{L-T}.
\]

A universal `X_max` would then require that expression to be constant across the whole supplied
family. That is a sharply narrowed next question, not a derived value or a selected universe.
