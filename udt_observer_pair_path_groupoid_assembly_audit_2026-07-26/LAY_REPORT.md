# Lay report

The earlier “middle mismatch” was mostly a bookkeeping problem.

We had been trying to attach one complete comparison frame to each spacetime point. But one observer
can compare with different observers in different directions. Those comparisons use different
clock-and-ruler pairs at the same event. Treating them as if they were the same object creates a
mysterious leftover transformation.

Once each ordered clock/ruler pair is treated as its own object, the leftover is simply the honest
change from one pair to another. Metric transport, pair changes, composition, and reversal then fit
together exactly. This works for every value of the unresolved angular weight `lambda`.

The angular screen still has an arbitrary rotation, but that rotation does not affect the reciprocal
clock/ruler operator because the current screen response treats both screen directions equally.

What remains missing is not the comparison machinery. It is the physical rule that says how much
signed reciprocal depth belongs to a particular observer-pair path. Ordinary metric parallel
transport cannot provide that number because it preserves the metric, while nonzero reciprocal
dilation deliberately changes clock-versus-ruler calibration.

If the depth depends only on endpoints and adds exactly through every intermediate observer, it
must be the difference of one scalar value at the endpoints. If it is path-dependent, loop periods
remain visible. If it is instead a nonnegative function of pair distance, its general composition
must involve angular information rather than simple scalar addition.

So the kinematic skeleton now fits together. The open joint is the metric-native depth law—not a
missing frame convention, action, or new mechanism.
