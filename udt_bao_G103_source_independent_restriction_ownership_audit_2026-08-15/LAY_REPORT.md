# Lay report — what G103 found

G102 built the measuring machine. G103 asked whether the machine itself forces the picture it will
measure.

The answer, in the territory tested, is no.

The metric does enforce the shape of the instrument panel: every source direction must lie on the
same observer's sky, the directions must fit inside three spatial dimensions, clock comparisons must
compose consistently, and pair counts must obey ordinary measure bookkeeping.

But those rules are like saying every musical score must use the available notes and fit on the
staff. They do not choose the melody. With the observer-query history and source pairing still free,
the exact algebra can reconstruct any regular local chord and any first change of that chord.

The sharpest example uses the same four sky directions and the same one-point distribution. One
legal pairing makes every pair parallel, another makes every pair perpendicular, and a third makes
every pair opposite. The underlying list of directions is unchanged; only the pair relation changes.

One earlier rule remains real but narrower: if we freeze one calibrated base and only add a positive
angular Gram contribution, reciprocal depth can move in only one direction. Once the full pair
realization is released, that fixed-base ordering no longer constrains every observer-source
relation. It was a rule for one instrument setup, not the whole orchestra.

So we have not found a parameter-free BAO prediction. Before looking at the sealed BOSS pattern, we
must openly supply either a source-pair premise or a native joint law that ties source structure to
the complete history. Global focusing, critical branches, topology, bootstrap, and singular limits
could still provide such a law; this local audit did not test or exclude them.
