## The stripped question

Do not ask for a new radial curve. Ask what the completed pair and metric already do.

The completed pair pullback supplies a clock direction and an orthogonal ruler direction. Those
two directions contain exactly two null directions. Once one orientation is selected, the metric
geodesic equation propagates the ray, endpoint clocks measure its frequency, and the same curvature
propagates the two-dimensional screen.

The candidate native chain is therefore

```text
complete metric + completed pair + orientation
    -> normalized null initial direction
    -> affine null branch

    -> parametric (Z, d_A)
```

No `R(Z)` is inserted. If `Z` is monotone, the parameter can be eliminated afterward. If it is not,
the multi-branch parametric relation is the honest result.
