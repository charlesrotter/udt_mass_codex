# Lay Readout

We learned that our “seven families” list was a mixed filing cabinet, not seven kinds of matter.

Three drawers contain actual conditional mathematical families: two different P4 versions and the
Hopfion model. But the two P4 versions differ in a basic rule about what is allowed to vary. One lets
seven settings vary only as whole-cell knobs; the other lets them vary from point to point. The first
is mathematically embedded inside the second, but solving the weaker whole-cell conditions is not the
same as solving the stronger point-by-point conditions. UDT has not selected which rule is physical.

The other four drawers are not candidate matter families:

- one holds calibration/test cases;
- one holds rules for joining cells;
- one records assumption-specific dead ends; and
- one holds mathematical pieces not yet assembled into one actual solution.

The earlier algebra did not collapse. The scoped positive, negative, structural, and Hopfion results
keep their limited meanings. What changed is the map: we no longer count test fixtures, road rules,
dead ends, and unassembled blueprints as separate houses.

For the stability hypothesis, we are not ready for a broad “five-family” numerical sweep. We have a
narrow P4 calculation that can still be done, a second conditional P4 branch blocked by realization
questions, and a separate conditional Hopfion example. Before counting physical families, the metric
must still tell us what the native world of possible matter configurations actually is.
