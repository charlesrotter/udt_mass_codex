# Completeness map

This result is one structural tile, not a field solver or a complete theory.

| criterion | covered here | explicitly dropped or open |
|---|---|---|
| 1. Fields | smooth fixed-rank complete coframe extension over a supplied split | physical reciprocal realization, rank-changing strata, matter/carrier |
| 2. Action terms | none assumed | every native bulk and boundary term |
| 3. Full equations | Cartan reconstruction and identities classified as kinematics | native response, constraints, evolution, source |
| 4. Domain/charts | exact three-chart cocycle and current bundle architecture | arbitrary stratified atlas and physical variation domain |
| 5. Boundary/regularity | dependency on bulk/boundary operators exposed | physical seal, polarization, corners, moving boundary |
| 6. Topology | global-frame and holonomy restrictions retained conditionally | physical completion/topology selection |
| 7. Dynamics | none | all initial-value and time-live laws |
| 8. Branches | all ten operation families adjudicated | complete on-shell branches under an unknown native law |
| 9. Stability | none | persistence operator, norm, and spectrum |
| 10. Regime | exact smooth fixed-rank algebra plus conditional monodromy controls | null/zero/rank-change strata and future laws |

No dropped class is treated as absent. In particular, `E10` remains an open stratified extension
problem; it is not counted as a failed return. The audit characterizes operations by provenance and
ownership rather than filtering geometries by desired smoothness or physical merit.
