# G314 lay report

We were mixing up two questions:

1. **What equations can a UDT spacetime obey?** G312/G313 now give a bounded vacuum answer.
2. **Why is our particular universe one solution rather than another?** The current theory does not
   answer that stronger question.

That second gap is not automatically a flaw. Ordinary field equations also allow many histories;
you supply starting conditions and the equations determine what follows. UDT only needs another
global rule if we demand that it choose the universe and its starting conditions from nothing.

The observer network does not secretly do that job. It is like a complete scan: it can reconstruct
whichever spacetime is scanned, but it does not decide which spacetime exists.

A global filter could reject some histories and still leave several. If so, choosing the realized
history—or how often different histories occur—is another piece of information. None of the
tempting filters tested here (positive curvature, compactness, roundness, topology, or scale) is
currently a UDT-owned law.

So the months-long “missing history” problem has become smaller and more ordinary: bounded vacuum
dynamics now exists; a unique-universe bootstrap remains optional and open.
