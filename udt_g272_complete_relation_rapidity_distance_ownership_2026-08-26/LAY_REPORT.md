# G272 lay report

We found that the infinite-foundational-`c` intuition was pointing at something real, but two
meanings of distance had been mixed together.

The complete metric already gives an exact dimensionless measure of how far apart two transported
observer clock frames are. For a radial comparison this reduces exactly to the familiar bounded
profile `tanh(delta)`, with `delta` equal to the endpoint change in `phi`. For an angled light path,
the same metric also produces a sideways screen component, so the complete separation state is more
like a bounded arrow than a single number.

If UDT provisionally identifies its signed bounded radial coordinate with normalized physical
distance, then the profile is no longer arbitrary:

```text
phi change = artanh(distance / limiting scale).
```

That profile is exact and approaches an asymptote automatically. What is not yet derived is the
conversion of this dimensionless distance into metres or megaparsecs, the value of the limiting
scale, and the global rule saying which observer relations make up the physical universe.

So the open problem has narrowed. We are not necessarily missing the shape of the UDT relation.
We may be missing only the formal ownership and calibration that say, “this native bounded relation
coordinate is physical distance.”
