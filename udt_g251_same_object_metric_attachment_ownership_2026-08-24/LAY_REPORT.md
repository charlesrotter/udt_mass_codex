# G251 lay report

The metric already knows how to calculate a clock interval, an image size, an area, a volume, or a
curvature. That part is not missing.

What is missing is the label connecting one real measurement to the exact thing in the model. It is
the difference between saying “this blueprint contains a ten-foot wall” and physically identifying
which built wall the tape measure was placed against.

The metric cannot calibrate itself by calculating the same wall twice. But once we explicitly match
one independently measured clock interval, area, or curvature to the same modeled object, G250 says
the remaining overall scale is fixed. Further measurements then test whether the history is right.

Using mass or density is a deeper step because UDT does not yet own the law connecting that matter
measurement to a particular metric length. That would require more physics, not merely calibration.

No measurement type or value was chosen here.
