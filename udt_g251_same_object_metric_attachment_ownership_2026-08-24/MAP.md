# G251 map — same-object metric-attachment ownership

Date: 2026-08-24

## Whole question

G249 leaves one positive constant homothetic scale after a complete dimensionless metric history and
regular branch are supplied. G250 proves that one independently calibrated, same-object metric datum
of nonzero homothety weight would fix that scale. G251 asks the next narrower ownership question:

> Does the current UDT source universe already connect any independently calibrated physical datum
> to the identical clock interval, branch point, screen, orbit, region, or event evaluated by the
> metric?

This is metric-led and observationally blind. It is not a search for a convenient numerical scale.

## Three legs that must not be conflated

For each G250 candidate, distinguish:

1. **Metric evaluator:** the supplied metric computes a proper interval, Jacobi amplitude/area,
   volume, or curvature quantity.
2. **Object identity:** the evaluated interval, event, screen, orbit, or region is identified across
   the model and measurement statement.
3. **Independent calibration attachment:** a datum not recomputed from the same unknown metric is
   lawfully assigned to that identified object in declared units.

Homothety weight plus the first leg proves scale sensitivity. It does not prove the second or third
leg. A metric quantity evaluated twice from the same unknown metric is a consistency identity, not
an independent anchor.

## Whole candidate census

- proper-time intervals;
- metric lengths and vertex-normalized Jacobi amplitudes;
- screen or symmetry-orbit areas;
- spatial and spacetime volumes;
- nonzero scalar/tidal and quadratic-curvature invariants;
- the mass, density, and energy-density dimensional composites already bounded by G132/G202;
- conversion-only or weight-zero controls: `c_E`, `G_obs`, reciprocal redshift, causal cones, and
  normalized Jacobi shape.

No candidate is preferred, and no observational value will be read.

## Premise map

- `pinned-by-THEORY` for this bounded audit: the positive G249 homothety orbit, the G250 candidate
  census and weights, and the source-owned conditional metric evaluators cited in the manifest.
- `free-and-explored`: candidate attachment class and whether the three ownership legs are present.
- `OPEN`, not silently chosen: complete physical history, observer/source population, branch,
  object matching, absolute datum, instrument/matter law, uncertainty, and numerical scale.
- `pinned-by-HABIT`: none.

Omitted sectors are caustics, finite-fiber aggregation, detector/transfer law, observational
outcomes, `X_max`, action, source dynamics, bootstrap, and protected local work.

## Certification and conclusion ceiling

A positive native-owner result requires an exact current source statement owning all three legs
without an imported coefficient, matter/instrument law, observed outcome, or circular metric
self-evaluation. Otherwise the audit may return only a source-bounded nonownership classification.

The strongest negative permitted is: **no current source owns an independent same-object attachment
for the registered classes.** It is not a theorem that no observational attachment can exist or
that absolute scale is unphysical.
