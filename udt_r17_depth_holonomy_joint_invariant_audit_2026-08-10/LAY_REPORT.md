# Lay report

We have now joined the measuring tape and the compass mathematically.

The measuring tape is the reciprocal endpoint depth: how much the clock/ruler balance differs
between two endpoints. The compass is the angular rotation accumulated while carrying a comparison
along a chosen path.

The metric says these two pieces travel together cleanly. Their combined transport composes exactly
when a journey is split through an intermediate observer. Globally, though, the compass is carried
between two different local screens; it looks like one ordinary rotation matrix only after endpoint
axes are chosen. The complete R17 coframe also fixes how the reciprocal scale appears in its
original angular vector and coframe descriptions.

But the join is more like a package with two compartments than a blender. The scale and rotation
commute. A single open path has no frame-independent angular number because either observer may
rotate their screen axes. For loops, or for comparing two different paths between the same
endpoints, the relative angular return becomes genuine invariant data.

This explains something important: the angular orchestra is real, but it cannot simply be added to
the reciprocal depth to manufacture a new real clock reading. The only normalized continuous real
number obtained directly from the order-zero joint object is the endpoint depth already known.

If derivatives of the geometry are allowed, many additional path integrals can be written from
angular curvature and `phi`, and line integrals always compose. Our simple non-exact example was a
general mathematical control, not a realized stationary R17 solution. So this exposes a possible
larger ambiguity without claiming R17 has already realized it. The present UDT foundation does not
choose one, so selecting a favorite would be invention.

The gain is a clean piece of structure and a much sharper missing joint. We no longer need to ask
whether depth and angular carry can coexist or compose—they can. What remains is whether some
native UDT principle selects a physical path or a particular higher-jet one-form, or whether the
full physical observable is inherently path/loop-valued rather than one scalar.
