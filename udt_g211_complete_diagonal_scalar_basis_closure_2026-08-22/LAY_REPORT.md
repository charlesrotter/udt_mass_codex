# G211 lay report — the lapse was not a third instrument

The diagonal part of the metric has two basic volume knobs once we have said which direction is
clock and which three directions are space.

One combination changes the overall four-dimensional volume. The other changes the relative width
of the causal cone—how much spatial separation corresponds to a clock interval. “Changing only the
lapse” turns both knobs in a particular opposite ratio. It is not an additional third knob.

This also explains why different measurements hear different things. Causal paths hear only the
clock-versus-space ratio. The affine calibration along a lightlike path and the completed observer
pair also hear the common scale. Two metrics can therefore have the same causal paths but different
affine reach and different completed depth.

This is a simplification of the metric anatomy, not a selection of the universe's scalar profile.
