# PIA1 return — conditional mathematics, physical admission still missing

No reviewed experiment yet justifies all the observing conditions and error
bounds used in FRI1. The largest issue is concrete: that conditional regime
requires received ticking more than54,180 times slower than emission. This is
the total ratio for the specified pairing, not a small extra effect to add to
ordinary astronomical redshift. Neither a precise laboratory link nor a
published systemic redshift automatically supplies that pairing.

The three audited classes supply useful pieces: engineered clocks can support
source/reference calibration; pulsars provide timed records; masers provide
spectral and angular monitoring. None of the reviewed protocols independently
admits this tail, its preparation and whole-hull source/frame/error conditions.
We did not fit data, exclude all experiments or refute UDT.

There is also useful progress in measurement reduction. We bounded the
difference between averaging frequency and averaging log-frequency; it is
tiny in the frozen control, but needs budgeting in a real instrument. We
specified how source-time drift transforms and how a justified joint
statistical error model could give coverage for the existing finite enclosure.
No such physical error model was manufactured from headline clock precision.

FRI1's1.902% synthetic width and short-record factor2 ambiguity remain valid
conditional tools, not experimental accuracy claims. Matched GR still gives
the same readings. Native UDT selection, source mass and physical X_max stay open.

saved arithmetic and primary-source claims. Same model is disclosed; no human,
different-model, instrument-validation or empirical-confirmation claim.
