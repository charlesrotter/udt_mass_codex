## Cartan geometer

For one fully supplied positive profile, the static-spherical geometry is cohomogeneity one. In an
adapted orthonormal frame,

\[
e_{\hat r}(r)=e^{-\phi(r)},
\qquad
e_{\hat t}(r)=e_{\hat\theta}(r)=e_{\hat\varphi}(r)=0.
\]

Every connection and curvature coefficient is therefore a supplied function of invariant areal
radius. This is a genuine finite local Cartan realization law for that member, but it is evaluative:
its structure functions already contain the full supplied profile.

For a fixed finite G204 family, a finite reduced state exists. For the unrestricted primary profile
family, arbitrary-order jet twins obstruct one universal finite-order autonomous closure.

## Relational theorist

\[

not a global coordinate across all regimes.
