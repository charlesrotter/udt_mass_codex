# Completeness map — one FC07 existence tile

This package fills one tile: smooth complete off-shell metric existence and transition descent for
the eight registered FC07 monodromy controls inside a chosen constant-depth block extension.

It covers the full positive `2 x 2` screen, exact domain/glue regularity, both orientation strata,
and spatial/four-metric completeness of the constructed family.

It drops the generic four-dimensional extension, pair-screen mixing, shift, nonconstant/time-live
`phi`, every native equation/action/source/carrier, the infinite `GL(2,Z)` census, other completion
classes, branch bifurcations, stability, and regime selection. Any dropped item could contain new
structure. No closure beyond this tile is inferred.

All construction choices are category-A smooth geometry or explicitly pinned bounded controls.
`TEN_CRITERION_SCOPE.tsv` gives the criterion-by-criterion record.
