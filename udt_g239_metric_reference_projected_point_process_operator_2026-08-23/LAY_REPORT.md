# G239 lay report

Imagine the real galaxies are sprinkled without a preferred pattern. The complete UDT metric acts
like an uneven lens: some directions can be spread out and others compressed. That changes how many
galaxies appear in each patch of the observed sky.

The BOSS random catalogue is a map of where the survey could see—not a second sky passed through
the UDT lens. The measured angular statistic therefore compares two maps:

1. the metric-distorted galaxy density;
2. the survey footprint density.

G239 proves the exact comparison rule. The surviving curve is the angular self-correlation of the
difference between those two densities, plus a separate term for any genuine source or branch-pair
correlation.

The reviewer caught one useful nuance. Even a perfectly random set of parent galaxies can create
an observed pair pattern if the metric lets one parent appear through more than one branch—like one
object producing two related images. Those sibling images belong in the separate connected term.
They do not mean the parent galaxies were clustered.

Two important cancellations are exact:

- if the metric only changes every direction by the same amount in one shell, it cancels;
- if the random reference is deliberately made identical to the metric-distorted density, it also
  cancels.

But a direction-dependent complete-metric response can survive the real fixed survey reference.
The earlier G127 result already proves that one supplied UDT metric can produce different local
screen areas in radial and tilted directions, so this route is genuinely metric-live.

What G239 does **not** supply is the actual whole-sky metric history or the real branch/source
population. We now know the exact machine those inputs enter; we have not yet supplied Nature's
settings or compared it with the BOSS outcome.
