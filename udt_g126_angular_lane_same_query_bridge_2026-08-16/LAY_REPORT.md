# G126 lay report

The current angular data and the current SNe score are not yet two microphones recording the same
instrument.

On the exact spherical observer setup used for G125, the sky screen simply enlarges and rotates
everything uniformly. It does not reshape one direction differently from another. The ideal survey
reference then removes that purely radial abundance change relative to whatever registered sky
footprint the survey has. Nothing left in that exact branch can be matched to R5's angular pattern.

There is a second missing link. SNe conditionally gives us radius versus observed frequency, but
`K` asks how radius changes with affine ray distance. The catalog does not provide that affine
clock. Two different affine rates can have the same radius-frequency curve and the same screen
picture while carrying different screen phase.

So the angular atlas cannot currently separate the instruments in G125's total score. This does
not make the angular work useless. It tells us exactly what a future bridge must contain: a
non-spherical or displaced observation query on the same complete history, plus source, branch,
reference, and affine/phase ownership. Until that exists, fitting R5 would manufacture the bridge
instead of discovering it.
