# G126 user frame correction — SNe is comparison data, not a branch

Date: 2026-08-16

Charles corrected the phrase “SNe branch.” No such branch has been derived or adopted.

- SNe is an observational comparison/non-regression data set.
- Its present role is primarily to check whether the evolving conditional observer relation remains
  compatible with measured redshift/brightness behavior.
- Because the registered luminosity comparison combines the pair-frequency score, screen area, and
  imported radiative-transfer assumptions, SNe compatibility does not isolate any one channel.
- A very small high-redshift angular contribution may eventually enter a complete prediction, but
  the current SNe comparison does not separately identify it.
- The metric history, observer query, and any mathematical branches belong to the geometric model;
  the SNe catalog neither creates nor selects them.

This is a category-language correction. It changes no G126 algebra or bounded landing.
