# G200 lay report

Both directions use the same instrument.

At the starting point, the inward-looking and outward-looking nonradial comparisons hear exactly
the same angular chord.  There is no native switch that makes one loud and the other quiet.

But they then travel into different parts of the same metric.  If the metric changes with distance,
one direction samples the change toward larger radius and the other samples it toward smaller
radius.  Their accumulated pictures can therefore differ even though the underlying rule is the
same.

So the clean picture is:

- **direction** chooses which part of the radial history is sampled;
- **regime** determines how loud the reciprocal/angular response is there;
- the primary metric supplies one law for both directions.

This narrows the architecture substantially.  It does not yet prove the proposed
loud--quiet--loud profile, because the physical radial history itself has not been derived in this
calculation.
