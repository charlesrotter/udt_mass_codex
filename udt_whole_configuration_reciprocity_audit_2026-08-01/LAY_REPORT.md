# Lay report

We found a real whole-universe consequence of Reciprocity, but it is a quality-control rule rather
than the missing engine.

Imagine several observers reading the same rulebook from different seats. Reciprocity says the
rulebook must still say the same thing after translating between their viewpoints. If a universe
is allowed from one seat, its correctly translated description must be allowed from every other
seat. That is important: it can reject a proposed law that secretly favors one observer.

But it does not write the rulebook. Many very different laws can treat all observers equally.
Exact examples in the audit obey the same exchange symmetry while selecting completely different
sets of states.

The common conceptual trap is to replace “the two descriptions are equivalent” with “the state
must be unchanged when the observers are exchanged.” The latter is a new restriction. It would be
like saying rotational symmetry requires every arrow to point in every direction at once, rather
than saying arrows rotate consistently.

The network of pairwise clock/depth comparisons also behaves cleanly: it can reconstruct relative
depths up to a shared zero if the comparisons are supplied. But when the geometry produces its own
comparisons, every depth pattern passes that consistency test. It is a map, not a choice.

So Reciprocity is not the missing table leg. It tells us how the missing leg must attach: any
future bootstrap return law must be observer-equivariant. If its observer transformation preserves
what the equation calls zero—as an ordinary linear transformation does—its solutions must come in
complete observer-equivalent families. Another principle must still supply the actual feedback
formula.
