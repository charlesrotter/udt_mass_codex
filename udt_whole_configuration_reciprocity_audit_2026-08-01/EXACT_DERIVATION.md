# Exact derivation — whole-configuration Reciprocity

Date: 2026-08-01

Outcome: `RECIPROCITY_DERIVES_EQUIVARIANT_QUOTIENT_ONLY`

This is a bounded theorem over the exact preregistered 1,384-path source universe. “Quotient” here
means equivalence/naturality of observer *descriptions*. It does not erase distinct physical
observers or select a physical configuration.

## 1. The three reciprocities remain different objects

The current source hierarchy distinguishes:

1. **Observer-frame Reciprocity.** No observer is preferred; a physical comparison law must carry
   the same form under an observer/frame change.
2. **Internal dual Reciprocity.** The founded clock/ruler pair carries

   ```text
   D(phi)=diag(exp(-phi),exp(phi)),
   D(phi)^T K D(phi)=K,
   K=[[0,1],[1,0]].
   ```

3. **`Xmax` reciprocity.** A conditional dimensionless positional group/schema whose physical
   position join, value, and boundary realization remain open.

Only the first item is the principal subject. The second constrains its two-dimensional
representation. The third cannot be used as founded content.

## 2. Strongest founded lift: naturality of any future law

Let an observer-change arrow `g` act on a supplied configuration domain and output domain as

```text
X -> T_g X,
O -> rho_g O.
```

If a physical return law exists,

```text
A: U_full x O -> Y,
```

observer-frame Reciprocity requires a compatible codomain action `sigma_g` and the naturality law

```text
A(T_g X, rho_g O) = sigma_g A(X,O).
```

This is the whole-law content of no-preferred-observer Reciprocity. If the codomain action preserves
the distinguished zero,

```text
sigma_g(0)=0,
```

as an ordinary linear/vector-bundle action does, then

```text
A(X,O)=0  =>  A(T_g X,rho_g O)=0.
```

Therefore a future physical solution set must be saturated by complete observer-equivalence
orbits. A proposed closure law that makes one observer solve the equation while an equivalent
observer does not would fail founded Reciprocity.

Invertibility alone is insufficient. The exact affine involution `sigma(y)=1-y` is invertible but
moves zero to one. With the matching domain involution `s(x)=1-x` and `A(x)=x`, equivariance holds
while `A(0)=0` is not carried to another zero. The zero-preserving premise must therefore remain
explicit.

This is a real selector **on proposed laws**. It is not a selector of one law or one state. The
current record also lacks one universal action of every observer arrow on boundary, corner,
completion, and global-output data, so even the displayed requirement remains typed by supplied
domains at that layer.

## 3. Equivalence is not fixedness

For the exact logic control, let the observer exchange act by

```text
S(x1,x2)=(x2,x1).
```

The point `(1,2)` belongs to the two-member orbit `{(1,2),(2,1)}` and is not fixed. The equation

```text
X=S X
```

has the rank-one fixed locus `x1=x2`. It is an additional state restriction, not the definition of
exchange covariance.

The same distinction is already present in the complete-coframe sources: a fixed non-scalar
reciprocal plane cannot be invariant under the whole local Lorentz group. The correct law is that
the observer-selected plane and generator transform equivariantly. Requiring fixed components in
every frame would create a preferred rigid presentation or collapse to a trivial central object.

## 4. Equivariance does not choose the return operation

The same swap action admits multiple inequivalent equivariant operations:

```text
A_identity(x)   = (x1,x2),
A_difference(x) = (x1-x2,x2-x1),
A_product(x)    = x1 x2.
```

The first two are vector-equivariant and the third is scalar-invariant. On five exact witnesses
their zero sets retain respectively `1`, `2`, and `3` witnesses. All respect the same Reciprocity;
none follows from the symmetry.

Thus Reciprocity supplies a gate

```text
candidate law -> equivariant or rejected,
```

not a construction

```text
Reciprocity -> unique A.
```

## 5. Pairwise comparison reconstructs but does not realize

For four observer objects, orient the six unordered pairs and define

```text
y_ij = phi_j-phi_i.
```

The `6 x 4` incidence matrix has exact rank `3` and kernel dimension `1`, the common additive
offset. All twelve preregistered checks—one orientation of each of four sorted triangles on three
independent depth witnesses—vanish:

```text
y_ij+y_jk-y_ik=0.
```

If the comparisons `y` are supplied externally and are exact, they reconstruct relative depths
modulo one common zero. But in a self-readout equation

```text
y=B phi,
```

the graph Jacobian `[-B | I_6]` has rank `6` and nullity `4`, equal to the entire supplied `phi`
configuration dimension. Every `phi` produces a reciprocal, triangle-consistent comparison set.
The cocycle selects neither the comparisons nor the realized profile.

This is the whole-configuration version of the source result that abstract composition is derived
while the physical observer/event/path assignment remains open.

## 6. The dual pairing is structure, not a response law

The exact rational representatives

```text
D_q=diag(1/q,q),  q in {2,3,5}
```

all satisfy `D_q^T K D_q=K`. But the same invariant product `x1 x2` admits arbitrarily different
invariant level equations such as

```text
x1 x2 = 0,
x1 x2 = 1,
x1 x2 = 4.
```

The pairing therefore fixes how the founded two-dimensional representation is dualized; it does
not select an invariant level, extend itself to all metric/coframe/boundary variables, or provide a
physical response covector.

## 7. Conditional global structures do not close the gap

- Finite-cell reversal, seams, and gluing can impose partial admissibility only after their
  completion/boundary premises are supplied.
- `Xmax` reciprocity remains conditional and cannot be promoted to the founded frame law.
- P4 supplies an equivariant family of permitted response laws. Covariance constrains its form but
  does not select a member through the whole-solution/global gates.
- `O=R(X)` remains a graph even when both sides transform equivariantly.
- Conditional Bach, EH, carrier, and reduced-action equations cannot be spliced into Reciprocity.
