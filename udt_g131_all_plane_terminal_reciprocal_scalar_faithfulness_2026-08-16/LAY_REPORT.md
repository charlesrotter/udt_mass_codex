# G131 lay report

We found that the endpoint clock-versus-ruler reading carries far more of spacetime than one radial
reading suggested.

If you make that same reading through every possible orientation, the collection determines all of
the geometry's angles, light-cone shape, tilts, and directional relations. Every fake alternative
except one disappears.

The one surviving freedom is like enlarging or shrinking the entire local sheet of music without
changing the intervals between its notes. The reciprocal reading measures an interval, so that
common magnification cancels.

`c_E` fixes how clock units translate into ruler units, but it still does not say how large the
entire local sheet is. That requires one common-scale measurement—something like an area, volume,
or full pair size—if the metric natively supplies it.

So the missing structure has become much smaller:

```text
all oriented reciprocal readings -> conformal spacetime
one native common-scale density   -> complete spacetime metric
```

The next question is whether any already-derived part of UDT supplies that last scale datum without
smuggling one in. Reciprocal volume, screen area, or an absolute pair norm are candidates to audit,
not assumed answers. We should test them before looking for an action, bootstrap selector, or new
mechanism.
