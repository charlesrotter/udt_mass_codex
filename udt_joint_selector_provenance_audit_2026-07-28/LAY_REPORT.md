# Lay report

We checked whether the missing “joint” was already hiding somewhere in the repository under a
different name. It was not.

But the search did reveal that the pieces are more organized than they looked.

Imagine UDT has already built three parts of a railway system:

1. On an important class of stationary geometries, the metric can calculate the clock difference
   between two stations directly.
2. The metric can carry a complete orientation frame along any route we hand it.
3. The reciprocal rule tells us exactly how the clock and ruler channels change once the signed
   depth is known.

Those parts connect cleanly. That is real progress. The strongest existing construction can carry
the clock comparison and the orientation information together.

What the metric has not yet told us is which route represents the physical comparison, how the two
remaining sideways directions must respond, and how the local railway is joined into the complete
global network. There are still several mathematically valid choices for each. Nothing presently
registered chooses them all at once.

So we are not back at the beginning, and we are not merely circling. We now have a linear scaffold:

```text
reciprocal clock/ruler rule
        -> stationary metric clock depth
        -> complete-frame path transport
        -> exact but conditional combined comparison
        -> missing physical/full-frame/global selector
```

The likely next high-value question is no longer “try another attractive formula.” It is whether a
universal, metric-natural joint selector is mathematically possible at all. A symmetry/no-go audit
can test that. If symmetry forbids such a selector on the full metric class, UDT must either select a
restricted global branch or state one additional relational premise. That would turn the present
missing table leg into a sharply defined design choice rather than another algebra hunt.
