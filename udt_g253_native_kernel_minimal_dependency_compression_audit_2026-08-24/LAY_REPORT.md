# G253 lay report

We found the short version, and it is cleaner than the development history made it look.

There are really two instruments sharing one score, plus an optional ruler for assigning units:

- The clock comparison gives redshift directly. No angular correction, SNe curve, flux law, or fit
  is needed for that step.
- The angular response comes from how the same metric bends and reshapes a bundle of neighboring
  sight lines. It is not pasted onto the redshift afterward.
- A later real clock or length observation can tell us the absolute size of an already supplied
  dimensionless geometry. That assigns units; it does not rewrite the music.

One phrase needed tightening. The angular orchestra does not always change the redshift number.
With the same clock comparison, it can change the ruler, orientation, sky area, and image shape
while leaving redshift alone. Both channels still come from the same metric, but redshift alone
does not tell us the angular picture; the metric's variation along the branch matters too.

So the present work has not drifted into fitting a new kernel. But the path here was unnecessarily
long, and some older formulas are now controls rather than active physics. The compact active chain
uses no P1, G116/G189 transfer, fitted profile, `X_max`, observational outcome, or protected work.

What remains is not another hidden correction to the kernel. It is choosing or deriving the full
dimensionless metric history and matching its observer relations to physical records. The audit
does not solve that larger problem.
