# Lay report

The good news is that the ruler survived the orchestra.

We let both independent angular “instruments” vary instead of keeping the screen evenly tuned. No
matter how those two shears deform the screen, the twist of the stationary clock still points along
the same reciprocal ruler. The earlier clock-and-ruler structure also survives in whole open
neighborhoods of these deformations, rather than at a few specially balanced points.

But we found a very specific tradeoff.

The earlier way the metric recognized the clock was like identifying the only straight road in a
landscape. That worked because every other continuous symmetry had been broken. For the complete
metric to repeat perfectly around the Hopf circle, however, it must acquire a circular symmetry.
There are then two roads: the clock direction and the Hopf-circle direction. The old “choose the
only road” test can no longer choose the clock.

That does not destroy the Hopf structure. The undilated ruler still projects exactly onto the
regular Hopf circle, and globally patched screens carrying both kinds of shear can repeat
consistently around it. It means we need a more refined geometric way to distinguish the clock
within the resulting two-direction symmetry plane.

So the path has narrowed again:

```text
full screen does not destroy ruler
    -> normalized ruler still gives Hopf circle
    -> full metric descent is exactly characterized
    -> descent introduces a second symmetry
    -> identify the clock inside that two-symmetry plane.
```
