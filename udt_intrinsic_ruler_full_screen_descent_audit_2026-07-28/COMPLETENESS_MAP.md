# Completeness map

| Criterion | Covered here | Still open |
|---|---|---|
| Fields | founded pair/phi and every stationary invertible `GL(2,R)` screen | pair-screen off-blocks, matter, other fields |
| Metric modes | area and both regular screen shears; coframe rotation kept gauge | physical screen equation |
| Action/equations | none; exact off-shell identities only | all native variations and dynamics |
| Domain | chosen global stationary `R x S3` and its `K` orbit space | time-live and other completions |
| Symmetry | rank-three open strata, fiber-invariant strata, and counterbranches | complete isometry classification |
| Descent | exact `phi` and `h` Lie-derivative conditions | native enforcement and physical quotient |
| Topology | supplied normalized Hopf circle on chosen `S3` | physical topology/fiber selection |
| Controls | twist-off, depth-off, fiber-dependent, and nonpositive-slice strata retained | on-shell branch census |
| Carrier/physics | not loaded | carrier, action, source, boundary, density, mass, scale, dynamics |

This is a bounded compatibility theorem, not a complete metric solution-space theorem.
