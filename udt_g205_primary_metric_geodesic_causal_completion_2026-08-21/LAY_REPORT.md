# G205 lay report

The repaired metric does not run into a hidden edge. A traveler, photon, or even a mathematical
spacelike trajectory cannot reach the center or the far outer limit and fall off the geometry in a
finite amount of its natural path parameter. The center is an ordinary smooth point, and the outer
end is infinitely far away in the relevant geometric senses.

The spacetime also has a consistent global ordering: every complete causal history crosses each
constant-time slice once. So this candidate geometry is not just locally well behaved; it forms a
coherent global static spacetime.

One new feature emerged. If the trough is steep enough, the geometry can hold light on circular
orbits—one stable and one unstable. If it is shallower, those orbits do not exist. That is a native
change in what the orchestra plays as the metric parameters change, not an added mechanism.

This still does not tell us that Nature selects this profile or any particular parameter, and it
does not turn the far limit into `X_max`.

An external reviewer tried to break this result and retained the geometry. It did catch that our
automation labels were too strong: the computer checks verify the algebraic gears and finite
controls, while the global no-edge and Cauchy-slice conclusions are analytic proofs. Those evidence
labels have been separated; the scientific result did not change.
