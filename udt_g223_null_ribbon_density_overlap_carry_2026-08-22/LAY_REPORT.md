# G223 lay report

The previous step found a local ruler scale along each lightlike comparison ribbon. This step asked
whether all those little ruler readings naturally join into one global ruler.

The answer is simpler than “we need another equation.” The metric already ties the clock direction
and ruler direction together. If you change the clock markings, the ruler markings change by the
exact inverse amount, so the complete clock-ruler chord stays unchanged.

Along any ordinary open ribbon, you can always number the ruler marks locally. The earlier
“closedness” problem arose from demanding that those numbers have no sideways change in one
particular coordinate grid. Change the grid and that closedness test can change even though the
geometry has not.

What remains genuinely open is joining rulers belonging to different observer-pair ribbons. Clock
rates compose automatically when one comparison really follows another. But the clock rule alone
does not tell us which ruler direction on the second ribbon is the continuation of the ruler on the
first. If the ribbons are supplied as one coherent family, that identification can carry. Merely
reusing an observer's name does not create it.

So we removed one apparent missing equation. The remaining gap is a global joining question, not a
failure of the local reciprocal kernel.
