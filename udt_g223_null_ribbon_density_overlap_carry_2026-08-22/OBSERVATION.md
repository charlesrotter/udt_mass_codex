# G223 observation

Date: 2026-08-22

Let two adapted charts on the same affine null ribbon satisfy

\[
y_j=f(y_i),
\qquad
\lambda_j=\alpha(y_i)\lambda_i+b(y_i),
\qquad f'>0,\quad\alpha>0.
\]

Writing `q=alpha' lambda_i+b'`, direct differentiation predicts

\[
K_j=\alpha^{-1}K_i,
\qquad
J_j=(f')^{-1}\left(J_i-\frac q\alpha K_i\right),
\qquad
a_j=\frac{a_i}{f'\alpha}.
\]

On the vertical cotangent line,

\[
[d\lambda_j]=\alpha[d\lambda_i],
\]

so

\[
a_j[d\lambda_j]=(f')^{-1}a_i[d\lambda_i].
\]

This suggests that the chart-free object is not an ordinary vertical one-form until the clock line
has been trivialized. The invariant metric object should instead be the mixed line pairing

\[
\mathcal A_i=a_i\,dy_i\otimes[d\lambda_i].
\]

The same calculation also warns that the full representative `a_i d lambda_i` acquires a
horizontal term under a `y`-dependent affine change. Its exterior derivative is therefore not, by
itself, an invariant of the vertical density class.
