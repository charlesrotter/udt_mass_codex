## 2. Preregistered proof obligations

The positive landing requires all of the following:

1. **Exact metric gate.** Independently recompute `Ric=0` and
   `Riemann_abcd Riemann^abcd = 12 mu^2/R^6`.
2. **Temporal/Cauchy gate.** Retain G323's exact temporal `R` foliation and compact Cauchy slices.
3. **First-integral gate.** Independently derive for an affinely parameterized causal geodesic

   \[
   \dot R^2=p_X^2+\frac{\mu(p_y^2+p_z^2)}{R^3}
   -\kappa\frac{\mu}{R},
   \]

   with `kappa=-1` for unit timelike and `0` for null curves.
4. **Future-completeness gate.** Prove every future-directed timelike geodesic has infinite proper
   time as `R -> infinity`, treating `p_X != 0` and `p_X = 0` separately.
5. **Finite-interior gate.** Prove a geodesic with a finite parameter endpoint and `R` bounded in a
   compact subinterval of `(0,infinity)` extends inside the original quotient.
6. **Past-curvature gate.** Prove every finite-parameter past endpoint forced outside the quotient
   has `R -> 0`, where the Kretschmann scalar diverges, excluding a `C2` endpoint.
7. **Theorem-interface gate.** Authenticate and apply only the one-sided statement that a future
   timelike-geodesically-complete globally hyperbolic spacetime has no future boundary in a `C0`
   extension. Use the time-dual endpoint result only to locate a hypothetical remaining boundary;
   use curvature only for the `C2` contradiction.
8. **MGHD gate.** Show any proper smooth G322 MGHD extension would be a forbidden proper `C2`
   Lorentzian extension. Conclude equality only in the smooth per-datum category.
9. **Modulus gate.** Use, without strengthening, G323's already-derived primitive-lattice modulus
   to distinguish only the registered unmarked MGHDs.

## 4. Preregistered falsifiers

The positive landing fails if any of the following occurs:

- a future-directed timelike geodesic reaches `R=infinity` in finite proper time;
- a finite-parameter extension endpoint can occur with `R` bounded away from zero and infinity;
- the curvature invariant stays bounded as a forced past endpoint is approached;
- the one-sided extension theorem does not apply to the exact regularity/global-hyperbolicity class;
- a proper smooth same-datum globally hyperbolic extension exists;
- G323's modulus is not invariant in its stated registered quotient category;
- any proof requires a new field equation, physical boundary, scale, source, fit, or occupancy rule.
