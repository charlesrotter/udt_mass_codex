# G324 lay report

G323 had built a complete-looking expanding spacetime for each tested set of starting data, but we
had deliberately left open whether each one was only part of a still larger smooth spacetime.

G324 now has a bounded positive answer: in this exact family, the displayed spacetime is already
the largest smooth causally well-behaved development of its own starting data.

The reason has two parts. Toward the expanding future, every freely falling observer has unlimited
proper time, so there is no missing smooth future edge. Toward the other end, the curvature grows
without bound, so that end cannot be smoothly filled in. There is therefore nowhere for a larger
smooth continuation of the same development to go.

This also means the compact-shape distinction found in G323 is real at the level of the full
maximal developments, not an artifact of having stopped the coordinates too early.

What it does **not** do is choose which compact shape Nature uses. It does not set a physical
scale, add matter, prove stability, alter the metric or reciprocal kernel, or determine
`X_max`. It closes a mathematical completeness gap inside the registered family. A fresh external
review is still pending.
