# G168 lay report

The last local piece was simpler than a path-selection law.

To measure anything with a metric, you must tell it two directions: which way the observer's clock
points and which way the other observer lies. That tiny local object is the **pair germ**. It is the
first infinitesimal arrow of the relationship, not a route drawn through spacetime.

Once those two directions exist, the UDT metric does all the rest. It removes any clock component
from the separation direction, produces the physical ruler direction, and therefore fixes the
two-dimensional clock/ruler plane. If the separation points partly around the sphere rather than
only radially, those angular components automatically enter the same pullback before the reciprocal
kernel is read. Nothing is bolted on afterward.

What the metric cannot do is turn the names “observer A” and “observer B” into that local arrow.
Names are not a measurement. Even two fixed observer worldlines can be joined by different smooth
comparison surfaces with different initial directions. But UDT does not need to choose a whole
surface to evaluate a local pair: the local arrow is enough.

So the simplification is:

```text
completed local pair relation -> its clock and separation directions
metric -> ruler + pair plane + angular participation
pair pullback -> one reciprocal response
```

The remaining unfinished work is global bookkeeping and physics: which local comparisons belong
to one coherent observer network and how their frames are carried between locations. The local
pair-plane problem itself is closed on the regular stratum.
