# G72 lay report

The geometry gives us more than an empty pipe. Once we specify a particular line of comparison
from the distant frame to our sky, it provides a complete local optical response with three parts:

1. how large the image becomes;
2. how much it is stretched differently in two directions;
3. how much the image rotates compared with a ruler carried through the same geometry.

The third item becomes meaningful because we compare two things that travel through the same
geometric construction: the image deformation and the carried ruler. The angle of the ruler alone
depends on how we drew coordinate axes at each end. Their relative angle does not.

This is a real advance for the observer-effect picture. Distance dilation and angular geometry can
form a genuine distortion machine. But a distortion machine does not paint its own picture. Feed it
a blank or perfectly uniform screen and it remains blank or uniform. It can reshape an existing
pattern, but the current metric evidence does not yet say what initial pattern exists or which
physical detector rule turns the response into CMB temperature or polarization.

The overall image size also still needs a physical reference scale. `c_E` calibrates clock length,
but it does not by itself state how far away the physical CMB comparison endpoint is. A future
global completion, potentially involving `X_max`, supplies the kind of information that could fix
that scale. The SNe result can later reject global profiles that fail near our end, but it cannot
currently choose the full profile.

On the existing G68 controls the geometry creates small but nonzero shear and area changes. It does
not create resolved image rotation. The much larger saved azimuthal displacement is a different
geometric channel, not hidden polarization.

So we now have a better machine, not yet the cosmic photograph.
