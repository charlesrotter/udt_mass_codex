# Lay report

We asked whether the original clock/ruler reciprocity automatically tells the rest of the metric
orchestra how to change.

The answer is surprisingly small.

If we demand that the rule not secretly point in a preferred direction on the two-dimensional
angular screen, the complete constant rule has only two possible additions:

1. make the whole angular screen grow or shrink together;
2. rotate the screen.

The rotation is like rotating the sheet music stand: the local pair metric hears no difference. It
may matter later for accumulated orientation or polarization transport, but it is not the missing
zero-order loudness rule.

The common angular growth really can change the final observer-pair clock/ruler ratio. But it
survives only under the weakest reading of the founding rule. If we require the complete action to
preserve total volume, a natural complete pairing, or an extended clock/ruler exchange symmetry,
that angular growth is forced to zero. None of those stronger complete rules is yet founded.

There is a second catch: the growth changes the answer only if we tell the metric frame to change
while holding the observer-pair realization fixed. If the observer relation is carried along in the
compensating way, the change disappears exactly. The reciprocal representation itself does not tell
us which carry is physical.

So this was productive elimination, not another circle:

- a constant hidden mixing matrix is not the score;
- constant angular shear is not the score;
- local screen rotation is not the score;
- only one common angular-loudness knob remains, and even it is conditional.

The next step is to let the metric propagate an actual observer screen through its curvature using
the already-identified Jacobi/Riccati machinery. That tests whether geometry determines how the
observer relation should move with the coframe. We should not fit the remaining knob before that
test.
