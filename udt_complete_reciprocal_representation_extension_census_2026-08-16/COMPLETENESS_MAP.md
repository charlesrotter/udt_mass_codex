# Completeness map

This package is one bounded algebraic tile, not a complete UDT solver.

| Criterion | Covered here | Explicitly dropped |
|---|---|---|
| Fields | constant linear action on complete base+screen coframe channels | physical metric and pair histories; matter |
| Action terms | none | all action/source terms |
| Full equations | representation/group identities only | dynamics and field equations |
| Domain | regular local zero-order fiber | spacetime, sky-depth, and global domains |
| Boundary/regularity | regular invertible coframe and rank-two pair | singular, caustic, cut, and boundary strata |
| Topology | none | all global sectors and holonomy |
| Dynamical character | supplied additive parameter, not time | stationary and time-live dynamics |
| Branches | all constant O2/SO2 generator classes under declared gates | field-dependent and query-reduced branches |
| Stability | none | all stability questions |
| Regime | finite-dimensional local representation algebra | micro/middle/cosmological assignments |

Every dropped criterion could contain further structure. No result here closes the history, source,
bootstrap, `X_max`, observational, or matter programs.
