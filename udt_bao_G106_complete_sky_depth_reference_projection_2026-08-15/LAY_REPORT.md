# G106 lay report

The survey's random catalogue acts like a filter. It already knows how many objects occur at each
redshift and which parts of the sky the survey could observe. Those features are subtracted.

Consequently, simply making the orchestra louder with distance is not enough if “louder” only means
more or fewer galaxies. That radial change disappears in the normalized angular comparison.

What survives is a changing picture: the angular/screen/mixing response must bend or redistribute
the apparent sky differently at different depths. One common UDT history may make that angular
effect loud, then quiet, then loud again. Different redshift datasets would then see different
strengths or mixtures of the same underlying instruments.

G106 gives an exact smooth full-sky example of that behavior. Its outer depth windows have a pair
amplitude 169 times the middle window, all from one function and with no separate window tuning.
The numbers and shape are only a mathematical witness—not a fit or proposed universe.

The next real test is to obtain the angular-mode functions from one supplied complete metric history,
pass them through each survey's documented reference construction, and only then compare the jointly
predicted windows with sealed observations.
