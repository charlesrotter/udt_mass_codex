## Strongest route: a conditional restriction with an actual discriminant

The admitted one-geometry interpretation and ordinary proper clocks already give
`Z[g,Q]=omega_e/omega_o`. An additional positional prediction must restrict `g`
or the physical comparison assignment `Q`. This is SGE1's existing argument,
not a new selector. F3 composes a supplied ordered depth; it does **not** establish
that every actual null-clock depth is a difference of one spacetime scalar.

One testable **UNADOPTED** strengthening would be:

> For a specified physical observer congruence U on an open domain, all
> sufficiently short regular future null segments have
> `-log Z_AB = Psi(B)-Psi(A)` for one smooth Psi on that domain.

This is exactly G402/NCI1's tested property P. It gives the nonidentity geometric
restriction absent from TPS1:

```
xi = exp(-Psi) U,
C_ab = nabla_(a xi_b) - (div xi/4) g_ab = 0.
```

Equivalently, with `H=div U/3`, acceleration a and spatial shear sigma,
`sigma=0` and `alpha=a_flat-H U_flat` is exact. Locally this means zero shear
and `d alpha=0`; global periods also matter. All null directions and arbitrarily
short subsegments are essential. A finite set of successful rays is insufficient.
The proof contracts `nabla_(a xi_b)` with every null tangent: its null quadratic
form vanishes exactly when the tensor is proportional to g. This is the known
criterion, not new mathematics. It neither identifies DDR's E nor imposes Ric=0.

**Concrete test 1:** given an independently specified physical U, compute sigma
and `d alpha` from its metric derivatives. One nonzero component rejects P for
that `(g,U)`; zero local tensors establish the local criterion only at the
proved neighborhood scope, with periods separately checked if global P is
claimed. Do not optimize U until the result passes: replacing endpoint clocks
changes the experiment. Do not fit Psi to each ray; one common scalar is the
tested restriction. Passing P permits both signs of clock shift and many
different metrics.

Closest prior work: G402/NCI1 already owns this theorem, its diagonal homogeneous
classification and flat observer controls; LKT1 tests a different, more

class. This route's contribution is its placement against TPS1's missing

new method, or revival of C1's unadopted radiation/population assumptions.

**Strongest objection:** F3/W1/W4/W5 do not currently identify every actual null
comparison with that single endpoint scalar or select this U. G402 expressly

CES1's covariant preparation: a laboratory event p, future unit U, direction n,
receiver at `exp_p(L n)`, and its initial velocity fixed by parallel transport

supplied query, not the positive-rapidity ensemble used by CES1's stationarity
theorem; that theorem is not applied. Choose one regular outgoing null branch
and an ideal immediate return in a chronological normal domain.

L is proper length of the preparation geodesic, specified without using the
tested Z. Receiver motion is evolved under each metric's geodesic equation;
coordinate curves are not frozen across arbitrary metric changes. With emitter
proper emission label s, record outgoing p, actual return q and return map F.
Separately measure `R=c_E(F-s)/2` and `beta_rad=(pq-1)/(pq+1)`. Radar distance
uses measured delay, not a cosmological z-distance formula. R is an output when
initial L is matched; demanding both equal without justification would change
the protocol. Initial rapidity, proper labels, branch and units are matched.

**Finite exact control:** set c_E=1 in proper-time length units and use supplied
smooth metric controls

