# G206 lay report

G205 gave us a complete, causally well-behaved static UDT metric family. G206 turned on the
simplest missing live instrument: a common clock-and-ruler scale that can vary with time and
direction.

The good news is strong. This instrument cannot scramble which events can causally reach which
others. Every smooth positive version keeps the same light cones and the same global Cauchy slices.
The full pair kernel also hears the change exactly; it is not a correction pasted onto the answer.

But causal order and light-travel completeness are different. The common scale can shrink so fast
far away that a light ray accumulates only a finite amount of its new affine parameter. A bounded
live, direction-dependent example remains complete; a smooth rapidly shrinking example does not.

So the new instrument interlocks with the existing kernel, but not every possible way of playing it
is physically equivalent. G206 maps that boundary exactly. It does not yet say which time-live
common-scale profile Nature uses, and it does not invoke `X_max`, observations, matter, or a new
mechanism.
