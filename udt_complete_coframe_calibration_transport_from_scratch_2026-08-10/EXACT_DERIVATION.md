## 2. The exhaustive local line-transport class

Let `Q` be the correctly typed regular observer-query/path state space and let

```text
C -> Q
```

be the positive reciprocal calibration line. In a local positive section `s`, write a connection
as

```text
nabla^C s = 2 alpha tensor s.
```

Its parallel multiplier on a path `gamma` is

```text
Lambda_gamma = exp[-2 integral_gamma alpha],
delta_gamma  = -(1/2)log Lambda_gamma
             = integral_gamma alpha.
```

Therefore identity, concatenation, and reversal are exact for every smooth `alpha`:

```text
delta_identity=0,
delta_(gamma2 o gamma1)=delta_gamma2+delta_gamma1,
delta_(gamma^-1)=-delta_gamma.
```

Conversely, every smooth local linear parallel-transport functor on a real positive line defines
one connection by differentiation at the identity path. Thus the declared local class is
exhaustive: the space of such transports is an affine space over `Omega^1(Q)`.

Changing the local positive section by `s'=exp(2f)s` sends

```text
alpha -> alpha+d f.
```

In one fixed trivialization this changes an endpoint depth by the coboundary

```text
f(q)-f(p).
```

The curvature is `2 d alpha`; loop periods are `integral alpha`. Composition alone imposes none of
closedness, zero periods, endpoint descent, or a coefficient choice. This theorem covers the
preregistered smooth local positive-line class. It does not claim that every nonlocal or higher
categorical path functional is a line connection.

## 3. Why canonical metric transport has zero magnitude

For a supplied causal clock/ruler flag `F=(L subset P)`, the founded calibration character uses
the clock-line and pair-plane density ratios:

```text
delta_RF=(1/2)b_2-b_1.
```

Any metric-compatible tangent connection preserves the norm on `L` and the Gram determinant on
`P`. Hence

```text
rho_1=rho_2=1,
b_1=b_2=0,
delta_RF=0.
```

This includes Levi-Civita transport in an arbitrary time-dependent geometry. It also includes any
other metric-compatible connection with torsion.

The complete coframe supplies a second tempting canonical construction. If `theta^a` is declared
parallel, the resulting absolute-parallelism/Weitzenbock connection obeys

```text
nabla^W theta^a=0,
nabla^W g=nabla^W(eta_ab theta^a theta^b)=0.
```

It is therefore also isometric and gives zero reciprocal magnitude. It may have torsion and a
different path-carry law, and it depends on ownership of the coframe representative, but neither
fact creates calibration dilation.

The R17 normal `SO(2)` connection is likewise isometric. Its holonomy is a real geometric channel,
but a continuous homomorphism from compact `SO(2)` to `(R,+)` is trivial. Angular holonomy cannot
be silently relabeled as the missing positive scale.

This proves a general statement, not a stationary slice result:

> A nonzero reciprocal magnitude cannot be generated by canonical metric-compatible parallel
> transport. It must arise from a non-isometric comparison object or from comparing unnormalized
> states supplied by a complete pair/global relation.

## 6. Why independently rebuilt tapes still need a transition

Suppose the `AB`, `BC`, and `AC` pair surfaces are independently rebuilt. Each can carry an
independent reciprocal calibration offset:

```text

```

The direct/composite mismatch contains

```text

```

Nothing in local terminal algebra sets this to zero. A common global pair family would set the
offsets consistently; otherwise an owned transition must relate them. This is exactly the
carried-versus-intrinsic middle-state issue, now stripped of an unnecessary extra scalar-law
search.


Once that object is supplied, the reciprocal scalar and its reset are downstream algebra.
