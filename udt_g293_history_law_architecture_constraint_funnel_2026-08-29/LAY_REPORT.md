# G293 lay report

## What we learned

We tested the two simplest places where the missing UDT rule might have been hiding.

First, perhaps reciprocity itself tells the dilation value how to advance. It does not. If we add a
uniform measuring parameter, reciprocity says only that depth advances at a constant rate in that
chosen parameter. Rescaling the parameter changes that rate. Nothing identifies the parameter with
physical distance or time.

There is an encouraging qualification. A signed linear depth can naturally run from a large
negative regime, through a quiet middle near zero, to a large positive regime. So this calculation
does not rule out the native loud-quiet-loud pattern. It says only that reciprocity has not yet told
us what physical separation the uniform parameter represents, which relations Nature populates, or
how the screen and curvature values travel with it.

If zero dilation were additionally required to be a stationary resting state, constant scalar flow
would become trivial. That is a conditional observation, not a requirement UDT has adopted.

Second, perhaps the newly derived screen topology supplies the missing evolution. It does not.
Topology fixes a whole-number sector, but many smoothly different local screen-curvature patterns
live inside the same sector. We verified the required time-dependent mixed term so this is a lawful
connection statement rather than a stack of inconsistent snapshots.

## What this adds to the GR result

Earlier G259 already showed that if we assume a very specific familiar architecture—local,
metric-only, rank-two, second-order, and divergence-free—the vacuum equation collapses to GR. G293
does not promote those assumptions into UDT.

The new conclusion is that scalar reciprocity provides a natural shape in an uncalibrated additive
parameter, while topology fixes a discrete sector. Neither yet attaches the parameter to physical
separation or propagates the continuous screen state. A non-GR UDT law must leave at least one
assumption in the strict GR-classifying package and constrain more than the scalar depth and
topological sector label.

This does not force one mechanism. A local scalar curvature equation already lies outside the strict
rank-two classification without being higher order or nonlocal. The search is narrowed, not closed.

## Where the search now belongs

The cleanest next question is which complete state is sufficient to continue the geometry:

- metric derivatives alone;
- the metric plus independently owned screen/relation/source variables;
- or an irreducibly global relation network.

For any candidate, we can now demand a concrete test: it must reject at least one of the G286
same-past/different-future universes, preserve the exact active-angular GR quiet branch, and constrain
continuous screen curvature inside a fixed Euler sector.

No observation, fitted curve, source, action, distance scale, or `X_max` was used.
