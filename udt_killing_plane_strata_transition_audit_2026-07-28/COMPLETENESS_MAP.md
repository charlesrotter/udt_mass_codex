# Completeness map

This package is one stationary kinematic tile, not a complete UDT solution.

| Criterion | Covered here | Dropped / still open |
|---|---|---|
| Fields | complete metric response on the registered `K,V` plane; every full-screen shear retained | direct pair-screen off-blocks, variable `alpha`, independent matter fields |
| Action terms | none | complete native action and every variation |
| Full equations | none; off-shell geometry only | on-shell branch and profile selection |
| Domain/coordinates | complete chosen `R x S3` stationary control and quotient-base variation | other topologies, generic spacetime, nonstationarity, metrics with additional Killing planes/circles |
| Boundary/regularity | smooth finite complete `S3`; all projective Killing directions | physical seal/boundary functional |
| Topology | free Hopf-circle orbit class, noncompact helices, and exact lattice-preserving automorphism group | physical quotient/carrier selection and higher-isometry plane selection |
| Dynamical character | stationary only | time-live or evolving transition |
| Branch/bifurcation | constant/nonconstant depth, twist, causal, and transition strata | on-shell bifurcation diagram |
| Stability | not tested | every stability question |
| Regime of validity | exact stationary constant-`alpha` block-screen family | macro/micro map, density, scale regime, observations |

Dropped criteria could contain emergent structure. In particular, a native equation or global
bootstrap closure could decide which stratum is realized and whether a transition has physical
meaning. This audit neither supplies nor approximates that missing law.
