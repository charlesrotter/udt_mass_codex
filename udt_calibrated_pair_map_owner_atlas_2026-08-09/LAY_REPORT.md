# Lay report — who lays down the observer-to-observer measuring tape?

The last result gave us a reliable **reader**. If the geometry hands us a properly calibrated
two-dimensional tape between observers A and B, we can read from that tape exactly how much clock
and ruler dilation it contains. The angular and mixing parts of the full metric affect the answer
before it is read.

This audit asked the step immediately upstream: **who lays down that tape?**

The answer is now much sharper:

- The metric can lay down a perfectly good **local** tape once the observer question tells it which
  observer history, which direction, which event pairing, and which regular path branch to use.
- The metric alone does not choose one tape from all those possibilities. Acceleration, rotation,
  multiple geometric paths, and global topology can give distinct tapes.
- A stationary universe branch supplies a particularly clean tape, but its familiar clock-rate
  reading is not the full UDT positional reading unless the ruler channel also satisfies the
  reciprocal-area condition.
- Near a cut locus, asking for “the tape” can be mathematically wrong: the honest geometric answer
  is a set of branches.
- Two separately built tapes, A–B and B–C, cannot simply be snapped together unless B carries the
  same clock/ruler calibration from one to the other. Recalibrating at B inserts an arbitrary offset.

So the reciprocal-`c_E` breakthrough survives. We did not lose `phi`; we located the remaining gap
more precisely. The missing joint is a rule defining a **calibrated observer-pair relation**: what
the observer query contains, which geometric branch connects the pair, and how calibration is
carried when comparisons are chained.

In the tape-measure metaphor: we have derived the markings and how to read them. We now know the
metric manufactures all lawful tape shapes once the measurement setup is stated. What UDT has not
yet told us is the exact operational rule for choosing or carrying one tape through the entire
observer network.
