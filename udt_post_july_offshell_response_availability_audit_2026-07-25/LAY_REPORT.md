# Lay report

We checked the entire current filing cabinet for the missing joint, rather than
assuming it had to be invented.

The answer is: the joint is not already there.

Several folders contain real pieces of it. The Bach and Einstein routes show
how a chosen geometry would react to a small change. The Hopfion work shows how
a supplied matter field would react. The boundary work shows the form that a
moving edge would add. The global atlases show ways a complete finite universe
could be assembled.

But no one folder contains all of those reactions as one UDT-native system.
In particular, none says simultaneously:

- everything that is allowed to vary;
- how the local angular geometry reacts;
- how the universe's own mass and volume react on that same solution; and
- how its finite boundary, corners, and global joins react.

The working bootstrap currently checks a completed universe, like an inspector
examining a finished bridge. What is missing is the engineering rule that tells
each local beam how the whole bridge pushes back while the bridge is being
varied.

That is progress because it removes a major ambiguity: we are not failing to
notice a completed law buried in an old derivation. The next justified work is
to ask whether the metric, Reciprocity, finite-cell structure, and bootstrap
can derive that whole-to-local pushback rule. It is not yet time to guess an
action, scan densities, adopt the Hopf carrier, or run a GPU solve.
