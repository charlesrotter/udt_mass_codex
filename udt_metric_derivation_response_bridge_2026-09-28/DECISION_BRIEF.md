# What the original metric contributes

The original derivation is useful: it fixes a real relationship between clocks
and rulers and supplies the full geometry needed to check proposed equations.
This step identified a precise limitation of using only its single radial
dilation profile to find the equation. The calculation and review disposition
are recorded in [CLOSEOUT.md](CLOSEOUT.md).

In the original static, spherical setting, changing that one profile changes
the clock and radial ruler factors together. We calculated exactly which parts
of a proposed response equation this change tests. For the curvature-linear
family studied previously, those parts cancel for every profile. The angular
part of the equation can still be nonzero. A profile can therefore pass this
one test while failing the complete proposed equation.

There is a concrete example using the usual Einstein action, solely as our
existing unadopted comparison. If we insert the one-profile metric first and
then vary the profile, the calculation selects nothing: every profile passes.
Keeping an additional metric variation until after deriving the equations
restores the missing condition. This is a limitation of that shortened
calculation, not evidence that the original metric is wrong.

Keeping the angular comparison also recovers the already known conditional
Einstein family under UDT's reciprocity condition and the stated response-class
assumptions. The full conservation-identity test remains possible on the original
metric too. Neither calculation establishes that UDT requires the extra
assumptions used to select the response itself.

## What changed

We can now specify an exact failure to avoid: treating changes of the single
profile as though they test every part of the full metric response. We know
which comparison is missing and how to retain it in a mathematical check.
This is a more concrete result than simply saying that information is missing.
The broader squared-curvature comparison confirms that this cancellation is
specific to the tested response family, not a universal property of all equations.

## Where this leaves the search

The original metric should remain an exact consistency test for a candidate
law. The unresolved native step is to identify the full response that UDT's
reciprocity condition acts on, or derive an additional restriction on it from
the admitted premises. The single-profile variational shortcut examined here
does not supply that step. We have not proved that another postulate is needed.

Observed c as positional clock dilation remains the founding postulate.
No separate primitive transfer speed, new physical field, action or equation
has been adopted. This step returns a checked limitation and a more precise
route for further work; it does not announce a new UDT field law or launch
another campaign automatically.
