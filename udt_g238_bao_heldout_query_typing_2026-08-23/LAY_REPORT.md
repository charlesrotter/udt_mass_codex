# G238 lay report

We have a good **measuring machine**, but not yet the complete film needed to run this particular
measurement.

G237 froze eleven reliable relative distance notes from two supernova catalogues. BOSS asks for a
much richer object: how pairs of galaxies at many directions and depths are remapped, how the
screen bends between the observer and each galaxy, which branches are populated, and how that sky
is compared with the survey's random reference catalogue.

The newer UDT mathematics does show that the angular “orchestra” can arise naturally from the same
metric as the radial response. That is real progress: no bolt-on angular volume knob is needed.
But eleven radial notes do not determine the full continuous score. Infinitely many smooth scores
pass through those same notes and produce different angular evolution between them.

So we did not open the BOSS results and choose whichever continuation looks best. That would be
rebuilding scaffolding. The next honest step is to specify one complete observer-sky history and
source/branch query independently, then carry it into BOSS without refitting.
