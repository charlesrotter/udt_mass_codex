# Lay report — what was wrong, and what still stands

The simplest picture is that we confused a **rule for comparing two clocks** with a **physical
number painted onto every location**.

The original UDT construction really does derive the reciprocal response: if the comparison depth
is `delta`, one member of the clock/ruler pair changes by `exp(-delta)` and the other by
`exp(+delta)`. That part is solid.

But the derivation is handed `delta`; it does not yet tell us how to calculate `delta` for every
possible pair of observers. Writing a pointwise `phi` whose difference supplies `delta` is one
useful coordinate description. We mistakenly let that useful description become the universal
physical thing itself.

That matters because some later work then varied `phi` like a native field, gave it a chosen field
equation, and interpreted failures of that equation as failures of UDT. Those failures now mean
only: “this particular field/action branch does not work under these premises.” They do not block
the more general observer-to-observer theory.

Most of the hard mathematics survives. The metric atlases still describe possible geometries. The
stationary clock law still works in its stationary regime. The SNe result still works as a
conditional compatibility result. The two geometry-only mass-bearing branches and the separate
Hopf stability result keep exactly their earlier caveats.

So we do **not** need to redo everything. We need to redo an older result only when we want to use
it as current native physics and it depended on the unjustified pointwise field, action or source.
The remaining central gap is now cleaner: derive—or explicitly posit and test—the actual law that
turns a complete pair of observers and their connecting geometry into the comparison depth.
