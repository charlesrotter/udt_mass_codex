# Next bounded scientific step

## Recommendation

Perform a CPU-only, preregistered **global functional-degree-of-freedom and
constraint-rank audit** across all twelve registered completion classes.

For each class, inventory the complete coframe/metric profile functions,
coordinate/frame freedoms, angular `H` and connection `S` data, `phi` role,
cap/boundary/glue jets, and continuous/discrete moduli.  Then apply only the
already registered metric, Reciprocity, observer-frame, finite-cell, seal,
regularity, and observational-anchor constraints and determine:

1. how many functions and constants remain free;
2. which constraints are identities rather than equations;
3. which channels couple rather than factor;
4. whether the residual freedom is one missing functional relation, several
   independent relations, a boundary choice, or an entire source/response
   law; and
5. whether any completion class becomes inconsistent without privileging a
   desired topology or particle result.

## Why this precedes density bracketing

The present atlas proves that continuous readout values require a complete
profile and that no native density-to-geometry response is yet registered.
Bracketing an imported density now would tune an undefined input channel and
could create a numerical pattern with no UDT meaning.

Density bracketing becomes honest after the rank audit identifies a native
slot through which total proper mass/energy density enters.  The previously
authorized Lambda-CDM estimate can then be used only as a comparison center,
with a broad unfitted bracket and explicit provenance.

## Stop conditions

Do not select a completion, invent an action/source/coupling, posit a carrier,
run a PDE/time-live/GPU solve, fit observations, or promote an identity into a
closure law.  If the registered constraints leave arbitrary functions, report
their exact count and type rather than repairing the gap.
