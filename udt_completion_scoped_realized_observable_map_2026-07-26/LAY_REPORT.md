# Lay report — what the lock map found

Yes: the complex-lock metaphor is now more accurate than “tuning an
orchestra,” though both are useful.

We listed twelve broad ways the UDT geometry could close globally, and for
each one asked whether seventeen different geometric features could actually
be read from it.  That produced 204 checks.  We now know which tumblers depend
on which other tumblers and which pieces cannot even exist in a particular
kind of lock.

The useful finding is that the lock is not random.  Most of its continuous
features—volumes, curvature values, path transport, loop holonomy, angular
lengths, and observer separations—share one missing upstream object: a
complete metric/coframe profile across the whole finite cell.  Caps, seams,
mirrors, twists, and singular layers then decide whether those features join
up globally.

We also found and repaired a conceptual mix-up.  The draft had partly treated
three different effects as one:

- carrying an ordinary direction along an open path;
- carrying an angular phase around a closed loop; and
- the discrete twist used to glue a torus back to itself.

They are now cleanly separate.  This matters because a zero in one channel
does not make the others zero.

Some tumblers can already be described exactly.  We can classify cap pairs,
gluing twists, completion families, and the way angular shortest directions
change at ties.  But these are shapes in the lock, not the key.  They tell us
what a complete solution must respect; they do not choose the solution.

So the result is genuine progress, but not closure: we have a much sharper
diagram of the machine and a much smaller description of what is missing.  We
do not yet have a complete global metric profile, a native mass/energy
response, or the rule that makes all readouts mutually self-consistent.

The clean next move is not to guess a density or search for a lucky numerical
answer.  It is to count the remaining freedom in the complete metric itself:
which functions are genuine geometry, which are coordinates, which are fixed
by Reciprocity/finite-cell/cap/glue conditions, and exactly how many
functional equations or boundary conditions are still missing.  That is the
closest mathematical version of measuring every remaining tumbler before we
try to infer the key.
