# G269 map — null-transport mutual clock and screen interlock

Date: 2026-08-26

## Lay question

G268 proved that `sech(delta)` by itself is only another way to write the already known reciprocal
depth. The non-circular question is whether the metric supplies a second construction that deserves
to be compared with it.

Use one supplied regular null relation from observer event `A` to observer event `B`. The metric
already gives:

1. a directional proper-clock ratio from the null frequency at the two ends;
2. parallel transport of `A`'s unit clock vector along that same null branch to `B`.

At `B`, compare the transported `A` clock with `B`'s unit clock. Their Lorentz factor is a
reversal-even bilocal scalar. Its inverse is the candidate mutual-clock magnitude in G269. Unlike
`sech(delta)`, this construction is not defined by applying a function to `delta`.

The exact question is whether the two constructions always agree, agree only when the endpoint
clock remains in the transported clock/null plane, or are unrelated.
