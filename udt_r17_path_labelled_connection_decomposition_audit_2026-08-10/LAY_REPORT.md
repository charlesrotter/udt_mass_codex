# Lay report

The previous audit followed the angular compass while moving around one clock--distance cylinder.
This audit let the traveler move in every direction available in the supplied four-dimensional
geometry.

The compass still has a perfectly well-defined rule everywhere. If you hand it a route, it tells
you how the angular frame turns, and consecutive route segments join exactly. But the geometry
does not choose the route for you, and the compass transport preserves lengths—it is not yet the
physical dilation map between observers.

The most useful correction is that `lambda=-1` is only flat in directions involving the clock.
Sideways travel still sees curvature. `lambda=0` makes the transverse ruler especially clean with
respect to the Hopf geometry, but the rest of the metric still prevents a universal base-only
rule. `lambda=1` removes a different first-gradient contribution. These are three instruments
playing different parts, not three candidates from which the simplest should be crowned.
