# G349 completeness map

Date: 2026-09-04

G349 is one finite geometric null-map tile, not a spacetime or radiation solve.

| Criterion | Covered | Dropped / still open |
|---|---|---|
| Fields | Metric-derived null-exponential map and its full two-direction differential | Matter and radiative fields |
| Action terms | No action introduced | Native radiative, source, matter, or selection action |
| Full equations | Exact geodesic family plus complete transverse Jacobi differential on the supplied patch | Metric evolution and sourced equations |
| Domain/charts | Arbitrary smooth 4D Lorentz metric, compact sky patch, smooth regular affine cut | Spacetime singularities and rays leaving the regular domain |
| Gauge/covariance | Affine rescaling, sky coordinates, finite source observers, optional orientations | Preferred frame or detector selection |
| Boundary/regularity | Piecewise-smooth patch boundary; all internal rank strata retained | Null observers and spacetime boundaries |
| Topology | Every supplied path label retained separately; overlaps counted | Topology and physical path population |
| Dynamical character | Exact finite geometric ray map and differential | Which metric/history/rays Nature occupies |
| Branches | Injective, folded, repeated-sheet, rank-one, and rank-zero map behavior characterized | Exhaustive singularity normal-form census |
| Stability | Not tested | Metric or congruence stability |
| Physical transfer | No transfer law | Emission, absorption, brightness, luminosity, probability, detection |
| Regime | Finite compact supplied null patch inside a common regular geodesic domain | Observations, matter, scale, `X_max`, canon |

The test characterizes maps and multiplicity rather than filtering to injective or pre-caustic
patches. Dropped sectors can contain additional structure and remain open.
