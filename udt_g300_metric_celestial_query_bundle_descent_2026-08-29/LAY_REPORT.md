# G300 lay report

The metric mathematically lays out every direction around an observer. Those directions form a
complete sphere, and the full relation tells us exactly how that sphere transforms between two
supplied observer states.

The complete relation between two observers tells us exactly how that entire sphere is seen from
the other observer. Doing the comparison in two stages gives exactly the same result as doing the
combined comparison, and reversing the same relation reverses the map.

For every direction we insert, the metric produces a regular two-dimensional clock-and-ruler
calculation. The external review caught an important overstatement: this proves that the direction
is a regular evaluator input, not that current UDT premises make every direction a lawful physical
query. In short:

```text
the metric derives the complete geometric menu and how it transforms;
the present premises still require the lawful physical query to be supplied.
```

The complete relation still carries more information than any one two-dimensional view. The
metric naturality argument also shows there is no single universal direction selected from this
menu, though a supplied route can select one in a particular case. Lawful query-family ownership
remains open. Nothing was added to or removed from the UDT metric or reciprocal kernel.
