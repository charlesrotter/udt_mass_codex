# Lay report

We laid all 24 banked kinds of UDT geometry on a table and asked which parts of the observer
comparison instrument each one actually contains.

They do not all contain the same machinery. Some can carry angular history along a path but do not
produce dilation. Some possess a clock but no reciprocal ruler. One contains a complete set of
clock, ruler, shift, and angular instruments—but only after we supply the missing observer
relationship. Another supplies only a choice of directions, sometimes as an unresolved pair.

That gives us a real pattern: the metric supports different **kinds of instrument panels**.

The adversarial reviewer caught one bookkeeping overreach: one entry is a box containing several
different kinds of geometry, not a geometry with one combined panel. We now label that box only as
“member dependent” and read the actual instruments from its individual members.

What we have not found is the conductor that says which panel is physically active at a given
scale or circumstance. Nothing in the banked static branches labels one “subatomic,” another
“ordinary,” and another “cosmological.” Nothing yet chooses the actual observer-to-observer
connection.

So this advances the multi-regime search without pretending to finish it. We now know what the
candidate panels are and exactly which pieces each lacks. The next useful information must come
from dynamics, global closure, bootstrap self-consistency, or a genuine observer-query rule—not
from another rearrangement of the same static catalogue.
