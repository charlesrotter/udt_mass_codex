# Ponder map — what this audit is actually looking for

Lay picture: we now know that `Delta_phi` is the reciprocal dial to read after two observers have
been properly connected. This audit lays all banked kinds of geometric connection on the table and
asks what instruments each one actually carries. It does not label any instrument panel as “micro”
or “cosmic.”

Possible observations, none preferred:

1. every branch exposes the same instruments and none owns the connection;
2. branches expose different subsets, but the differences have no selected physical meaning;
3. a global completion restricts an otherwise free measurement channel;
4. a pinned source explicitly owns a physical pair relation;
5. the existing evidence is too incomplete to compare some branches honestly.

The first three are useful maps. Only the fourth would narrow the missing owner. The fifth is not a
failure; it identifies the exact upstream derivation still owed.

This is one static/banked evidence tile. It does not replace time-live exploration, solve the
complete metric, or establish physical regimes.
