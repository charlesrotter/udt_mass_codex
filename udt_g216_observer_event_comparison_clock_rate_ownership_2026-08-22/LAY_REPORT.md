# G216 lay report — what the clock joint actually is

The result is simpler than “the theory needs another clock rule.”

Each observer already has a natural clock: proper time measured by the metric. But if we use each
observer's own clock separately, both clocks tick at one unit per unit of themselves, so the local
reciprocal number is zero. That cannot describe a nonzero comparison.

The comparison comes from how the pair relation matches one observer's clock ticks to the other's:

```text
one tick of A's proper clock  <->  some number of ticks of B's proper clock.
```

The completed UDT depth is exactly the negative logarithm of that tick-rate ratio. Reversing the
pair inverts the ratio. Chaining A-to-B with B-to-C multiplies the ratios, so the depths add. These
are just the inverse-function rule and chain rule.

This means G215's “shared observer clock” needs more precise wording. It is the clock tangent made
by the observer **inside the supplied pair comparison**, not merely the observer's unit
four-velocity. Once the pair's event matching is supplied, the metric fixes the rate and no extra
clock coefficient is needed.

What is still open is which physical events are paired. We have narrowed the remaining local joint
to that pair germ; we have not invented or selected it here.
