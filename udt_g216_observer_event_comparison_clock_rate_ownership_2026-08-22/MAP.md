## Whole question

\[
\Phi_X=-\log T_X,
\qquad
T_X^2=-g(u_X,u_X),
\]

and descends across incident pairs when the same calibrated clock tangent and parameter are reused.
Does a physical observer's metric proper time already own this clock germ, or does a nonzero
completed scalar require the first jet of a supplied event-pairing/comparison parameter?

## Metric-led frame

- supplied timelike observer worldlines and observer events;
- metric proper time on each supplied timelike worldline;
- one supplied regular pair germ or pair map with pair-domain clock parameter `y`;
- G176 working completed-pair clarification and G215 scalar formula;
- no path, action, source, signal law, fit, `X_max`, or scaffolded kernel.

Let `tau_X` denote the observer's dimension-matched proper-clock coordinate and

```text
U_X = dz_X/dtau_X,       g(U_X,U_X)=-1.
```

For the pair-domain clock parameter `y`,

```text
u_X = dz_X/dy = (dtau_X/dy) U_X.
```

The candidate exact interpretation is therefore

```text
T_X = dtau_X/dy,
Phi_X = -log(dtau_X/dy),
delta_AB = log[(dtau_A/dy)/(dtau_B/dy)].
```

## Load-bearing warning

proper time can normalize the observer clock but cannot by itself be silently identified with the
nonzero G215 comparison-clock tangent. In the primary static chart, the nonzero result instead uses
the shared dimension-matched coordinate `y=x0=c_E t`, for which `dtau_X/dx0=exp(-phi_X)`.
