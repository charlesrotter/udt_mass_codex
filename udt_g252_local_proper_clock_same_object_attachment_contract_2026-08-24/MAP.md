# G252 map — local proper-clock same-object attachment contract

Date: 2026-08-24

## Whole question

G249 leaves one positive constant scale `ell` after a complete dimensionless metric history and a
regular branch are supplied. G250 proves that a nonzero proper-time interval has homothety weight
`+1`. G251 finds that the current metric corpus evaluates proper time but does not itself own an
independently calibrated datum attached to the identical interval.

G252 asks one deliberately smaller question:

> If an independently calibrated proper clock records the elapsed duration between two physically
> marked events on the same supplied regular timelike observer segment, does that one blinded
> attachment fix the single G249 scale without modifying the reciprocal kernel?

This is metric-led. The metric supplies the dimensionless proper-time evaluator; the clock record
is an explicitly supplied empirical attachment. The clock value is not opened, fitted, or used to
choose the contract.

## Same-object square

The attachment has four distinct legs:

1. a supplied regular timelike segment `Gamma` with marked ordered events `(p0,p1)`;
2. the dimensionless metric prediction `bar_tau[Gamma;p0,p1]`;
3. an independently calibrated clock record `tau_star[Gamma;p0,p1]` on those same events;
4. the equality `tau_star = ell * bar_tau`, which determines `ell` when both durations are positive.

Changing the observer segment, either endpoint, clock identity, or calibration breaks the
same-object contract rather than producing a competing UDT kernel.

- `pinned-by-THEORY` in this bounded calculation: the supplied G249 homothety family
  `g_ell=ell^2 bar_g`, the G250 weight `w=+1` for proper time, and the G216 proper-time evaluator.
- `CHOSE_OPERATIONALLY`: one observer segment, two ordered event markers, and one independently
  calibrated clock are fixed before any value is read.

- `OBSERVED_CONVERSION`: `c_E` converts the attached duration to a clock-equivalent length after

- `OPEN`: complete physical-history selection, global observer population, branch population, and

- `pinned-by-HABIT`: none.

No chart, boundary condition, source model, material law, angular aggregation, radiative transfer,
caustic prescription, `X_max`, SNe, BAO, CMB, or protected local work enters.

## Conclusion ceiling

At most G252 can prove a conditional one-value calibration contract and exact consistency tests for
additional frozen attachments. It cannot select a history, observer population, branch, clock
value, fit, prediction, or ontology, and it cannot promote the attachment into a new kernel law.
