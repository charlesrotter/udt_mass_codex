# G286 lay report

We now know exactly what the current mathematics does and does not do.

It already gives a complete local description of a pair of observers: not only their clock and
redshift relation, but also how nearby directions focus, stretch, and shear. It also guarantees that
different coordinate descriptions agree and that comparisons can be carried consistently.

But those rules do not yet say what the next local state must be.

The test used two perfectly regular universes that are identical throughout their entire past and
match to every derivative at the dividing surface. Immediately afterward, one remains flat while
the other develops a small tidal distortion. All current UDT consistency rules accept both.

That means the missing piece is no longer vague. We do not need to rebuild the metric or add the
angular sector. We need a native rule that tells the already complete local metric state how it may
continue—or a global rule that rejects one of the two continuations.

An observation can later set constants inside that rule. It cannot honestly replace the rule by
drawing the continuation directly from the data.
