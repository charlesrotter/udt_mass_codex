# G256 preregistration — primary-state value-closure rank

Date: 2026-08-25

## Whole question

Do the currently owned primary UDT metric and completed observer-relation equations determine the
numerical reciprocal depth/profile and time-live scalar-state values, reduce them to finitely many
constants, or leave function-valued freedom as the number of sampled events grows?

This is `METRIC_LED` and `OBSERVING`. It does not target a preferred profile, loud--quiet--loud
shape, observational fit, `X_max`, or familiar field equation.

## Exact bounded arena

The derivation will join three views of the same supplied primary state:

1. a finite connected matched-clock observer/event graph with exact reciprocal edge depths;
2. the primary static-spherical radial metric with angular responses through the first two radial
   jets of the same profile;
3. a finite time-live event graph carrying the same reversal, actual-composite, and positive clock
   first-jet laws.

The graph size `N` is free and swept. The continuum conclusion requires an explicit arbitrary-`N`
construction and an exact smooth interpolation theorem; no finite grid alone can establish it.

## Closure criterion

After one reference calibration, let `nu(N)` be the dimension of freely assignable primary scalar
state values compatible with every frozen native equation in the bounded arena.

- `FINITE_NATIVE_FAMILY`: `nu(N)` is bounded by one fixed integer independent of `N`, and the frozen
  sources own the algebraic or differential relation that propagates the values.
- `GLOBAL_VALUE_LAW`: a frozen source owns a natural nonidentity global relation that rejects at
  least one preregistered regular valuation while retaining another.
- `FUNCTION_VALUED_PRIMARY_STATE_REMAINS`: an exact arbitrary-`N` construction gives
  `nu(N)>=N-1`, arbitrary finite radial jets admit smooth realization, and no frozen source-owned
  nonidentity relation rejects the construction.

Merely reconstructing vertex values from edge values, metric components from pair planes, or jets
from angular outputs does not count as closure.

## Preregistered tests

1. **Scalar graph rank.** For complete and independently generated connected graphs with
   `2<=N<=12`, compute exact incidence/cycle ranks. Require a general proof, not only the sweep.
2. **Angular interlock.** Use the exact primary formulas
   `A_parallel=exp(-2 phi)(2 p^2+p-q)` and
   `A_perp=1-exp(-2 phi)(1+p)` to classify whether they constrain or reconstruct `(p,q)` when their
   output values are not separately prescribed.
3. **Smooth-jet realization.** Construct an exact Hermite interpolant for arbitrary rational
   `(phi,p,q)` data at distinct positive radii and verify every requested value, first derivative,
   and second derivative exactly.
4. **Time-live carry.** Repeat the graph-rank and smooth-interpolation test on event-clock
   potentials. Reversal and actual composition must be checked, while higher clock germs remain
   visible rather than frozen.
5. **Owner gate.** Every claimed cross-event value equation must have one exact frozen-source owner,
   be natural, and reject a registered regular valuation for a reason other than a chosen query,
   profile, observation, or boundary.

## Certification and falsification

- Production may use symbolic algebra and exact rational arithmetic only.
- The independent verifier must not import production code or read its result.
- Hostile controls must catch a deleted graph edge, corrupted cycle, collapsed `N`-dependent
  nullity, failed Hermite jet, angular equation promoted from output to residual, and an unowned
  finite-family condition.
- A fresh zero-context adversarial review is required before banking.

`FUNCTION_VALUED_PRIMARY_STATE_REMAINS` is falsified if any frozen native equation bounds
`nu(N)` independently of `N` or rejects the arbitrary Hermite family. `FINITE_NATIVE_FAMILY` is
falsified if exact compatible freedom grows with `N`. `GLOBAL_VALUE_LAW` is unavailable without an
exact source owner and a preregistered accepted/rejected valuation pair.

## Maximum conclusion

function-valued scalar state. It cannot prove that no future UDT value law exists, demote the metric
or kernel, select empirical reconstruction, or authorize an ODE/PDE/GPU solve. A positive result
licenses only the exact mathematical closure type it derives; observations may calibrate constants
only after the family is finite.
