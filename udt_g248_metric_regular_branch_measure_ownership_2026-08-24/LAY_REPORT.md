# G248 lay report

We found one more gear that the metric itself supplies.

For one regular lightlike connection from observer A to observer B, two things matter:

- how their clocks compare, \(r\);
- how much a tiny bundle of neighboring directions has spread, \(A\).

The metric combines them automatically as

\[
\text{incidence density}=\frac{r}{A}.
\]

In plain language: a branch counts more strongly when clock reciprocity enhances it and less
strongly when the same bundle has spread over a larger screen area. This is not a fitted mechanism
bolted onto the kernel; it comes from measuring the actual geometric intersection of A's null sky
with B's worldline.

The important limit is that this is not yet “the probability that Nature chooses this branch.” The
metric also has other legitimate measures—sky area, phase-space volume, and simple branch counting.
They answer different questions. A source population or detector rule is still needed before the
incidence density becomes an observed catalogue prediction.

So this is real narrowing, not final calibration: the orchestra's clock and angular instruments now
interlock in a native formula, but the score telling us what sources exist and how observations
aggregate them remains open.
