# G113 adversarial whiteboard record

Date: 2026-08-16

Three fresh read-only agents began from the bounded source universe with distinct roles. None read
the protected packages.

## Founding minimalist

Initial position:

- the local common object is `H=F* g`;
- the smallest closed carrier along one ray is the first-variation/Jacobi phase-space propagator;
- terminal depth, screen expansion, shear, and holonomy are typed readouts rather than one scalar;
- G112 proves non-regression, not history selection.

After cross-critique, this role accepted the exact central spherical chord but rejected static P1
promotion because `phi'(0)` is nonzero and curvature diverges. It warned that a same-ray R17
composition replay is mostly a fundamental-matrix identity and that a time-live P1 reconstruction
must reopen source/query ownership rather than hide it.

## Scaffolding hunter

Initial position:

- old complete-strain depths and stationary `delta_a` are diagnostic witnesses, not candidate laws;
- `B,Q,S,Y,Z` attribution is representative-dependent when `E dF` is fixed;
- arbitrary point-source screen amplitude and arbitrary local `J` disappear on the G110 subclass;
- branch, carry, source, and transfer types must remain separated;
- G112's assigned isotropic screen is not generally derived.

This role independently derived the static chord and found the center obstruction. It additionally
noted that P1's observed interval is annular and does not itself measure the singular center. Its
final recommendation was a common-source three-observer type gate, followed by an outcome-blind
time-live regular-jet census.

## Empirical skeptic

Initial position:

- G110/G111 are substantive geometry; G112 is an algebraic retyping and likelihood replay;
- SNe constrains only `2 Phi + (1/2)log det D_sky` under the conditional transfer;
- pair depth, screen determinant, and determinant-preserving shear/rotation are not separately
  identifiable from magnitudes;
- bootstrap is premature.

After cross-critique, this role accepted the static chord and center no-go. It stressed that a
same-ray propagator composition is gauge-covariant and largely automatic, while the real test is
whether different observer/source rays can be assembled with lawful path labels, calibrations,
and holonomy. A genuine observational prediction requires history and transfer frozen before the
outcome is opened.

## Common ground

All three roles agreed on the following bounded synthesis:

1. G110/G111 reveal a real metric-native local assembly, not a fitted scalar score.
2. G112 is useful non-regression but does not prove one complete history.
3. The static spherical chord binds `phi_pair` and `D_sky` conditionally.
4. Exact P1 static inward extrapolation is not a smooth point-observer center.
5. Treating a null-cone observational chord as a static spatial profile is the exposed category
   error.
6. The next gate must type a common-source observer network before an outcome-blind time-live
   regular-jet census.

No role claimed that this selects a physical history, native flux law, `X_max`, bootstrap closure,
action, source, matter, or mass.
