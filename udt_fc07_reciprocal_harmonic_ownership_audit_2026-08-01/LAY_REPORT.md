# Lay report — one lock tumbler is now connected

The earlier work found a special “global ruler” made by solving a problem over an entire completed
cell. We did not know whether it was part of UDT's original clock-and-ruler structure or just a
separate geometric feature.

It is the same ruler direction.

We allowed the UDT depth `phi` to change from place to place and tested a broad, clearly chosen
family of ways the clock/ruler and angular sectors can mix. This family includes the already
registered mixing patterns but is not itself a newly derived physical law. Across all four tested
global branches with only one possible global ruler, none of that mixing knocked the ruler off its
original UDT direction.

The angular sector does affect it in another way: it changes the ruler's local calibration. Think
of a violin string whose direction is fixed, while the body of the violin changes how strongly it
resonates. Here the angular cross-sectional area and the geometry of the entire cell jointly set
the strength of the harmonic ruler at each location.

That is a real connection between previously separate parts of the metric. In the lock metaphor,
we have shown that one global tumbler is physically linked to the original reciprocal tumbler.

We have not yet shown what turns the lock. The global calculation normalizes the ruler, but it does
not force the universe to choose a particular `phi`, angular shape, curvature, or density. This
specific machinery works throughout the smooth nondegenerate family; it does not switch on only in
a narrow curvature range.

Your limited-density bootstrap idea therefore remains alive but moves one step downstream. A
future native equation may say that matter-supporting configurations exist only when this linked
geometry falls within a narrow global range. This audit found the linked geometry; it did not find
that equation or the range.
