# G186 lay report

The cleaner kernel has now been tested with angular motion genuinely switched on by the supplied
observer-pair geometry—not by adding a correction afterward.

The result is surprisingly simple. The metric routes different angular effects to different
instruments:

- angular motion of the observer's clock direction changes the reciprocal depth;
- angular tilt of the ruler changes how much calibrated ruler is laid along the relation;
- overlap between those motions creates shift;
- the remaining two perpendicular directions form the local observation screen automatically.

This also explains the exact SNe non-regression. In the radial SNe query the clock direction is
static and the pair ruler is radial, so the scalar depth naturally reduces to the old \(\phi\)
result. Nothing was tuned off. Angular sky area remains a separate live channel.

The result is local. It does not yet propagate a beam across the universe or replace P1 R(Z).
