# G140 lay report

The metric can tell us that all the pieces belong to one perfectly consistent geometric stage
without telling us which pieces form one positional sentence.

We placed four static observers in one flat spacetime and used all six pair surfaces. Because this
control has one constant metric and a natural affine identification between locations, those
surfaces contained enough pooled information to reconstruct every constant component exactly. Yet
their terminal pair numbers could not be given any directions that made them add consistently
around every triangle. We then rearranged four observers in the very same metric and obtained
another six-pair network whose triangle values did close.

So “enough pooled observer views to know this constant metric” and “one composable positional
network” are different requirements. The provisional G139 rule filters the latter: routes in one
positional family must agree on endpoint position, while orientation memory may remain
path-dependent.

The metric pullback itself supplied only an unoriented number. We supplied the edge directions for
the test and checked every possible sign choice; none repaired the nonclosing network. This does not
add a new spacetime equation or choose a universe. It tells us more precisely what is still missing:
the metric must natively identify the physical inverse comparison and which complete pair queries
belong to one positional family.
