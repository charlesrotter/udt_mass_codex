# Lay report

The metric now looks less like one mysterious dial and more like an instrument panel. It carries:

- a common-size dial (`kappa`);
- the clock-versus-ruler imbalance (`phi`);
- a pairing/shift setting (`beta`); and
- an angular compass that remembers the path (`U_gamma`).

The original UDT postulates ask one very specific question: how has the clock side changed relative
to the ruler side? Once a complete observer query has supplied the actual calibrated comparison
tape, that question has one unique answer in its proper mathematical class: the change in `phi`.
The postulates do not construct the tape from bare observers. Common scale cancels because it
changes both sides together. The angular and shift information does not disappear; it belongs to
different instruments.

There is an important limit. Mathematics lets us invent infinitely many other readings from the
same panel. The founding postulates do not tell us to use those readings. So we have identified the
native reciprocal microphone, not the complete physical policy for which microphones an observer
uses in every regime.

The angular orchestra still matters: it helps build and modulate the complete pair geometry before
the reciprocal `phi` reading is taken.
