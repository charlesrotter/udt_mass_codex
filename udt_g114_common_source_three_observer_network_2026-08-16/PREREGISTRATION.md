# G114 preregistration — common-source three-observer network

Date: 2026-08-16
Mode: metric-led, exact, no solve, no observational outcomes

## Whole question

For one supplied smooth time-oriented Lorentz metric, three supplied calibrated observer
worldlines, and one supplied common source event or source worldline, determine the smallest typed
network in which the full observer-exponential differentials can meet and compose without
identifying unrelated `2x2` matrices or appending an external orchestra score.

The audit will determine:

1. which ray, screen, pair, phase-space, and source-junction objects the metric and query own;
2. the exact composition, reversal, covariance, and loop laws;
3. whether a common source event alone canonically identifies the three ray screens;
4. whether caustics obstruct the full Jacobi phase-space carrier or only its position block;
5. whether terminal `phi_pair` values form an edge cocycle without an explicit common reciprocal
   calibration;
6. which source transfer, occupancy, branch weight, history, and physical-selection slots remain
   open.

## Bounded regime

- one supplied smooth time-oriented four-dimensional Lorentz metric `g`;
- three supplied observer worldlines `z_A,z_B,z_C` with proper-clock calibration;
- one supplied source event `s`, or one marked event on a supplied source worldline;
- every regular exponential preimage of `s` retained as a path-labelled branch;
- one full first-variation phase-space propagator per ray;
- terminal pair metrics and angular screen maps kept as different typed blocks;
- no metric solve, time-live history census, observational exposure, fit, source model, action,
  bootstrap law, `X_max` realization, matter, or signalling claim.

Three observers are used because a based triangle is the smallest loop test. This is not a claim
that every physical observation requires three observers.

## Exact candidates to test

For ray branch `b_i` from observer `i` to the source, let `P_i` be its full screen Jacobi
phase-space propagator and let `C_ji` be a correctly typed source-junction map from the endpoint
phase fiber of ray `i` to that of ray `j`. Test the conditional carried edge

```text
R_ji = P_j^-1 C_ji P_i.
```

For `A -> B -> C -> A`, test whether

```text
R_AC R_CB R_BA = P_A^-1 (C_AC C_CB C_BA) P_A.
```

The equality is a typed algebraic candidate, not a physical-selection rule. Also test the exact
common-trivialization case `C_ji=B_j^-1 B_i` and a path-labelled nontrivial source holonomy case.

## Catch controls

The audit fails if it:

1. multiplies two endpoint Jacobi `2x2` position blocks merely because their dimensions match;
2. filters a branch because `det D=0` while the full phase propagator remains regular;
3. subtracts independent terminal `phi_pair` values as a physical edge depth without a common
   reciprocal calibration local system;
4. silently sets a source-junction map to identity;
5. treats a common event as automatically supplying a source rest frame or cross-ray screen map;
6. uses Pantheon+, DES, BAO, CMB, P1 parameters, or desired loud/quiet behavior;
7. promotes a composition identity into a history, branch, source, or transfer selector.

## Certification contract

- exact symbolic or rational verification of edge composition, reversal, covariance, and loop
  reduction;
- an independently implemented finite-dimensional replay;
- an explicit caustic witness with singular Jacobi position block and invertible full propagator;
- complete type and premise ledger;
- adversarial review before any `DERIVED` or `VERIFIED_WITH_CAVEATS` landing is banked.

## Falsification contract

The candidate network architecture is blocked in this scope if the carried edges cannot be typed
without identifying unrelated fibers, if the claimed loop reduction fails exact algebra, or if the
full phase propagator is noninvertible at an ordinary Jacobi caustic.

## Maximum conclusion

At most this audit may derive a conditional common-source network evaluator and identify its exact
remaining source-junction/calibration ownership. It may not select a physical history, universal
observer protocol, source law, branch weights, observation, `X_max`, bootstrap, action, matter, or
mass.
