# Lay report

We asked whether a UDT law could say, “this must work for every possible observer pair,” without
choosing one preferred observer.

The answer is yes. Think of checking a sculpture from every viewing angle. The individual view is
angle-dependent, but the rule “every view passes” gives one observer-independent verdict about the
sculpture. No preferred camera has to be installed in it.

In the exact local example, checking every observer direction removed nine kinds of directional
distortion and left only the part proportional to the metric itself. That large stack of
observer-dependent checks could be rewritten as one nine-component spacetime tensor condition. It
was much stronger than checking a single scalar number, but it did not escape spacetime tensor
language altogether.

Global path checks are different. Two spaces can look perfectly identical in every small
neighborhood yet rotate or reflect a carried frame differently after a complete loop. No finite
local curvature test can see that difference. A universal loop rule can.

So the candidate architecture is real: UDT could constrain the metric through all observer pairs or
paths without adding a preferred observer. But we still have not derived the actual rule that every
observer or path must satisfy. Reciprocity supplies the comparison machinery, not yet the missing
equation.

One more warning was confirmed: combining all failures into a single “sum of squares” may preserve
which solutions are zero while destroying the equations' first-order behavior. That shortcut cannot
be used to manufacture an action.
