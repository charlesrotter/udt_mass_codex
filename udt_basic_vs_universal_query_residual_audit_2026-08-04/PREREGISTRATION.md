## Whole question

Does requiring one equivariant metric residual `L(g,q)=0` for every observer-pair/path query `q`
force the law to reduce to a basic spacetime relation, or can a genuinely nonbasic query residual
impose additional metric-native content without selecting a physical observer section?

The audit must distinguish:

1. operator descent: whether `L` itself is the pullback of a base object;
2. solution-set descent: whether `for all q, L(g,q)=0` defines an observer-independent subset of
   metric configurations;
3. finite local tensor reduction: whether the universal family is equivalent to finitely many local
   tensor/coefficient equations;
4. variation equivalence: whether a proposed base replacement has the same linearized/tangent
   constraints, not merely the same zero set;
5. global/path reduction: whether a universal path law is equivalent to a global metric property
   even when no finite local jet detects it.
