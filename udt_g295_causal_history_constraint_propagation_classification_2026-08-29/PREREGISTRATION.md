# G295 preregistration

Date: 2026-08-29

## Frozen question

Classify, without choosing a physical formula, whether W6 and the current metric-native network
architecture reduce the missing object from “constraint plus update” to one covariant nonidentity
history condition, and determine the exact compatibility requirements on any slice-level
factorization.

## Candidate classes fixed before outcomes

1. `IDENTITY_DESCENT_ONLY`: pair reversal/composition, overlap, gauge, and screen descent.
2. `INSTANT_GLOBAL_PROJECTION`: project a simultaneous state onto a nonidentity constraint surface.
3. `SLICE_CONSTRAINT_PLUS_CAUSAL_UPDATE`: supplied slicing, constraint, and cone-sparse update.
4. `WHOLE_HISTORY_COVARIANT_CONDITION`: one nonidentity condition on complete histories; any
   constraint/evolution split is representational.
5. `INITIAL_OR_BOUNDARY_DATA_ONLY`: select a member without a propagation law.

## Exact tests

- For a full-row-rank linear constraint `A x=0` and update `x'=U x`, verify constraint preservation
  iff `A U=R A` for some residual propagation matrix `R`.
- Verify that this condition and a declared causal sparsity mask are logically independent.
- Exhibit a dense global projection that preserves a constraint but violates the causal mask.
- Exhibit multiple distinct cone-sparse updates preserving the same nonidentity constraint.
- Exhibit multiple admissible initial states under one fixed causal update, proving that a law family
  and one realized history are different objects.
- Verify that incidence/cycle identities remain valid under arbitrary vertex-potential updates and
  therefore remain reconstructive rather than nonidentity value laws.
- Retain screen/frame variables as arbitrary additional state components; scalar depth alone may not
  stand for the complete state.

## Acceptance gates

1. **Ownership:** no free constraint/update is labelled derived UDT physics.
2. **Nonidentity:** a viable law type must be capable of rejecting at least one G286-style future.
3. **Causality:** controllable response must respect the supplied metric-cone support mask.
4. **Propagation:** constraints must be preserved by the update on admissible data.
5. **Naturality:** the whole-law type must admit a diffeomorphism/gauge-natural statement.
6. **Screen retention:** complete frame/screen carry remains upstream of readout.
7. **No targeting:** no desired profile, observation, scale, `X_max`, source, or action enters.
8. **Independence:** a second implementation must avoid importing production code or outputs.

## Preregistered landings

- `CURRENT_STRUCTURE_SELECTS_A_UNIQUE_CAUSAL_HISTORY_LAW` only if one candidate formula follows
  without a new premise and rejects a registered twin.
- `ONE_COVARIANT_HISTORY_CONDITION_IS_THE_MINIMAL_TYPE__FORMULA_OPEN` if the two-part architecture is
  only a sliced representation and current structure fixes the type but not the law.
- `CONSTRAINT_AND_UPDATE_REMAIN_IRREDUCIBLY_SEPARATE` if no covariant unification is lawful.
- `W6_ADDS_TYPING_ONLY__ARCHITECTURE_REMAINS_UNSELECTED` if even the minimal type is not narrowed.

## Certification ceiling

No outcome may be promoted to a field equation, complete spacetime, physical observer population,
global present, empirical prediction, or canon.
