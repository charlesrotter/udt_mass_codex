# G263 lay report

There are two different ways to “change the sign,” and we had sometimes blended them together.

First, we can look at the same observer pair in the opposite direction. Nothing about the universe
changes. The clock/ruler exchange simply inverts. This naturally has a directionless strength—how
far the pair is from the quiet middle—and a sign telling us which way we are reading the pair.

Second, we can replace the entire metric profile by its negative. That is not merely turning around
to view the same pair. It changes the metric itself. Although its scalar redshift factor reverses,
its acceleration, geometric mass-shaped quantity, curvature, and angular response need not be
mirror images.

This means negative `phi` was never excluded, but it should not be treated as an automatically
symmetric copy of positive `phi`. The primary metric permits very different behavior on the two
sides. It also permits exceptional histories whose angular response stays quiet even at either
extreme, so the metric still has not forced every instrument into one loudness curve.

The clean intuitive picture is therefore:

```text
same pair, opposite arrow = exact reciprocal inversion in the same geometry
opposite whole profile    = generally a different geometry
```

That distinction is native and removes a misleading one-sided reading of the earlier work.
