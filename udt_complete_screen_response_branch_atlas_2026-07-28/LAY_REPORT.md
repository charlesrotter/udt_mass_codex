# Lay report

We finally let the whole angular “orchestra” onto the score instead of treating `lambda` as the
only instrument.

At any point, a tiny two-dimensional angular patch can do four basic things:

- grow or shrink evenly;
- rotate;
- stretch one way while squeezing the other;
- perform the same uneven stretch on axes turned 45 degrees.

The complete branches already in the repository do not use all four.  The simple round and
squashed examples rotate.  The newer twisted complete geometry can grow/shrink evenly and rotate;
when its depth varies in a genuinely angular way, it also couples the clock/ruler pair to the
angular screen.  That coupling is real metric structure, not an added force.

The two uneven-stretch instruments—shear—did not sound in any response we could calculate exactly.
But this is not evidence that the metric forbids them.  Our most developed complete coframe gave
both angular directions exactly the same weight from the beginning.  In musical terms, we wired
those two instruments to the same control knob.  Of course they could not play different notes.

So the advance is twofold:

1. We now know which pieces of the full angular vocabulary the existing complete geometries really
   exhibit: even scaling, rotation, and pair/angular mixing.
2. We found a precise reason the missing shear could have stayed hidden: it was frozen by the
   equal-angular-weight ansatz, while the harder path-dependent shear calculation was never done.

This does not close UDT.  It gives a much cleaner next experiment: release the angular screen as a
general positive two-by-two geometry, build complete finite cells without asking for a particle or
a known force, and see which combinations survive globally.
