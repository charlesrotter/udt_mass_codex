## Preregistered gates

1. **Founding algebra:** independently reproduce `P^T K P=K -> uv=1`, continuous composition ->
   `D(delta)=diag(exp(-delta),exp(+delta))`, and the declared primary metric readout.
2. **Complete-pair order:** verify algebraically and by source trace that angular, screen, shift, and
   mixing enter `h=J^T E^T eta E J` before any terminal reciprocal/projective readout.
3. **Status preservation:** the audit must fail if supplied depth/history/germ, W1, W5, or an
   observational import is relabelled `DERIVED` beyond its source-owned grade.
4. **Executable dependency cut:** build a file/formula dependency graph from the current G278
   executables backward. A historical package is non-load-bearing unless imported, read, or required
   as an explicitly frozen artifact.
5. **Scaffold exclusion:** fail on executable dependence upon P1, G116, G189, a post-readout
   orchestra coefficient, a fitted profile, a preferred `K`, `X_max`, a Lambda-CDM distance, or a
   protected package.
6. **Import subtraction:** removing radiative/Cepheid/optical/DES imports must leave the native
   dimensionless metric/kernel derivation intact while making the absolute G278 attachment or
   holdout unavailable. Removing a genuinely native dependency must break its downstream native
   edge.
7. **Independent reconstruction:** a new implementation may use SymPy/NumPy and source equations,
   but must not import production modules or stored result JSON. It must verify the load-bearing
   identities on exact symbolic cases and deterministic random regular matrices.
8. **False-pass controls:** mutations for covariant rather than reciprocal scaling, angular
   post-processing, W1/W5 promotion, preferred-resolution selection, hidden P1, hidden `X_max`, and
   hidden Lambda-CDM distance must each be caught by a named guard.
9. **Repository gate:** package checks, `git diff --check`, the repository premise verifier, and the
   applicable no-shortcuts test harness must pass or be explicitly scoped with raw failure evidence.
10. **Blind adversarial gate:** no final positive or negative provenance verdict is banked before a
    fresh zero-context adversarial review independently reruns the key checks.

## Falsification contract

The strongest positive landing is falsified by any executable or algebraically load-bearing edge
from the prohibited scaffold list into the native kernel, by any observational attachment disguised
as a derived kernel identity, by failure of complete-pair-before-readout order, or by inability of an
independent implementation to reproduce the native identities without production outputs.

## Scope ceiling

Even a full pass certifies provenance only for the bounded current chain. It does not prove that UDT
is physically correct, that W1/W5 are necessary, that G236 is representation independent, that the
imported light law is native, or that G278 owns a unique scale.
