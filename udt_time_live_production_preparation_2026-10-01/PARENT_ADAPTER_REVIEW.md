# Separate parent review of the production extraction adapter

The runtime reviewer authored assemble_campaign.py and the keyword-argument
refactor of assemble_windows.py. Parent `/root` independently inspected those
sources, the generator change, preserved previous editions and the author's
regression receipts. This is actual different-context source review, not a
claim that the author independently reviewed their own implementation.

The legacy function keeps the same default source/run/receipt/output routes and
unchanged checkpoint authentication, shape/tick and payload extraction. Its new
parameters permit explicit manifest-derived paths. The author compared all
Kasner output arrays against the earlier windows and actual supervisor windows
against uninterrupted engineering fields; these remain attributed regression.

The adapter authenticates queue/source/spec/initial bindings, actual launch and
attempt receipts, stdout/stderr, completed endpoints and checkpoint signatures.
The receipt bridge declares its schema-adaptation role. A successful assembly
does not certify equations or convergence. It reserves uncompressed state/window
bytes plus bounded overhead before writing, includes analysis in the production
storage accounting, and authenticates previously assembled outputs. Partial
assembly remains a diagnostic rather than being overwritten.

Parent checks execute the real adapter on copied control records in three
negative cases: insufficient output budget, changed stdout hash in an attempt
receipt, and missing initial-artifact binding. Each is rejected before creating
analysis outputs. The launch-binding repair is included in the second captured
run; the first source/test and successful result remain preserved. No scientific
array, original receipt, solver or GPU execution was modified by these tests.
See checks/adapter_parent_launch_bound.stdout and its capture provenance.

Disposition: ACCEPT_WITH_LIMITS for this explicit manifest-controlled extraction
workflow. No exhaustive corruption, race, crash or arbitrary externally supplied
manifest safety claim is made. Execute extraction serially after the queue is
paused/complete so the resource reservation is not shared with another writer.
The production dispatch keeps every original-equation and refinement gate.
