# G255 lay report

We did not lose a finished universe-building equation in the last ninety runs.

What those runs built is more like a very complete instrument panel. Given a UDT metric and a real
observer relation, it now knows how to read the reciprocal clock/ruler response, angular image
changes, branch structure, transport, and how many such views fit together into one metric.

The confusing phrase “choose a physical history” was too broad. We are **not** choosing one metric
from every geometry anyone can write down. The UDT metric already defines the kind of machine. What
is still missing is the score: the actual values of its depth/profile and time-live instruments at
all separations and times.

One apparent shortcut really would close much of that gap—all-direction isotropy—but the earlier
work correctly showed that UDT does not currently own that assumption. The other tempting
shortcuts merely check, transport, or reconstruct values that were already supplied.

So G254's roadmap survives, with sharper wording: do not launch an ODE or GPU solve until the metric
itself yields a value-closing relation. That relation might be an equation, but it could also be an
elegant global consistency rule or a finite algebraic family. After it leaves only a few constants,
observations may legitimately calibrate those constants and then test the model elsewhere.
