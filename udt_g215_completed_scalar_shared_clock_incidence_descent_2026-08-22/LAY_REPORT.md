# G215 lay report

We found that the remaining three-observer problem was partly framed too broadly.

Each completed observer pair still has its own ruler direction, angular geometry, density, shift,
and full pair plane. Those can genuinely differ. But the reciprocal scalar—the clock/ruler depth—
depends only on the clock part after the complete pair has been reciprocally normalized.

So if observer B uses the same calibrated clock when comparing with A and with C, B contributes the
same scalar endpoint value to both comparisons. The scalar differences then cancel around every
observer loop automatically. We do not need to invent a multiplication law for the two pair
metrics.

This also corrects an older counterexample. Its angular change altered the raw ruler length and
therefore appeared to alter depth. After the later completed-kernel rule is applied, both depths
are equal; the angular difference remains in density and shift instead.

What remains open is smaller: whether different comparisons really reuse the same clock
calibration, and how their full pair planes—not merely their scalar depths—are carried or matched.
The metric values and physical population of observer germs are still not generated here.
