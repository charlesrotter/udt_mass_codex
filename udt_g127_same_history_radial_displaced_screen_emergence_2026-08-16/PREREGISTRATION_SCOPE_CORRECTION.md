# G127 preregistration scope correction

Date: 2026-08-16

The preregistration was committed before executable evaluation and is preserved unchanged. Its
phrase “the isotropic G119 central-radial screen” was too compressed for the calculation actually
performed.

The executable strict comparison is:

- one regular finite-radius event in one supplied reciprocal spherical metric;
- one symmetry-radial null direction at that event; and
- one tilted null direction at that same event.

The symmetry-radial result is consistent with G119's broader radial-isotropy result, but the shared
finite-radius event is not literally G119's center-vertex observer. The same metric family also
admits the separate center-vertex query, so the package still establishes a same-history bridge;
only the same-event typing has been narrowed.

This correction changes no algebra, tested metric, witness, or preregistered maximum conclusion.
