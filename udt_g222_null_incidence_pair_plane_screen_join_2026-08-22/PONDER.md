# G222 ponder — the null ribbon

In lay terms, a single null ray is only a thread. A continuously changing observer comparison gives
a ribbon made from neighboring threads.

- Moving along a thread gives the null tangent `K`.
- Moving from one thread to its neighbor gives the clock-correspondence tangent `J`.
- The metric between those two directions measures the ribbon's oriented area density.

If that area density is conserved along each thread, it is a natural candidate for the reciprocal
ruler calibration that G221 had not yet constructed. The screen then consists of the two directions
normal to the ribbon. That would let the scalar clock chord and G188's matrix-valued screen response
belong to one geometric object without pretending they are the same observable.

One caution is load-bearing: a ruler density along each thread need not integrate to one global
ruler coordinate across the whole ribbon. If its curl is nonzero, the local completed pair remains
lawful while global coordinate carry remains open.
