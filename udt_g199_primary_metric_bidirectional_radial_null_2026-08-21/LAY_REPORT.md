# G199 lay report

The simpler picture won.

When we ask the actual primary UDT metric what happens in the two radial directions, it gives the
same basic instrument in both directions.  One ray moves outward and the other inward, but the
clock shift and the local image-spreading law are the same rule read along opposite orientations.

The dramatic “one direction loud, the other silent” result from G198 was not fake mathematics.  It
was the correct behavior of a later experimental metric that had been built with a one-sided gear.
That gear was never derived from the primary UDT metric.

So we should not add a second free gear to balance it.  We should return to the primary metric:
radial comparisons give the clean reciprocal redshift chord, while nonradial comparisons already
produce metric-derived angular distortion.  A richer asymmetry must come from a genuinely derived
richer metric, not from tuning the test coframe.
