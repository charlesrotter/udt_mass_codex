# G276 lay report

Your intuition was almost exactly right, with one important distinction.

`c_E` is like the conversion printed on a measuring instrument. It tells us how much length
corresponds to a measured amount of clock time. But a conversion rate alone is not a measured
length—just as “inches per centimeter” is not itself a ruler.

Once one real clock interval is attached to the exact observer segment described by the metric,
the combination acts like a tape measure:

\[
\text{length scale}
=\frac{c_E\times\text{measured clock time}}
{\text{normalized metric clock length}}.
\]

That fixes the one overall size left open by the normalized reciprocal kernel. The dimensionless
pair position can then be expressed in physical length units.

What it does not do is decide which cosmic history is real, which observer segment supplies the
clock reading, or whether the edge of the normalized relation state is physically populated as
\(X_{\max}\). It calibrates a supplied solution; it does not create the solution.
