## Landing

The infinite-bare-`c` statement does not by itself select the primary metric profile. Read as “all
observed delay is the metric's null delay,” it is exact for every positive `f`. Equating that delay
to static-slice proper distance is an additional premise and forces flatness. Equalizing the signed
null arrow in both directions likewise forces constant lapse.

The recovered mutuality statement nevertheless exposes a major semantic correction. The reciprocal
kernel already has a reversal-even invariant `cosh(delta)` as well as the directed factors
`exp(plus/minus delta)`. A candidate mutual clock rate is `sech(delta)`; the directed factors then
obey `exp(plus/minus delta)=cosh(delta)(1 plus/minus tanh(delta))`. One depth can therefore own both
mutual and directional outputs without making them identical.

## What was not derived

- an intrinsic separation functional assigning `delta` values;
- a nontrivial static profile, time-live history, source law, or propagation mechanism;
- an infinite physical signalling speed inside the completed metric.
