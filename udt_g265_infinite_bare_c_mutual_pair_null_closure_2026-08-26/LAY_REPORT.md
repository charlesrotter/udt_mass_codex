# G265 lay report

Saying that the underlying transfer takes no time does not yet tell the metric how much delay to
create. If “the delay is whatever the metric's light cone says,” every candidate metric passes. If
we force light-travel time to equal ordinary spatial ruler length everywhere, only the flat metric
survives and the intended UDT behavior disappears.

The useful algebraic discovery is that we had been mixing two readings of the same reciprocal
kernel. Its signed side gives directional redshift-like factors. Its even side gives the same
magnitude when the observer order is reversed. If the recovered mutual-distance premise is later
adopted, that even side could support mutual slowdown. The candidate clock rate is
`sech(delta)`—it is not yet a founded physical readout. Both channels can be built from one depth
without being the same observable.

So the proposed infinite-bare-`c` interpretation would place all observable delay in geometry, but
it does not yet write the geometry's score and has not been adopted as startup authority. The
recovered, still-proposed mutual-distance premise points to the sharper next problem: determine
whether a symmetric pair law follows in a complete time-live metric.
