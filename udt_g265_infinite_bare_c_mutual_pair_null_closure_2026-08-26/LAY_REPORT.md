# G265 lay report

Saying that the underlying transfer takes no time does not yet tell the metric how much delay to
create. If “the delay is whatever the metric's light cone says,” every candidate metric passes. If
we force light-travel time to equal ordinary spatial ruler length everywhere, only the flat metric
survives and the intended UDT behavior disappears.

The useful discovery is that we had been mixing two readings of the same reciprocal kernel. Its
signed side gives directional redshift-like factors. Its even side gives the same magnitude when
the observer order is reversed and can naturally support mutual slowdown. Both can come from one
depth without being the same observable.

So infinite bare `c` clarifies that all observable delay belongs to geometry, but it does not yet
write the geometry's score. The recovered mutual-distance postulate now points to the sharper next
problem: derive the symmetric pair law in a complete time-live metric.
