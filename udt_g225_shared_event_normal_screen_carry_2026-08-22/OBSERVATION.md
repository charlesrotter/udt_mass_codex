# G225 observation — what the current metric already supplies

Date: 2026-08-22

The existing chain already fixes the object types:

- G188 derives the positive quotient screen `K_perp/<K>`, its connection, tidal operator, and
  matrix Jacobi response on one supplied affine null branch.
- G222 identifies that quotient screen isometrically with the positive normal plane of the supplied
  null pair plane.
- G224 canonically normalizes incident null **lines** at a shared observer event, but explicitly
  derives no ambient direction or screen map.

At the shared event, the unit clock `U` turns each normalized future-null direction into one unit
spatial sight direction in the Euclidean rest space `U_perp`. Its screen is the two-plane
orthogonal to that sight direction. Therefore the metric already supplies both screen planes.

What is not yet known is whether their direct identification is unique and composable, or whether
the angular channel retains genuine path/order memory.
