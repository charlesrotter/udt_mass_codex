# GCA1 bounded checks

Before computation: exact audit of conditional response classes on smooth
Lorentz4 metrics. No observational data or approximation. Parent author has
derived the candidate and seen historical formulas/results; this is disclosed
mathematical exploration, not blinded empirical confirmation.

Compute Christoffels and Ricci directly for flat Lorentz2 times a round two-sphere
patch, then evaluate the inherited f(R) Euler identity for R+alpha R^2. Test
constant scalar, non-Einstein shape, conserved pure-trace response at the diagnostic
alpha and nonzero full response. A second time-dependent metric with varying R
tests actual divergence and detects dropping the derivative terms. These are
explicit comparison metrics, not admitted UDT solutions or a causal/stability test.
Test homothety failure of Q at fixed alpha and the representative/zero-set
distinction. No assertion that passing finite examples proves a general theorem.

Use exact SymPy, no tolerance, no producer code imports. Expose nonzero wrong-rule
controls rather than counting zero component identities as independent results.
General Noether/DDR/classification statements rest on the argument and named
hypotheses; published classification proofs are not rerun. CPU60s/512MiB, one
thread, existing capture utility, no GPU. Preserve failures; freeze candidate,
code and output before direct review. Each fresh reviewer chooses independent
checks before exposure to parent code. Normal central/maintenance/full406 checks
are regression/version gates, not proof of the new audit's physical conclusions.
