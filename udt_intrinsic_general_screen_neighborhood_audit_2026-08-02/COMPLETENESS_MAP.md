## Enumerated field coverage

The primary full-screen release includes all three symmetric screen-metric degrees of freedom:

```text
area: V,
diagonal shear: r,
off-diagonal shear: b.
```

The local `O(2)` rotation of a screen coframe is gauge and is not an additional metric amplitude.
The registered profiles vary all three metric modes, but one fixed analytic profile per mode is not
the complete function space.

The pair parameter `a` is varied only through the exact controls `0,1,4,5`. `u` is either the one
registered nonconstant quadratic profile or the constant `4` control. The audit therefore maps a
finite ensemble plus, if certified, an open existence neighborhood. It cannot support a universal
negative outside that scope.

## Outcome-neutral classification

Every candidate receives entries for:

1. four-metric nondegeneracy and Lorentz character;
2. exact invariant-Jacobian results at both registered points;
3. intrinsic Killing/twist projector status;
4. alternating depth/area class and any retained zero locus;
5. `Q<0`, `Q=0`, and `Q>0` strata;
6. symmetry enhancement, twist loss, or certificate inconclusiveness; and
7. the exact scope of any neighborhood inference.

A candidate is not removed because it is null, negative, symmetric, twist-free, or degenerate. A
failed uniqueness certificate is recorded as `INCONCLUSIVE` unless a separate exact symmetry proof
settles it.
