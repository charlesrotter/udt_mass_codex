# Completeness map

This audit covers one exact stationary metric family only.

1. Fields: arbitrary smooth stationary `phi`; no independent matter or source field.
2. Parameters: all six supplied `lambda` values; symbolic positive twist specialized to `1/64`.
3. Equations: connection/curvature identities; existing R17 equation ownership audited afterward.
4. Domain: complete regular `R x S3`; compact spatial integration allowed.
5. Fibers/base: `R x S1 -> R x S3 -> S2`; local and global descent kept separate.
6. Holonomy: complete oriented rank-two normal connection; leaf-only holonomy kept distinct.
7. Controls: registered twist-off and depth-off configurations retained but not promoted.
8. Excluded: time-live, null, rank-changing, other completion and branch families.
9. Downstream: action, source, matter, bootstrap, mass, `X_max`, CMB, signalling, and dynamics.

A negative is confined to this map. A later field equation or completion can change ownership but
cannot retroactively turn an off-shell witness into an on-shell selection.
