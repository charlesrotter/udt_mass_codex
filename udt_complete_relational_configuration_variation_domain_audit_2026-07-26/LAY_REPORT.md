# Lay report

We found that two ideas which looked like rival versions of UDT are actually related.

The more general construction asks: “For this observer, looking along this particular direction,
how does the reciprocal clock/ruler rule act?” It has one unresolved setting, called `lambda`, that
controls what happens to the two sideways directions.

At exactly `lambda=1`, the answer stops depending on which ruler direction the observer chose. The
one time direction is treated one way and all three space directions the opposite way. That is the
previously found simple `1+3` version. So locally it is not a rival theory; it is one special setting
inside the larger family.

But UDT has not selected that setting, nor has it selected one universal observer direction across
the whole universe.

The audit also cleaned up what counts as “the universe” versus “a question asked about the
universe.” The metric is physical geometry. An observer, ruler direction, and path specify a
comparison. Changing those labels asks a different question; it does not create a new universe or a
new field. Coordinate and screen rotations are bookkeeping. The founded `phi` tells us how
reciprocal dilation composes, but a separate missing rule must still say how much physical `phi`
belongs to a particular observer-pair path.

For now, the full metric—including its angular and mixed parts—must remain available. We cannot
throw pieces away, but we also cannot call every available piece a new particle or dynamical mode.

The gain is a clean set of drawers: geometry, observer questions, derived readouts, gauge choices,
global sectors, and future dynamics no longer get mixed together. The complete variation rule is
still open, but we now know what it must not double-count.
