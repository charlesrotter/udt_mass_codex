# Solver completeness map

This package is one bounded tile, not a complete UDT solver.

| Criterion | Covered | Dropped / still open |
|---|---|---|
| 1. Fields | all metric/coframe channels present in each declared witness; query/path state separate | no matter carrier; no universal split owner |
| 2. Action terms | none used | complete native action open |
| 3. Full equations | metric-owned geodesic, Jacobi, parallel/normal transport and algebraic pair readout | no native metric evolution or source equation |
| 4. Domain/charts | declared regular local charts and source-owned global branches | other components, split changes, all topologies |
| 5. Boundary/regularity | center/axis/loop/end/cut/conjugate classifications where present | no invented physical seal or boundary functional |
| 6. Topology | each source-owned topology is retained and labelled | no topology selected |
| 7. Dynamical character | stationary and off-shell time-live geometry kept distinct | no on-shell dynamics or physical stability |
| 8. Branch/bifurcation | endpoint/path homes and all constructible source-owned branches | not an exhaustive universe of metrics |
| 9. Stability spectrum | not covered | physical stability requires native evolution |
| 10. Regime | regular bounded witness and perturbation neighborhoods | singular/global completion outside source ownership |

Every numerical outcome is classified, never filtered for physical merit. A horizon, caustic,
rank loss, path dependence, or noncompletion is an output class, not a solver failure.
