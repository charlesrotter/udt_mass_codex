# Post-preregistration connection-scope clarification

The preregistered clock-curvature gate is a pointwise natural-frame
generator condition inherited from the parent audit. During exact replay,
the most general pointwise eigen-intertwiner exposed an additional
path-level requirement.

This does not alter the candidate source universe, fit a result, or change a
falsification threshold. It prevents an overstatement:

- `det(T+a^2 I)=0` with simple screen spectrum can intrinsically select the
  matched screen line;
- `[T,D_lambda T]=0` can keep that line parallel; but
- pointwise generator similarity is not automatically an equivalence of
  path connections when `a=d delta/d lambda` varies.

For the natural scalar Jacobi and reciprocal generators, a pointwise
eigen-intertwiner has columns proportional to `(1,-a)` and `(1,+a)`.
Connection compatibility with those unmodified generators requires its
path derivative to vanish. With nonzero columns this requires
`d a/d lambda=0`, unless the metric derives an additional connection term
or a different intrinsic normalization law.

The final report therefore keeps the original gate result and records this
extra transport caveat. It does not claim a full cocycle from a pointwise
match.
