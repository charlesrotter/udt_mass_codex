# G175 lay report

G174 said that a fully marked ruler gives one answer. G175 asks whether marking the ruler only near
observer A automatically determines all the marks out to observer B.

It does not. We can leave every mark near A unchanged, smoothly stretch the spacing farther away,
and obtain a different B reading without changing the underlying metric or pair curve. Nothing in
the current equations forbids that stretch.

There is still a useful simplification: if two complete tapes give the same reading between every
pair of points, they can differ only by a single constant choice of units—centimeters versus
inches—not by a distance-dependent change of scale.

The metric's own local "unit ruler" is not an automatic solution. Resetting the ruler to unit
length at every point changes the founded reciprocal readout. It is a different measuring protocol,
not A's ruler naturally carried outward.

So the kernel readout remains clean. The small unfinished joint is the ownership of the complete
A-to-B calibrated tape, not another scalar formula.
