# G71 in plain language

We checked whether the parts that made the previous CMB calculation solvable were already hiding
inside UDT's existing geometry.

One part is real: once we specify a line of sight and a screen, the metric carries orientation
information along it. Think of that as the geometry twisting or carrying an arrow painted on the
screen.

But we still lack three different things:

1. what pattern and strength the early source starts with;
2. which full profile and observation surface are physically realized;
3. which actual observation reads the carried arrow independently.

The important distinction is that **carrying information is not the same as creating it, selecting
its route, or measuring it**. The metric owns the carrier mechanism conditionally. It does not yet
own the source, the physical CMB setup, or the detector/readout rule.

So this was useful pruning. Another parameter-rank scan would only rediscover the same freedom. The
next useful work is to derive one of the missing connections—most immediately, whether the complete
observer-sky construction itself yields a native orientation-sensitive response—without inserting
a desired CMB source or fit.
