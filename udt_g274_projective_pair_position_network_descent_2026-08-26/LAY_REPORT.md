# G274 lay report

The new distance candidate passed the consistency test, but it taught us what kind of object it is.

Imagine that every observer comparison gives an arrow showing where the second observer lies in a
bounded three-dimensional relation ball. That arrow is real metric information. Along one straight
radial line, arrows combine by the simple Möbius rule already found.

When comparisons point in different directions, however, the metric also turns the carried ruler
frame. The arrow alone does not record that turn. Two comparisons can display the same arrow while
carrying differently rotated rulers; after one more comparison, they then produce different final
arrows.

Nothing has broken. Keeping the complete frame makes reversal and composition exact. The candidate
therefore behaves naturally as a path-labelled network of metric comparisons—more like arrows with
carried orientation than points on one universal ruler.

This does not yet tell us the number of metres represented by the unit ball, choose which paths
Nature populates, select the universe's evolving metric history, or derive `X_max`. It does show that
the proposed normalized position is compatible with the complete angular/screen geometry rather
than being a radial formula bolted onto it.
