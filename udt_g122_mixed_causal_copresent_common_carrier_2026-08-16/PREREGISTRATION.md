# G122 preregistration — mixed causal/co-present common-carrier audit

Date: 2026-08-16
Status: preregistered before reduction or witness evaluation

## Whole question and bounded regime

For one supplied smooth time-oriented Lorentz metric and one completely typed observer/source
query, determine whether the metric naturally puts these two constructions on one common linear
carrier:

1. the carried causal observer edge
   \(R_{BA}^{\rm causal}=P_B^{-1}C_{BA}P_A\), acting on four-dimensional transverse Jacobi phase;
2. the direct co-present pair construction, whose first differential supplies a longitudinal pair
   metric and terminal reciprocal readout.

The proposed square

\[
q_B R_{BA}^{\rm causal}=R_{BA}^{\rm pair}q_A
\]

will be tested only after the domains and codomains of every arrow are derived. Equal matrix size
will not count as a solder. No quotient may be chosen after seeing a residual.

This is a metric-led type/existence audit. It is not an observational fit or a search for a desired
history.

## Certification and falsification contract

A common linear carrier is derived only if every map is natural, nonzero, fixed before evaluation,
and retains the load-bearing phase information. A zero map or postselected quotient cannot make a
commuting diagram physical.

A nonidentity history restriction is found only if one covariantly defined typed residual vanishes
on one regular frozen history and fails on another without changing the query, branch, screen,
source junction, or quotient.

The result must be independently reproduced from exact algebra. If the common structure is only a
jet-level parent with distinct output channels, the proposed square is withdrawn rather than
repaired by an invented solder.

co-present pair readout within the declared observer-exponential class. It cannot select a
physical cosmology, derive a light/matter law, determine `X_max`, or establish a global nonspherical
completion.
