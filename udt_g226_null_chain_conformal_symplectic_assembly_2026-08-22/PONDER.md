# G226 ponder — what the assembly means

Date: 2026-08-22

The main advance is architectural. The clock comparison is not a separate dial attached after the
angular calculation. It grades the complete transverse phase that the metric carries along the
same supplied relation. The reciprocal ruler coefficient is exactly the inverse grading.

This makes the local null-chain machinery more cohesive and less scaffolded:

```text
metric along edge
  -> screen connection and curvature
  -> full Jacobi phase
metric clocks at endpoints
  -> exact conformal grading of that phase
shared event and directions
  -> pointwise screen change of basis
ordered chain
  -> one conformal-symplectic matrix
```

The remaining route memory is not a defect to eliminate. G225 already proved that the celestial
screen bundle cannot support a global flat endpoint-only carry. G226 shows where that memory lives:
inside the residual symplectic matrix after the exact clock grading is removed.

This still does not answer which null chains Nature populates. It says that once a chain is
supplied, its scalar and angular instruments now form one lawful gearbox rather than a pile of
separate parts.
