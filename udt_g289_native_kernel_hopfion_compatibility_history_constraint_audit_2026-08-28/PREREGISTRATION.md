# G289 preregistration

Date: 2026-08-28
Status: frozen before outcome implementation

## Question

Does the current metric-native complete projective/null-screen state own the historical Hopfion
carrier, and does any owned compatibility condition nontrivially restrict metric history?

## Tests

1. **Null embedding.** Starting only from a unit spatial direction `n` relative to a supplied unit
   timelike observer `U`, verify that `k=U+n` defines a null line and that Lorentz frame changes
   preserve the null-line sphere.
2. **Round-target test.** Determine whether the historical fixed round-`S2` metric and its derivative
   norms are invariant under the full allowed frame changes, not merely spatial rotations.
3. **Trivialization/topology test.** Determine whether the integer Hopf class of the component map
   `n:B3/boundary(B3)->S2` is invariant under smooth local frame rotations fixed at the boundary.
4. **History separator.** Construct at least two regular, geometrically inequivalent metric histories
   carrying the same null-direction texture and all currently owned kernel identities. A positive
   history-selection claim requires a kernel-owned criterion that rejects at least one.
5. **Conditional stability audit.** Trace every load-bearing carrier, action, boundary, staticity,
   and operator premise in the earlier stability result. None may be silently promoted.

## Certification contract

- All algebra/topology is derived afresh from current objects.
- At least one implementation-distinct exact or high-precision replay checks the algebraic claims.
- A hostile control must catch false nullity, false round-target isometry, and false history
  selection.
- A raw component Hopf number is not physical unless it descends through allowed frame gauge.
- Existing `L2+L4`, fixed boundary, or static stability cannot count as a metric-history selector.

## Falsification and stopping

Native ownership fails if a supplied observer/frame, target metric, connection, boundary, or action
is indispensable. History selection fails if a regular inequivalent metric family carries the same
texture while all owned identities continue to hold. Stop before any new action, source,
backreaction, physical mass, time law, or numerical Hopfion solve.
