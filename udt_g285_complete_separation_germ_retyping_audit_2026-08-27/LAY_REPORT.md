# G285 lay report

`phi` records one part of separation: the reciprocal clock/ruler comparison. It is not the complete
distance between observers.

The complete separation also includes the direction and how neighboring relations focus, spread,
or shear. Two pairs can therefore have the same `phi` while having different complete separations.
The earlier examples with equal `phi` but different angular area are examples of exactly that—not
two contradictory outcomes from one fully specified distance.

This removes a false problem: UDT does not need to force all angular behavior to be a function of
`phi` alone.

One real problem remains. The current mathematics can read and reconstruct any supplied complete
separation pattern, but it does not yet determine how those complete patterns are populated or
change across the universe and over time. The reframe clarifies that remaining problem; it does not
pretend to solve it.
