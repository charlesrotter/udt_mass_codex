# G184 lay report

The question was: when are two routes genuinely different, and when are they just the same route
drawn with different graph paper?

The answer is exact. They are the same when you can relabel the coordinates on the measurement
surface while preserving the ordered observers, clock/ruler calibration, and every other declared
part of the query, and the relabelled surface lands on precisely the same geometry.

There is one optional enlargement. If the query explicitly says that a mirror reflection counts as
the same experiment, mirror-related branches can be identified. If the query fixes handedness, they
remain different. The metric cannot decide which convention was declared after the fact.

Most importantly, two branches can give the same endpoints, the same reciprocal depth, the same
tape length, and even the same two-dimensional pair metric while bending differently through the
four-dimensional geometry. So the kernel is trustworthy as an evaluator, but it is not a complete
photograph of the route that produced the reading.

This does not reopen or weaken the kernel. It removes duplicate coordinate descriptions while
preserving real branch information. It also does not choose which branch Nature uses.
