This is not a demotion of founded `phi`: `phi` remains the additive logarithmic coordinate of the

## 2. Pointwise phi is not the founding invariant

On the supplied factorized coframe architecture use multiplicative depth `z=exp(phi)` and

```text

theta=D(z) bar_theta.
```

For any positive local `h`,

```text

bar_theta' = D(h)^-1 bar_theta,
D(z')bar_theta' = D(z)bar_theta = theta.
```

The production witness uses `z=3`, `h=7`; the independent witness uses `z=4`, `h=9`. Both give
different depth coordinates and exactly the same complete coframe. Thus complete geometry does not
canonically recover a pointwise `phi` unless a reference presentation or another owner is supplied.

For two endpoints the same identity gives

```text

z_q' = z_q h_q,
(z_q'/z_p') = (z_q/z_p)(h_q/h_p).
```

With independent endpoint shifts, even the potential difference changes while the endpoint
complete coframes and their complete physical arrow remain identical. The saved primary witness
changes `11/2` to `55/6`; the independent witness changes `13/3` to `91/6`.

## 3. What is reference independent

The full presentation orbit is reference independent. Reference transitions transform by the
two-sided coboundary while complete coframes and physical arrows remain fixed. But independent
endpoint shifts act transitively on every positive scalar depth representative:

```text

```

Consequently the orbit is a genuine invariant **class of complete presentations**, yet it cannot
by itself return the named scalar clock weight. Calling the orbit physical does not secretly select
one `delta`; the orbit contains them all unless reference or pair-depth data are separately owned.


## 8. Signed depth and nonnegative separation are not the same object

The founded additive arrow coordinate reverses sign. Physical separation magnitude is symmetric
and nonnegative. For a nonzero pair,


```text

```

reversal-even mutual readout therefore remain distinct. A future two-observer law may need both a
nonnegative magnitude and an orientation/arrow lift; the foundation does not yet provide their
