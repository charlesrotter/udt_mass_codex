## The central obstruction

The metric's Levi-Civita connection is metric-skew, while the founded reciprocal generator is
metric-self-adjoint. Their invariant trace pairing is exactly zero. Therefore Levi-Civita transport
can carry the ordered pair and its angular frame, but it cannot itself generate a nonzero
self-adjoint reciprocal dilation.

Raw coframe differentiation can display `dphi`, exactly as in the static diagonal control, only
relative to a selected reference coframe. A nonconstant reciprocal change of reference shifts the
extracted current by `-dchi`. The tensorial metric-compatible replacement returns zero.

This explains why prior calculations could both reproduce the reciprocal matrix in coordinate
components and find identity transport in physical orthonormal frames: they were comparing different
object types.

## The four principal route classes

1. **Endpoint field.** Exact and additive if a global founded-depth section is supplied. Every exact
   endpoint real cocycle has this form. The physical section, profile, and transitions remain open.
2. **Path one-form.** Exact and additive on paths if a normalized reciprocal current is supplied.
   Endpoint independence additionally requires zero loop periods. The metric-compatible connection's
   reciprocal projection is zero, and no alternative current is selected.
3. **Relative coframe logarithm.** Unique and additive inside one supplied positive reciprocal
   subgroup. It is not a homomorphism on generic noncommuting complete maps, and the metric has not
   supplied the endpoint comparison map.
4. **Bilocal/observer chart.** A metric can supply separation magnitude in a stated branch, but a
   symmetric nonnegative magnitude is not a signed reversal-odd cocycle and generic triangle lengths
   do not add. Signed lifts and angular transition data remain possible but unselected.

Two controls sharpen the boundary. A clock-frequency log ratio is an exact cocycle given matched
observer/signal/path data, but its identity with founded depth remains conditional. Differences of
chosen scalar curvature invariants are exact covariant cocycles, but the available choices are
nonunique, lack a founded identification, and need a dimensionless normalization.
