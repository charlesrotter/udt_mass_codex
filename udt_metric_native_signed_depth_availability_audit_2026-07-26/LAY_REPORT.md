# Lay report

We found the precise place where the clock law is still incomplete.

`phi` itself is not mysterious. It is already the number that says how much the founded clock and
ruler have changed reciprocally: one shrinks by `exp(-phi)` while the other grows by `exp(phi)`.

The missing step is assigning a `phi` difference to two real observers.

If someone hands us a valid `phi` map, a reciprocal measuring field along a path, or a comparison map
between the observers' frames, the mathematics reads the depth perfectly and composes it correctly.
But the present metric record does not yet pick which of those maps is physical.

The ordinary connection supplied by the metric cannot secretly do the job. That connection preserves
the metric while transporting a frame. Reciprocal dilation changes the clock/ruler scale in opposite
directions. The two kinds of change are mathematically perpendicular, so the dilation part of ordinary
metric transport is exactly zero.

This also explains an old source of confusion. Differentiating the metric's coordinate components can
display `dphi`, but that calculation is comparing them with a chosen coordinate ruler. Change that
reference ruler from place to place and the displayed value changes. The formula is exact after the
reference is chosen; the reference is the part UDT has not yet selected globally.

Distance alone does not solve it either. Distance is positive and the same in both directions, while
the reciprocal depth must change sign when the observer order is reversed. General distances also do
not add around a triangle. The angular sector may carry the missing composition information, but this
audit did not assume how.

So this is genuine narrowing, not another claim that `phi` is undefined. We know the measuring scale
and the algebra. We still need the metric to identify the physical comparison rule that places that
scale between observers.
