# G236 lay report

The two supernova catalogs now agree on the same broad relational-distance curve after we remove
the supernovae known to appear in both releases.

We did not guess a formula. Each catalog was allowed to draw the curve independently at several
fixed resolutions. Their curve shapes agree within the released uncertainties every time.

This is useful because SNe can now act as measurements of one slice of the universe's relational
state rather than as a machine for inventing the UDT law. The next test is whether a different kind
of observation hears the same underlying state without letting us redraw the curve.

The caution is important: these are processed astronomy releases, not raw light. Their light-curve
and bias corrections contain conventional astrophysical and approximate-cosmology assumptions.
The agreement is therefore a strong release-level consistency result, not yet a native UDT
prediction or proof.
