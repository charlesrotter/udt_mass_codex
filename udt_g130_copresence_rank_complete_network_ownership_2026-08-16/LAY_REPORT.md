# G130 lay report

The cleanest picture is this:

- Given one supplied finished score, co-presence says which locations belong to that same score.
- Reciprocity says every clock–ruler comparison follows the same musical grammar.
- Testing every mathematically admissible direction gives enough probes to reconstruct the score.
- But none of those statements writes the actual notes.

This “every direction” test is not a claim that physical observers occupy every direction; defining
timelike and spacelike directions already presumes the geometry. It is a reconstruction test.

Once the complete notes—including more than scalar depth—are given smoothly and consistently, they
reconstruct the metric exactly. The valued network is not an extra layer attached to spacetime; it
is spacetime written relationally.

So we no longer need to ask, “After constructing a complete network, what selects its universe?”
The complete network already is that universe's metric. The remaining question is smaller and more
honest: what determines the numerical values of the complete relational field?

Reciprocity and composition constrain those values strongly, but do not make them unique. Two
different reciprocal metrics can occupy the same event domain and obey all the same comparison
rules while having different curvature.

The next narrow test asks how much information survives if every full `2x2` pair pullback is reduced
to the terminal reciprocal scalar `phi_pair`: the whole metric, only its conformal shape, or less.
