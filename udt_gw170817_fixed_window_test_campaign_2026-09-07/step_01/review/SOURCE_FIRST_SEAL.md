## Independent minimum contract, before target exposure

1. Identify exact public H1/L1 C02 and Virgo Repro2A4096Hz release files,
   observed headers/time span/rate, authoritative release mapping, checksums,
   channel/time conventions and metadata masks. Check the entire support of
   delays and analysis filters, not only displayed core times. DATA/CAT flags
   have published meanings and do not establish absence of every transient.
   Injection bit sense must be read rather than inferred from the word mask.
   Do not confuse the special C00/Repro1A cleaned event files with this release.
2. Match LIGO hourly calibration epochs by actual GPS stamps and Virgo run-wide
   record. These are estimates at discrete times, not automatically certified
   continuous interval bounds. The stated ratio is true/model response; its
   inverse is the response of the released channel to a true signal if working
   without correcting the released strain. Median complex bias and uncertainty
   belong separately. Pointwise +/-1sigma does not give a joint frequency/time/
   detector covariance or deterministic envelope. A declared sensitivity grid
   or conditional envelope remains useful if no unsupported coverage is claimed.
3. The two input waveforms stay unrestricted within the declared linear weak
   tensor/plane-wave regime. A finite-dimensional band or sampling restriction
   must be stated; arbitrary omitted/outside-window content must not silently
   vanish. For complete analysis operator A and supplied response R, a claimed
   exact null requires N A R=0 on the actual waveform domain. Pointwise rank(F)
   alone does not prove this for finite windows and filters. Nonconstant response
   F(t) and frequency-dependent transfer do not generally commute with filtering
   or tapering. Delay interpolation and boundary extension are part of R/A.
   A common operator applied after an exact aligned time-domain null preserves
   zero; filtering each channel before a varying null generally does not.
4. Finite-arm, detector motion/rotation and astrometric errors must either be
   implemented with their conventions or bounded through the actual operator.
   Small2pi fL/c or Omega T is a diagnostic parameter, not a bound by itself.
   Any bound multiplying signal size needs justified signal-size control.
   Independent injection families can falsify preservation but a finite set
   does not prove it for every unrestricted waveform; use analytic/operator
   argument for claimed universal control. Time-dependent tidal reconstruction
   retains response derivatives and cannot just differentiate calibrated d(t).
5. Explicit upstream evidence is required for cleaned/downsampled release signal
   retention. O2 docs link final C02 cleaning to the cited subtraction work.
   Source safety tests and hardware/software injections support its intended
   class, but their statistical scope must survive. Downstream injection only
   tests later analysis. Paper diagnostics include narrowband spurious effects;
   no generic algorithm test is an exact arbitrary-waveform whole-band bound.
   Documentation or a justified conditional model may suffice; no demand for
   every raw servo sample or new instrument premise is imposed by this review.
6. Freeze core/padded support, band/notches/tapers, sky/frame/timing, interpolation,
   estimator/training/reference roles, covariance/bias handling, statistic,
   effect size and decision/exclusion rules before the reserved contrast.
   Quality-led narrowing is allowed when recorded before outcome exposure.
   Pre-glitch core placement alone does not exclude filter or upstream support.
   Fixed off-source windows exclude known event and glitch with full padding.
7. Off-source noise assumptions must cover the actual statistic under detector
   weighting, temporal change and calibration epoch, not an unrelated scalar PSD.
   Keep temporal/frequency/cross-detector correlation and finite training error.
   Empirical rank p-values require exchangeability; stationarity diagnostics do
   not prove it. Event selection/known published outcomes remain exposed, even
   with a new fixed contrast. A descriptive conditional scale need not be sold
   as a blind selection-corrected significance. One null channel is one relation,
   with correlated Fourier/time observations, not three independent holdouts.
8. Calibration and response uncertainties may leak a large allowed tensor signal
   into the null. Arbitrary per-channel functions erase every test; do not fit
   them away. The response-weighted centered covariance is b C b^dagger, with
   residual bias b mu retained. Null/signal orthogonality alone is not stochastic
   independence. Any alternative in the tensor response image is invisible.
   Power/effect-size gate precedes event contrast and can legitimately stop FW2.
