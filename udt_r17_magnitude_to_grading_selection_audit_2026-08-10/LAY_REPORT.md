# Lay report — what the R17 audit found

We found that one earlier “missing joint” was partly a bookkeeping mistake.

R17 already had two pieces:

- a number saying **how much** the clocks differ between two places; and
- a built-in set of directions saying **what should shrink and what should expand**.

If that number is nonzero, doing nothing is not an honest alternative. “Do nothing” can transport a
frame, but it cannot represent the nonzero clock/ruler dilation that the founding UDT rule says is
there.

Once one of the complete off-shell R17 metrics is supplied, the pieces fit in essentially one way: the clock shrinks,
the ruler expands, and the two angular directions scale by the amount already written into that
particular metric. The only leftover freedom is rotating the two angular axes together. That
rotation changes how we label the angular directions, not the metric or the reciprocal readout.

So the **internal dilation gear** is no longer an additional free ansatz inside that supplied branch
geometry. It is fixed by the complete coframe, up to harmless angular-frame rotation. This remains
conditional because UDT has not selected that off-shell coframe as the realized geometry.

A fresh adversarial reviewer independently checked all 17 sources and both exact calculations and
found no counterexample to that carefully limited conclusion.

What we still do not have is the whole observer-to-observer machine. The metric has not yet chosen
which path connects the observers, how a carried frame is reconciled with the frame rebuilt at the
destination, or which two-dimensional comparison surface is physically used. Nor has UDT selected
R17 as the realized universe or put these off-shell configurations on shell.

In short: we connected the “amount” to the “gear,” but we have not yet derived the road on which the
gear operates.
