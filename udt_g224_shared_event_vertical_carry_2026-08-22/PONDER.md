# G224 ponder

The likely simplification is that no new ruler-carry mechanism is needed at a true observer
vertex.  The middle observer's clock is the common socket into which both null ruler lines plug.
The metric measures each future-null generator against that same clock.  Matching those two
measurements is then the only positive line map compatible with the supplied data.

This would be a narrow but important closure:

- G216 supplies the clock-rate chain on actual observer events;
- G222--G223 supply each ribbon's clock--ruler pairing;
- the shared event lets those pairings be compared;
- the resulting vertical carry should be the inverse representation of the clock carry.

The danger is overpromotion.  A scalar line map at one shared event is not an identification of
ambient null directions, a screen/Jacobi map, a unique path, or a proof that an independently
constructed direct `A -> C` relation equals the broken composite.  Those claims remain outside
this package.
