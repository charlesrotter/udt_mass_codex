# G224 map — shared-event vertical carry

Date: 2026-08-22

## Whole question

For two supplied, composable observer relations

\[
A\longrightarrow B\longrightarrow C
\]

whose null ribbons meet the **same event** of observer `B`, does the complete Lorentz metric and
that shared incidence canonically identify the two one-dimensional null ruler lines at `B`?  If it
does, does this close the local scalar carry that G223 correctly left open, without selecting a
screen map, a path, an observer population, or an independently supplied direct `A -> C` ribbon?

## Exact bounded regime

- one smooth time-oriented Lorentz four-metric `g`;
- three supplied future-timelike observer germs with metric-unit tangents `U_A,U_B,U_C`;
- one supplied regular future-null ribbon for `A -> B` and one for `B -> C`;
- the two ribbons have the same marked event on `B`;
- their vertical tangent lines at that event are one-dimensional and future-null;
- affine generators may be rescaled independently by arbitrary positive constants;
- only the vertical line carry and its scalar composition are in scope.

The normal screen, matrix Jacobi data, global path selection, `X_max`, history selection, sources,
actions, matter, profiles, fits, and boundary completion are omitted.

## Metric-led object

For an incident ribbon `e` at the shared event of `B`, let `V_e` be its future-null vertical line.
The metric and `B`'s unit clock define the positive linear functional

\[
\mu_{e,B}:V_e\to\mathbb R,
\qquad
\mu_{e,B}(v)=-g(U_B,v).
\]

The fork is whether the condition

\[
\mu_{BC,B}(S_Bv)=\mu_{AB,B}(v)
\]

defines a unique, invariant positive line isomorphism

\[
S_B:V_{AB,B}\longrightarrow V_{BC,B}.
\]
