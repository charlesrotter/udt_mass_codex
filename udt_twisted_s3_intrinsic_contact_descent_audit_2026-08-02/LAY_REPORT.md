# Lay report

The last audit showed that one complete mathematical UDT geometry can identify its own clock and
ruler directions. This audit asked what happens when we use those directions instead of the old
labels we had placed on the coordinate frame.

Three old contact readings now become genuine properties of that metric. In the orchestra
metaphor, we have stopped measuring two instruments by where their chairs happened to be and are
instead identifying the instruments by their actual sound. Turning the coordinate chart or
rearranging the chairs no longer changes the readings.

Those readings also recover two rates: how reciprocal depth changes and how the angular screen area
changes. In the frozen equal-unit witness, the ratio of the two readings even recovers the depth
value itself. That absolute statement depends on the frozen branch normalization; it is not yet a
universal zero point for depth. Across all three versions of the explicit witness, the contact
reading stays strictly on one side of zero; the old null boundary is never reached.

There is also an important limitation. In this simple witness the angular screen changes only as a
fixed function of the same depth variable. The two parts never vary independently. Their
alternating “orchestra” effect therefore collapses to zero. We have solved a bookkeeping and
geometric-authority problem on this branch, but we have not yet found a nontrivial independent
depth–angular interaction or a law that selects the branch.
