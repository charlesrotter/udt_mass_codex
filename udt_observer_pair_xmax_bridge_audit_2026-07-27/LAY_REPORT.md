# Lay report

The metric gave us a real new piece, but not the final bridge.

On the stationary test universe, the metric itself tells us how a path mixes three things:

1. the clock weighting from `phi`;
2. the full angular distance crossed;
3. the directional twist of the geometry.

Going around the same path in reverse cancels the twist from the round-trip part but exposes it in
the directional difference. That is a clean, native interaction between the clock and angular
sectors. We did not have to add a mechanism to obtain it.

However, this path geometry is not the same object as the reciprocal clock comparison. Two
observers can move around a surface on which `phi` is unchanged: their clock-depth difference is
zero, while the angular distance between them is still positive. So one scalar clock number cannot
stand in for the entire three-dimensional relationship. The missing bridge, if it exists, must
carry angular/coframe information as well.

That does not make the clock system trivial. The collection of clock comparisons for every pair is
an enormous object: changing `phi` changes that whole network, except for adding one common constant
everywhere. A native rule comparing that network with complete path/coframe data could therefore
be a genuine field-level law. The current premises simply do not select such a rule.

The smooth compact stationary test universe also makes all three executable quantities—spatial
diameter, clock-depth range, and optical/path diameter—finite and actually attained. It therefore
does not reproduce the working picture of `X_max` as an approached but unreachable limit. This
does not refute that picture. It tells us that the required asymptotic behavior must enter through
the still-open global completion, observer domain, or physical comparison rule—not by relabeling
the compact diameter.

Finally, calculating how any one path or diameter changes gives only an output. The complete
all-pairs clock network has enough information to do more, but no UDT premise yet tells it what
complete geometric network it must equal or preserve. The feedback rule needed for bootstrap is
still missing, not mathematically ruled out.
