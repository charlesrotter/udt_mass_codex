# G344 lay report

G343 showed how a narrow bundle of neighboring paths carries both its sideways displacement and
its opening direction between any two points. G344 shows that the entire transport can be
compressed into one endpoint bookkeeping object.

That object is well behaved between every two distinct positive-time points on each supplied path.
If a path is divided into pieces, the endpoint objects join and reproduce the whole path exactly.
Running the path backward changes the sign of the endpoint object and leaves its spreading density
unchanged. No hidden reference event or distance scale enters.

The second derivative of this endpoint object gives the inverse of the bundle's geometric area
response. This is a real bridge toward observational geometry: it tells us how sensitively the
final screen position depends on the initial opening. But its numerical normalization still changes
when the arbitrary affine derivative unit is changed. It is therefore not yet brightness,
luminosity, probability, or observational distance.

There is one harmless freedom. The transport cannot detect a term depending only on the endpoint
times. Choosing the homogeneous representative sets that term to zero. Any other composable choice
is only a difference of endpoint conventions and leaves the spreading density unchanged.

The result covers one exact supplied UDT spacetime and every labelled ray in its stated family,
including both principal directions and all compact path labels. It does not choose which path
Nature uses, a universe, matter, a physical scale, or `X_max`.

A fresh external reviewer authenticated the sealed evidence, reran every registered check, rebuilt
the core calculation separately, and accepted this bounded result without repair.
