# G344 map — endpoint generating function and determinant density

Date: 2026-09-04
Status: preregistration stage

## Whole question

Starting only from G343's exact bilocal screen phase-space propagator on one fixed labelled null
ray, does the metric determine a single quadratic endpoint generating function on every
noncoincident positive-time segment? If so, does its mixed endpoint Hessian give a globally regular
screen determinant density, and how do both objects compose, reverse, and transform under changes
of reference event, common affine unit, endpoint screen basis, principal direction, and compact
path label?

This is `METRIC_LED` and observing rather than targeting. It asks what is already encoded in the
G343 symplectic map. It does not introduce a light, flux, amplitude, probability, action-of-the-
universe, distance, source, or population law.

## Exact bounded arena

Use only the G343 metric, its supplied normal-observer congruence, one supplied fixed labelled null
ray, the parallel quotient screen, one common affine gauge along that ray, and arbitrary distinct
positive endpoint times. All two-dimensional endpoint screen positions and directions remain live.
Every projective direction, including both principal limits, and every supplied compact-lattice
lift remains in the domain.

Write the G343 map as

```text
(x1,p1) = (A x0 + B p0, C x0 + D p0),
```

where `x` is screen separation and `p=dx/ds` uses the common affine parameter. A type-I endpoint
generator is allowed only where `B` is invertible. Coincident endpoints are excluded from that
chart because the identity map has `B=0`; the exclusion is algebraic chart typing, not a discarded
physical solution.

The candidate geometric density is the absolute determinant of the negative mixed endpoint
Hessian. It must be treated as a density with affine and endpoint-basis weights. Calling it a
brightness, luminosity, observational distance, quantum amplitude, or full spacetime Van Vleck
scalar is forbidden.

4. Prove or refute stationary endpoint composition and the corresponding determinant gluing law.
5. Derive reversal, common-affine scaling, separate endpoint-frequency typing, independent

8. Retain every compact lift separately and distinguish a per-lift density from any sum, weight,
