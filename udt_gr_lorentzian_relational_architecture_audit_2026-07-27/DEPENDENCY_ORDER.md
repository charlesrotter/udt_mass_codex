# Relational dependency order exposed by the survey

The corpus does not supply one universal “observer-to-observer relationship.” It separates a stack:

1. **Local geometric class.** A Lorentzian metric supplies cones, norms, and an orthonormal-frame
   class; orientation supplies future/past.
2. **Observer representative.** A timelike direction or worldline chooses an observer-adapted split
   or tetrad representative. This is additional data, not a unique output of the metric.
3. **Comparison domain.** A curve, geodesic, ray, loop, congruence, or thin-path class identifies what
   is being compared between separated events.
4. **Transport and descent.** A connection transports fiber data. Transition functions and gauge
   equivalence say when local representatives describe the same global object.
5. **Holonomy and global completion.** Curvature and topology control path dependence, invariant
   subspaces, quotient existence, and whether a global section or spacetime reconstruction exists.
6. **Dynamics and data.** Field equations plus initial/boundary/matter data choose a physical metric
   development within the theory; they do not generally manufacture a canonical tetrad.
7. **Operational readout.** Clock, light, free-fall, or reference-field rules turn the geometry into
   a measurement statement.

For UDT this is a comparison map, not authority. The current exact pointwise extension class is
physical metric data until a UDT-derived equivalence law proves otherwise. The legitimate type
correction is only this: derive the global bundle, transition/equivalence law, connection/path
category, and admissible sections before treating “choose one extension member” as the first or only
closure problem.

The next derive-or-fail object is therefore a **UDT-native reciprocal comparison bundle**:

- base objects: explicitly typed observer/event data;
- arrows: explicitly typed path classes with identity, reversal, and composition;
- fiber: the founded reciprocal pair embedded in the complete coframe extension class;
- transition law: derived from the UDT metric rather than imported Lorentz/Cartan habit;
- connection/transport: derived or shown not to follow;
- equivalence: sufficient to distinguish representative freedom from inequivalent metric freedom;
- global gates: descent, holonomy, admissible sections, and quotient/integrability conditions.

Only after that object is derived or fails should one ask whether a preferred section, variation
domain, bootstrap fixed point, action, source, or boundary is selected.
