## What the test found

A local mathematical realization is possible for compatible supplied ray
families. Compatibility does not determine what, if anything, is carried.
The candidate local criterion for a smooth nonzero future null field is

\[
 d\Theta=\alpha\,g(\ell,\cdot),\quad\alpha>0
 \quad\Longleftrightarrow\quad
 g(\ell,\cdot)\wedge d[g(\ell,\cdot)]=0
 \quad\text{on a sufficiently small neighborhood}.
\]

In plain language, the ray directions must fit together as normals to phase
sheets. Being null and geodesic alone does not guarantee that. If the vector's
normalization must also be preserved, its covector must itself be closed;
an integrating factor cannot silently change a supplied frequency.

G352 already supplies an exact phase gradient, so this compatibility condition
is automatic in its declared domain. The twisting control is not a defect in
G352 or a counterexample to G349's source-vertex wavefront theorem.

 \Gamma_j/\Gamma_i=R_{ji}A_{ji}^{-1}\quad(s>0,\ J_i,J_j>0).

phase changes can preserve same-ray transfer ratios while changing absolute

between cuts does not by itself impose the same measure on every phase sheet.
Passive relabeling is distinguished from genuinely different measures.

## What would count against a proposed continuation

- Nonzero `beta wedge dbeta` on the proposed family blocks its realization as
  this phase-gradient direction; this would not reject every possible carrier
  or every G352-compatible family.
- Failure of `d(alpha_0 beta)=0` blocks a specifically prescribed normalization.
- Varying phase-slice total measure, with phase and spacing held fixed, is
  outside the same-mu product branch even if each phase is conserved along rays.
- Surviving inequivalent data at fixed supplied inputs defeats a uniqueness
  claim based only on those inputs. Successful transfer ratios alone cannot
  demonstrate an absolute population, phase profile, or physical source.

These alternatives do not force a choice between native derivation and a new
postulate. Additional accepted construction data, an initial-data convention,
an optional mathematical readout, an observational attachment, a different
realization, or genuinely new physical input remain distinguishable routes.
No route is selected here.
