# G129 lay report

We were mixing up two questions.

First: if we knew every sufficiently varied observer-to-observer clock/ruler comparison, would that
already describe the metric? Yes. Locally, the metric has ten independent numbers. One pair
comparison exposes three combinations. Six suitably angled clock–ruler comparisons recover all ten
exactly. When neighboring observer charts agree on their overlaps, these local reconstructions
assemble into one geometry.

So a complete co-present observer network does not need a separate “choose the universe” switch.
The network is another complete description of the geometry.

Second: do the founding postulates already give every value in that network? That is not yet proved.
A network looking in too few directions can miss real curvature. The terminal `c_eff` value also
compresses a full pair metric to one number, so it cannot reconstruct everything by itself.

The quiet-middle and loud-end picture remains an important clue, but it is not unique by itself:
one can alter a smooth profile between the quiet region and an extreme without changing either.
Something in the full global relation network would have to forbid that alteration.

The next question is therefore much cleaner: does co-presence mean that the complete rank-sufficient
observer network and its global compatibility are foundationally supplied? We should answer that
before searching for an action, selector, or new mechanism.
