# Lay report

The earlier calculation treated the angular part of the universe like a single circular track.
The new map lays out the whole orchestra before choosing which instruments matter.

It found three levels:

1. A perfectly round angular geometry lets each clean angular pattern play independently.
2. A geometry with one rotational symmetry keeps one label intact, but different angular shapes
   can still mix with one another.
3. A fully uneven angular geometry can mix both angular labels, so it must be treated as one coupled
   problem.

It also found a specific term that disappears in the simple rotational case but is present in the
general case. That is useful progress: we now know exactly why the old shortcut cannot safely be
extended to every angular geometry.

Nothing here says which geometry nature uses. Instead, it gives us an honest shelving system for
all the known possibilities and the correct mathematical tool for each shelf. The next small test
would build the coupling chart for the simplest rotating full-angular control. It would test our
machinery, not declare that control to be the universe.
