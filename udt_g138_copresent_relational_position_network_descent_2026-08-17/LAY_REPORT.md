# G138 lay report

Imagine every observer carrying their own map and placing themselves at its center. If the network
is coherent, switching from Alice's map to Bob's map moves every coordinate by one exact rule, but
nobody's actual relationship changes. The equations choose no map origin; this alone does not rule
out a physical solution having an asymmetric feature or distinguished observer for another reason.

That rule is the same Mobius law already found in the pair kernel. Mathematically, all arbitrary
depth-origin gauges form a **torsor**. Observer-centered maps are particular members of that family.

There is one decisive test. Travel around a closed chain of observer comparisons. If the signed
depth returns to zero, all pair positions can be represented as differences of endpoint depth
potentials. If it does not return to zero, two possibilities remain:

- the network is inconsistent if those routes were supposed to be the same physical comparison;
- or the mismatch is genuine path memory—holonomy—if the routes remain distinct.

The current theory has not yet chosen between those global possibilities. It has now made the fork
precise.

This is the positional skeleton of co-present relational spacetime, not yet the entire body. It
does not determine the orchestra's full metric values, which observer-pair realizations occur, or
the physical size represented by `X_max`.
