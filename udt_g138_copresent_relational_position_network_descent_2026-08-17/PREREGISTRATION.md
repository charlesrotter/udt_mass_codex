## Preregistered theorem candidates

For each oriented edge, set

```text
phi_BA=-phi_AB,
xi_BA=-xi_AB,
q_AB=exp(-2 phi_AB).
```

Test equivalence on a connected graph between:

1. existence of endpoint potentials `Phi_A`, unique up to a common additive constant, with
   `phi_AB=Phi_B-Phi_A`;
2. zero additive depth around every cycle;
3. unit product of `q_AB` around every cycle;
4. zero iterated native-Mobius sum of `xi_AB` around every cycle;
5. path-independent root reconstruction.

For a chosen reference observer `O`, preregister

```text
u_A^(O)=tanh(Phi_A-Phi_O),
xi_AB=(u_B^(O)-u_A^(O))/(1-u_A^(O)u_B^(O)).
```

Changing the reference to `R` must give

```text
u_A^(R)=(u_A^(O)-u_R^(O))/(1-u_A^(O)u_R^(O)),
```

with every pair `xi_AB` invariant. This is the preregistered no-preferred-center test.

For a connected graph with `n` vertices and `m` unoriented edges, a spanning tree must leave
exactly `m-n+1` independent cycle residuals. Vanishing only those fundamental residuals must imply
vanishing of all cycle residuals.

## Path-labelled counterbranch

remain a lawful path-additive assignment when different paths are not identified. Its cycle value
is real additive holonomy, with bounded display `tanh(h_cycle)`. No averaging, antisymmetrization,
or least-squares projection may erase that residual.

This establishes a classification, not a selection theorem. Endpoint descent may be demanded only
for arrows declared to represent the same physical relation; otherwise nonzero holonomy remains a
valid branch/path label.
