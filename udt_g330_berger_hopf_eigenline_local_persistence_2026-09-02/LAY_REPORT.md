# G330 lay report

The current metric contains a real Hopf-shaped structure in one admitted class of universes,
without adding the old Hopfion field.

A perfectly round three-sphere has too much symmetry: every direction looks equivalent, so the
metric cannot choose one family of linked circles. Slightly squash or stretch that sphere into a
Berger sphere and its own curvature identifies one special direction everywhere. Following that
direction produces the linked circles of the Hopf fibration. The result does not depend on the
coordinate frame, the direction in which each circle is traversed, or the sphere's overall size.
The normalization uses each fibre's own metric-measured circumference; it does not import a ruler
or treat the Berger parameter as a new physical scale.

If that non-round geometry is used as initial data for the provisionally adopted local metric law,
the symmetry and curvature distinction survive for at least some nonzero interval of time. This
statement is conditional on the general imported Einstein initial-value existence/uniqueness
theorem and its standard isometry-extension consequence; G321 recorded an earlier scoped use of
that theorem but did not prove it. The Hopf class
therefore cannot instantly disappear. It could change later only if the distinguishing curvature
gap closes, the topology changes, or the geometry becomes singular—cases not decided here.

This is a useful native bridge, but not a universe selector. The same law still permits the perfectly
round history and other topologies that do not select this Hopf line. It also does not revive the old
`L2+L4` carrier energy or prove a stable particle. It says the metric can itself carry Hopf geometry
on a bounded non-round `S3` branch; it does not say Nature must occupy that branch.
