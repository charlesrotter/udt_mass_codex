# G250 lay report

G249 showed that the native geometry determines the shape of the picture but leaves one overall
zoom setting. G250 asks what kind of real measurement can set that zoom.

The answer is simple: one genuine measurement of a length, time interval, area, volume, or nonzero
curvature—attached to the same clearly identified part of the model—sets the single zoom. A second
independent measurement should produce the same zoom; if it does not, the proposed dimensionless
history or the matching protocol is wrong.

Redshift and `c_E` do not do this by themselves. They tell us ratios and convert clock units to ruler
units, but they do not supply an interval. `G_obs` also needs a mass or density and a rule saying
which geometric length that combination represents.

The current SNe reconstruction intentionally discarded its absolute zero point, so it cannot set
the zoom. An older SNe-derived scale exists, but it depends on the old P1 curve and imported light
physics. It remains a conditional comparison, not part of the native kernel.

No scale has been fitted or chosen yet. We now know exactly what a lawful anchor must look like and
how a second anchor can test the model instead of becoming another adjustable coefficient.
