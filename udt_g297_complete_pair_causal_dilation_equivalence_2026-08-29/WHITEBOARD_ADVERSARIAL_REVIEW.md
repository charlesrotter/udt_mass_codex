# G297 three-role whiteboard adversarial review

Date: 2026-08-29

Three independent read-only roles reviewed the first G297 formalization: local geometry, global
relation/network structure, and foundations/semantics. All accepted the scalar controls and all
rejected the initial complete-transfer theorem.

## Shared findings

1. A radar midpoint is a diagnostic coordinate on an A-centered causal diamond, not a definition
   of W6 co-presence or universal simultaneity.
2. Genuine bidirectionality requires both the A-centered and B-centered causal diamonds.
3. The static-lapse witness refutes only the scalar rule `R=M_PT`; it does not select or reject a
   metric history.
4. Active-screen algebra refutes `sech(delta)` as a universal complete scalar; it does not construct
   the missing transfer.
5. A causal-diamond/directional-data family and a rank-two pair immersion germ are different types.
   The first formalization named but did not build the map between them.
6. Supplying transported frame/screen carry inside the causal input partially inserts the reciprocal
   result and violates the intended independence test.
7. W1 evaluates every regular pullback and cannot turn common-metric reconstruction into a history
   law.
